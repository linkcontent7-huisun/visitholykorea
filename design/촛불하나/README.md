# 「촛불 하나」 시안 (2026-11-08)

> 「불이 없는 곳에 불을 켜 주세요. 그러면 조금, 따뜻해집니다.」
> 순례 웹앱이 "잘 만들었지만 설레지 않는다"는 반응에서 출발한 새 입구 시안. 앱 코드와는 별개이며 배포하지 않는다.
> 배경·결정 대기: `docs/50-research/벤치마킹/2026-11-08-온라인사찰-산사.md`, `docs/이어서-할-일.md` 맨 위.

| 파일 | 무엇 | 순서 |
|---|---|---|
| `1-light-map.html` | 빛의 지도 — 세계 지도에서 각 도시의 촛불이 한국 성지로 「빛의 실」로 이어짐(성지 205곳 실제 좌표) | 첫 안 |
| `2-warm-world.html` | 성지를 걷어내고 「어두운 곳을 누르면 불이 켜지고 따뜻해진다」만 남긴 판 | 사장님: 성지가 너무 보이는 게 싫다 |
| `3-story.html` | 이야기 판 — ① 두 손 비비기로 켜기 ② 시련(바람·떨림·촛농·그을음) ③ 세계 ④ 불 건네기 | 사장님: 1~5 흐름 |
| `4-votive-stand-3d.html` | 3D 봉헌초 받침대 — 성모상 앞 3단 50자리에 내 초를 나란히 세움 | 사장님: 받침대 + 3D |

- 열기: 파일을 브라우저로 더블클릭. 지도·3D 엔진(d3·topojson·three.js)은 cdnjs 에서 불러오므로 **인터넷이 필요**하다. 인터넷 없이 열리는 한 파일 판은 사장님 노트북 `바탕 화면\모두의창업-복구\촛불-시안\` 에 있다.
- 🧪 **다른 사람의 촛불은 예시 데이터**다(시안 화면에 표시). 실제 서비스로 만들면 실제로 켜진 촛불만 보여야 한다(더미 금지 규칙).
- 시련·불 줄어듦은 확인하기 쉽게 빨리 오도록 당겨 두었다.
- 확인한 것(11/8): 휴대폰 폭에서 각 단계 자동 조작 + 화면 캡처. ⏳ 실제 손가락 손맛은 확인 안 함.
