## 6. 이 세션에서 알게 된 도구 메모

- **Aside**(AI 브라우저, 오르카 옆에 열려 있음): `aside repl "…"` 로 열린 탭을 **읽기만** 할 수 있다. 순서: `listBrowserTabs()` → `attachBrowserTab(targetId)` → `page.evaluate`. `aside guide repl` 를 먼저 읽을 것. 탭을 클릭·이동하지 않는다.
- **오르카 CLI**: `…\AppData\Local\Programs\orca\resources\bin\orca.exe` — `project list`, `repo list`, `terminal list/read`, `repo add --path`. 프로젝트 = 폴더(깃 저장소).
- 셸에서 파이썬을 한 줄로 쓰면 `\` 와 한글 경로가 깨진다 → **파일로 써서(Write) 실행**. PowerShell은 `Remove-Item`·와일드카드가 안전 검사에 걸릴 수 있다.
- 커밋은 항상 `git commit -- <경로>` 로 경로 지정(공유 작업트리, `-a` 금지).
- 노트북 전체 검색은 5분을 넘긴다 → 폴더를 좁혀서.
