# 완료보고 — T-001 홈 화면 사진 히어로형

- 작성: 2026-09-05 (지시자)
- 판정: **통과 (1차)**

## 무엇이 됐나

홈 화면을 6개 진입점이 한꺼번에 쌓이던 구조에서, 사진 하나를 주인공으로
두고 나머지는 아래로 축소되는 구조로 바꿨다. 완료 조건 9개 전부 검토자가
파일·줄 번호·실제 화면으로 근거를 남기고 통과시켰다. 검토.md 참고.

## 시험 운전에서 배운 것

- **1차 개발 시도는 실패했다** — 도구 호출 없이 600초 멈춤. 원인으로
  의심되는 것: 지켜보는 사람이 없는 비동기 작업에서 "이대로 진행할까요?"
  류의 판단 지점에 멈췄을 가능성(Claude Fable 5.1 공식 가이드가 정확히 이
  실패 패턴을 설명한다). 에이전트 문서에 "혼자 일한다 — 멈추지 않는다"
  절을 추가하고 재시도하니 끝까지 실행했다.
- **`subagent_type` 에 역할 이름을 직접 못 쓴다** — `developer`·`reviewer`
  로 불렀더니 "Agent type not found". `general-purpose` 를 부르면서
  역할 문서를 읽고 따르라고 지시하는 방식으로 우회했다. 효과는 같다.
  `orchestrator.md` 에 반영해 다음부터는 바로 이 방식을 쓴다.
- **검토가 실제로 걸러낸다는 것을 확인함** — 검토자가 개발기록을 그대로
  믿지 않고 `npm run verify` 를 다시 돌리고, 화면을 다시 열고, git diff 로
  범위를 직접 대조했다. 판정 근거에 파일 경로·줄 번호가 남아 있어 지시자가
  다시 확인하기도 쉬웠다.
