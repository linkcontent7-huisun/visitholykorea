# T-001 · 홈 화면을 "사진 히어로형"으로 재구성

- 작성: 2026-09-05
- 담당: developer
- 마감: 시험 운전이므로 없음 (완료되는 대로 검토)

## 목표

지금 홈 화면은 검색창 아래로 6개의 진입점(오늘의 쉼표·붐빔피하기 배너·AI가이드
배너·코스추천·나침반CTA·가까운성지 목록)이 스크롤 한 번에 다 쌓여 있어서
사용자가 뭘 눌러야 할지 모호하다. Claude Design으로 그린 시안 중 사장님이
"사진 히어로형"을 골랐다. 이걸 `src/pages/HomePage.tsx` 에 실제로 구현한다.

**핵심 아이디어**: 오늘 소개하는 성지 사진 한 장을 화면 상단에 크게 두고,
나머지 5개 진입점은 스크롤 아래로 축소해서 이어지게 한다.

## 완료 조건

- [ ] 화면 상단(첫 화면, 스크롤 없이 보이는 영역)에 **사진이 있는 성지** 한 곳이
      큰 히어로 카드로 나온다. 사진 없는 성지가 뽑히면 안 된다
      (`image_url` 이 있는 53곳 중에서 고른다 — 어떻게 고를지는 구현 재량)
- [ ] 히어로 사진 위에 성지 이름·교구가 오버레이로 보인다. 그 성지에 오디오
      도슨트 원고가 있으면(`getDocentScript`) "오디오 가이드로 먼저 들어보기"
      CTA 를 함께 보여준다. 없으면 CTA 문구를 빼고 사진+이름만 보여준다
      (없는 기능을 있는 것처럼 보여주면 안 된다 — 더미 금지 원칙)
- [ ] 기존 "오늘의 쉼표"(TodayQuietSection) 3개 카드는 히어로 아래에서
      **한 줄 요약 리스트**로 축소된다: 이름 + 붐빔 배지만, 3줄 설명 문구는 뺀다
- [ ] 🔴 **`CrowdingBadge`가 "아주 조용" 같은 두 글자 이상 라벨에서 두 줄로
      깨지는 기존 버그를 고친다** (`white-space: nowrap` + `flex-shrink: 0`
      등으로). `src/features/quiet/components/CrowdingBadge.tsx`
- [ ] 순례 여권 미리보기(로그인 전 상태, 기존 `EmptyPassportPreview` 컴포넌트
      재사용)와 순례자 이야기 미리보기(공개 데이터 1건, `getSiteNotes` 재사용)를
      스크롤 하단부에 노출한다. **실제 데이터 훅을 그대로 쓴다** — 새 더미
      데이터를 만들지 않는다. 표시할 데이터가 없으면 그 섹션은 조용히 숨긴다
- [ ] 붐빔피하기·마음나침반 진입점은 큰 배너 대신 작은 칩 2개로 나란히
- [ ] AI 가이드 진입점은 유지하되 배치만 조정 (기능 제거 금지)
- [ ] 큰 글자 모드(`largeText`)를 존중한다 — 텍스트는 상대 단위, 기존 관례를 따른다
- [ ] `npm run verify` 통과 (타입검사·린트·테스트)
- [ ] 모바일 375px 폭에서 실제로 띄워 스크린샷으로 확인, 가로 스크롤 없음

## 범위 밖 (하지 말 것)

- 다른 화면(탐색·기록·지도·성지상세 등)은 건드리지 않는다
- 새 DB 테이블·컬럼을 추가하지 않는다 (기존 `image_url`, 기존 훅만 재사용)
- 죽어 있는 SNS 로그인 버튼을 되살리지 않는다 (별개 이슈, 의도적으로 꺼둔 상태)
- TourAPI 응답을 저장/캐시하지 않는다 (CLAUDE.md 원칙)
- 시안 2·3(카드 재설계형·여정 진입형)은 구현하지 않는다 — 1번만
