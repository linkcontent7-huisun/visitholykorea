# 디자인 시안 메모 — "사진 히어로형" 구조

Claude Design 목업으로 그린 시안 1안의 구조를 코드 없이 그대로 옮긴다.
개발자는 이 목업을 화면으로 못 보므로, 여기 적힌 순서·값을 근거로 삼는다.
실제 값은 기존 소스에서 확인한 것이고, 아래 순서만 새 배치다.

## 화면 순서 (위 → 아래)

1. **헤더** (기존 그대로) — 로고 "VISIT HOLY" · 큰글자 토글 · 언어선택 · 검색창
2. **히어로** (신규) — 사진 320px 높이, `rounded-3xl`, 하단에서 위로 어두워지는
   그라디언트 오버레이(`linear-gradient(to top, rgba(0,0,0,.75), rgba(0,0,0,0) 65%)`),
   왼쪽 하단에 흰 글씨로 "교구 · 분류" 작게 → 이름 크게(26px, extrabold) →
   반투명 알약 버튼("오디오 가이드로 먼저 들어보기" + 헤드폰 아이콘, 도슨트 있을 때만)
3. **오늘 유난히 조용한 곳** (축소) — 섹션 제목 + "더보기" 링크, 그 아래
   흰 카드 3개를 세로로 촘촘히(성지명 + 위치 한 줄 + 우측에 붐빔 배지).
   기존 3줄 이유 문구는 뺀다. 배지는 `white-space: nowrap` 필수
4. **순례 여권 미리보기** — 흰 카드. 좌측 "순례 여권" + 부제, 우측 "가입하고
   첫 도장 찍기" 알약 버튼. 아래에 회색 점선 원(도장 자리) 2~3개 + "0 / 208"
5. **순례자 이야기 미리보기** — 흰 카드, 좌측 정사각 사진(72px) + 우측에
   "순례자 이야기" 라벨 + 방문자 한 줄 인용 + 날짜
6. **보조 진입 칩 2개** — "붐빔피하기"/"마음나침반"을 나란히, 각각 아이콘 +
   두 줄 라벨의 정사각형에 가까운 카드
7. **AI 가이드 배너** — 기존 그대로 유지 (색만 맞으면 위치는 6번 아래든 어디든
   개발자 재량)
8. **하단 탭바** (기존 그대로)

## 색·톤 (기존 `globals.css` 값)

- `--color-brand-blue: #1e3a8a` / `--color-brand-violet: #7c3aed`
- `--color-app-bg: #f8f9fa` / `--color-app-text: #1a1a1a` / `--color-app-text-muted: #495057`
- 카드: `bg-white`, `border border-app-border`, 라운드는 기존 관례(`rounded-[20px]`
  ~ `rounded-[24px]`) 따른다
- 배지 색은 `CrowdingBadge.tsx` 의 기존 5단계 그대로 (건드리지 않는다, nowrap 만 추가)

## 왜 이 순서인가

- 정보 밀도는 유지하되(3안처럼 텍스트를 다 빼지 않는다), "무엇을 먼저 볼지"를
  사진 하나로 명확히 한다
- 순례 여권·순례자 이야기를 로그인 화면 밖으로 꺼내는 것은 가입 유도 장치다
  (수요조사 근거: 성지 해설 니즈 1위 60%, 스탬프=실방문 인증 구조 참고)
- "지금 안 하면 놓친다" 식 문구는 쓰지 않는다 — 순례·기도 공간의 톤을 지킨다
