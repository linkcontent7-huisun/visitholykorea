### 참고 (판정에는 영향 없음, 기록으로 남김)

- **큰 글자 모드와 `text-[Npx]` 방식의 관계**: 이 프로젝트의 큰 글자 모드는
  `html[data-text-size='lg'] { font-size: 118% }` 로 루트 글자 크기를 키우는
  방식이라, `rem` 단위라야 실제로 커진다. 그런데 이번 변경(`HomePage.tsx` 등)은
  `text-[13px]` 같은 고정 px 방식을 쓰고 있다. 이건 **이번 작업이 새로 만든
  문제가 아니다** — 같은 방식이 기존 코드베이스 전역에 101곳 넘게 이미 있고,
  지시서도 "기존 관례를 따른다"고 명시했다. 실측으로도 큰글자 모드를 켰을 때
  레이아웃이 깨지거나 가로 스크롤이 생기지는 않았다(완료 조건은 만족). 다만
  텍스트 자체의 확대 폭이 rem 기반 요소보다 작을 수 있다는 것은 프로젝트
  전체의 별도 과제로 남겨 둔다 — T-001 범위 밖.
