같은 인증키(`.env.local` 의 `VITE_TOUR_API_SERVICE_KEY`)로 전부 호출한다. 기본 URL `https://apis.data.go.kr/B551011/<서비스>/<오퍼레이션>`,

## 만들 것

### A. 외국어 화면의 주변 관광정보를 그 언어로 (프·스 — 영어는 승인되면)

- `tour-api.ts` 의 BASE_URL 을 언어별로 고르는 함수 `serviceFor(language)`: `fr→FreService2`, `es→SpnService2`, 그 외(ko·en·pt·it) → `KorService2`. 러시아어는 앱 언어가 아니므로 넣지 않는다.
  (영어 EngService2 는 아직 미신청 — 승인되면 `en→EngService2` 한 줄만 추가)
- `getNearbyByLocation`·`getNearbyAttractions`·`searchAttractionsByKeyword`·`getNearbyFestivals` 가 `language` 인자를 받아 그 서비스로 부른다. 오퍼레이션 이름은 같다(`locationBasedList2` 등)
- 호출부(`use-nearby-tour.ts` 등)는 `useSettings().language` 를 넘긴다. 쿼리 키에 language 포함
- 외국어 서비스는 데이터가 국문보다 적다 → 결과 0이면 KorService2 로 한 번 더(폴백), 화면에는 "한국어 정보" 표시 없이 그대로

### B. 붐빔 지수를 실제 「관광지 집중률」로 (오버투어리즘 — 공모전 핵심)

- `src/shared/api/tour-api.ts` 에 `getCongestionRates(areaCd, signguCd)` → `TatsCnctrRateService/tatsCnctrRatedList` (numOfRows 200)
- `src/features/quiet/api/crowding-score.ts` 의 추정 산식에 **실측 항목** 추가: 성지 반경 `RADIUS_KM.festival`(15km) 안의 집중률 관광지 중 가장 높은 `cnctrRate` 를 `real` 점수로 (0~100 그대로). 실측이 있으면 `real` 이 총점의 60%, 기존 추정(축제·인프라)이 40%. 실측이 없으면 지금처럼
- `CrowdingScore` 에 `source: 'measured' | 'estimated'` 와 `measuredSpot?: { name, rate }` 추가. `CrowdingBadge` 는 실측이면 「실측 집중률 49% · 간송미술관」처럼 근거를 보여주고, 기존 「추정」 문구는 estimated 일 때만
- 집중률 조회는 시군구당 하루 1번이면 충분 → staleTime 6시간 (저장은 안 함, 메모리 캐시만)
- `crowding-score.test.ts` 에 실측 혼합 테스트 3개

### C. 성지 상세 「함께 가는 곳」 — 연관 관광지·지역 중심 관광지

- `getRelatedSpots(areaCd, signguCd, baseYm)` (TarRlteTarService1) 와 `getHubSpots(areaCd, signguCd, baseYm)` (LocgoHubTarService1). baseYm 은 지난달(YYYYMM)
- 성지 상세 「주변」 절 아래 작은 카드 줄 「이 지역 사람들이 함께 가는 곳」 — hubRank 순 5개, 이름·분류·거리(성지 좌표에서 haversine). 결과 없으면 절 자체를 안 그린다
- 6개 국어 키 `siteHubSpotsTitle` 등

### D. 관광지 오디오 가이드(Odii) — 성지 도슨트 옆에 「주변 관광지 이야기」

- `getAudioStoriesNearby(lat, lng, langCode)` → `Odii/storyLocationBasedList?mapX&mapY&radius=3000&langCode=` (문서 확인; 없으면 `themeLocationBasedList` 로 테마 → `storyBasedList?tid=` 2단계)
- 성지 상세 도슨트 아래 「주변 관광지 오디오 이야기」 접이식 — 제목·1문장·▶ 재생(`audioUrl` 이 있으면 `<audio>`). 우리 도슨트와 섞이지 않게 「한국관광공사 제공」 표기
- 언어: ko/en/ja/zh 만 제공 → 한국어 화면은 ko, 그 외는 en

### E. 두루누비 — 성지 근처 걷기길

- `getWalkingCoursesNear(lat,lng)` — `Durunubi/courseList` 는 위치 검색이 없을 수 있음 → 시군구 이름(`sigunguNm`)으로 필터하거나 전체 목록을 받아 좌표(`gpxpath`/시작점)로 거리 계산. 문서 확인 후 가능한 쪽으로
- 순례 코스 상세(`RouteDetailPage`)와 성지 상세에 「이 근처 걷기길」 최대 3개 — 이름·거리·소요시간·두루누비 링크
