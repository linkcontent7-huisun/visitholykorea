# T-017 개발기록

## 시작 상태

- 2026-09-13 작업 시작 전에 `git status --short`를 확인했다. `.claude/settings.local.json`, 카카오톡 이미지, HTML 파일, `movie/`는 기존 미추적 파일이어서 건드리지 않았다.

## 구현

- 여러 장 사진 테이블·RLS·기존 `photo_url` 복사·공개 후기 뷰·관리자 사진별 대표 승인 RPC를 `20260913110000_add_stamp_photos.sql`에 작성했다. 기존 대표 사진 칼럼은 삭제하지 않아 이전 화면 호환성을 유지한다.
- 모바일 5장/PC 10장 정책과 압축 옵션을 추가하고, 성지 상세·내 기록에서 여러 장 선택·미리보기·삭제를 연결했다. 공개 후기는 접힌 상태에서 최신 6개를 보이고, 모두 보기에서 제한 없이 다시 조회한다.
- 관리자 승인함은 `photo_id`로 대표 사진을 정하게 바꿔 한 스탬프의 여러 사진을 개별 승인할 수 있게 했다. 번역 사전에 사진 수·공개·운영 검토·후기 표시 문구 6개 언어를 추가했다.

## 확인 결과

- 변경 직후 `npm.cmd run typecheck`는 통과했다.
- 이후 다시 실행한 `npm.cmd run typecheck`는 통과했고 `npm.cmd run verify`도 타입 검사와 lint(기존 fast-refresh 경고 2건)는 통과했다. 다만 Vitest 시작 단계가 이 환경에서 `vite.config.ts` 접근 거부로 실패해 테스트는 실행되지 못했다.
- T-017 변경 파일에 대한 `git diff --check`는 오류가 없었다. 로컬 개발 서버 화면 확인과 데이터베이스 마이그레이션 적용은 지시서에 따라 실행하지 않았다.
