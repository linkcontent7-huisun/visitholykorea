   를 반복시켜야 했다(`--resume` 은 엉뚱한 최신 스레드를 이어서 못 씀). `--write` 를 빼면 읽기 전용 샌드박스라
   파일을 못 쓴다.
3. **속도 ≈ 20곳 / 6분.** 후반에는 "번역 중"이라고 하고 0곳을 저장하는 턴이 나왔다. 100곳 남은 시점(02:37)에

4. 검사기(`npm run translate:check`)는 Codex 환경에서 `tsx` 가 `ENOMEM` 으로 죽는다. Codex 에게는 JSON.parse 만
   시키고 검사는 밖에서 돌린다.
