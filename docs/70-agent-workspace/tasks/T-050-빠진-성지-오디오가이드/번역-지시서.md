# T-050 번역 — 검증 끝난 원고를 스페인어·이탈리아어·포르투갈어·프랑스어로 (Codex)

원고: `data/research/missing-sites/docent/<cbckCode>.json` — 한국어·영어는 Claude·Codex 검증이 끝난 상태다.
기준: `docs/00-overview/가이드/다국어-번역-작업-지침.md` 3장. T-029 와 같은 규칙이다.

## 할 일 — 이번에 맡은 한 곳만

1. **영어본을 원문으로 번역만 한다.** 사실·순서·문장 수 그대로. 한국어·영어 필드는 손대지 않는다.
2. 채울 필드(언어별 접미사 `Es`·`It`·`Pt`·`Fr`):
   `intro.narration<Xx>`, `points[].title<Xx>`·`narration<Xx>`·`lookFor<Xx>`(영어가 null 이면 null)·`forEveryone<Xx>`(영어 필드가 없으면 한국어 `forEveryone` 을 번역, null 이면 null), `outro.narration<Xx>`.
   **한 곳·한 언어는 전부 채우거나 전부 비운다.**
3. 안내자 구어체 존댓말(usted / Lei / você / vous).
4. 지명·인명 로마자는 영어본 그대로(Meokguni, Sinsi Island → Isla Sinsi 처럼 보통명사만 옮김). 세례명만 그 언어 관용: Andrew→Andrés/Andrea/André/André, Thomas→Tomás/Tommaso/Tomé/Thomas, John→Juan/Giovanni/João/Jean, Francis→Francisco/Francesco/Francisco/François, Paul→Pablo/Paolo/Paulo/Paul, Anna 그대로, Pius→Pío/Pio/Pio/Pie, Ignatius→Ignacio/Ignazio/Inácio/Ignace, Ursula 그대로(fr Ursule), Magdalene→Magdalena/Maddalena/Madalena/Madeleine. `Kim Dae-geon` 금지.
5. 연도·숫자는 하나도 빠뜨리지 않는다. 한글이 섞이거나 영어 문장이 그대로 남으면 실패.
6. **번역은 네가 직접 쓴다.** Ollama 등 로컬 모델·외부 번역 API·자동 번역 스크립트 금지.
