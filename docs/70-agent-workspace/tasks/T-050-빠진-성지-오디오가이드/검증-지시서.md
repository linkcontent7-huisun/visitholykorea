# T-050 검증 — Claude 가 쓴 오디오 가이드 원고를 사본과 대조한다 (Codex)

원고: `data/research/missing-sites/docent/<cbckCode>.json` (한국어 `narration`·`lookFor`·`forEveryone` + 영어 `…En`)
근거: `data/research/missing-sites/_pages/<cbckCode>/*.txt` 사본뿐. 각 지점 `sourceNote` 에 어느 사본을 봤는지 적혀 있다.
**인터넷을 쓰지 않는다. 기억·상식으로 판정하지 않는다.** 사본에 없으면 `근거없음` 이다.

## 할 일 — 이번에 맡은 한 곳만

1. 한국어 문장을 **하나도 빠짐없이** 본다: 여는 말, 지점마다 `narration`·`lookFor`·`forEveryone`, 맺음말.
   문장은 마침표·물음표·느낌표 뒤 공백으로 나눈다. `text` 에는 원고 문장을 **글자 그대로** 복사한다 (검사기가 글자로 맞춘다).
   - `근거있음`: 사본에 같은 사실이 있다. `evidence` 에 사본 원문을 짧게 인용하고 파일 이름을 적는다.
   - `근거없음`: 사본에서 찾을 수 없다. `fix` 에 고친 문장(사본 범위로 줄인 것) 또는 `"삭제"`.
   - `틀림`: 사본과 다르다(연도·숫자·이름·순서). `fix` 에 바로잡은 문장.
   - 여러 사본이 서로 다르면 `틀림` 이 아니라 `근거있음` + `evidence` 에 두 사본을 모두 적고 `note` 에 "사본끼리 다름".
2. 영어를 한국어와 대조한다: 여는 말, 지점마다(제목+본문+lookFor), 맺음말 — `part` 는 `intro`·`point1`…·`outro`.
   - `일치`: 뜻이 같다. 한국어에 없는 사실이 영어에 붙었거나 빠졌으면 `어긋남` + `fix` 에 고친 영어.
   - 성인 이름 표기: Andrew Kim Taegon (`Kim Dae-geon` 금지), Thomas Choe Yang-eop.
3. `siteVerdict`: 고칠 것이 하나도 없으면 `OK`, 하나라도 있으면 `고칠것`.
