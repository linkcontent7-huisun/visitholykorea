# T-013 — 제출판 숨김 플래그 (관리자 콘솔·즐겨찾기·여행기 작성)

작성 2026-09-12 · 담당 Codex · 지시자 Claude

## 목표

한국관광공사 공모전 제출판에서는 **순례자의 본질 기능만** 보이게 한다. 관리자 콘솔·즐겨찾기·
여행기 작성은 코드는 그대로 두고, 환경 변수 하나로 **입구만 숨긴다**. 제출 뒤 값 하나 바꾸면
다시 나온다. 삭제가 아니다 — 사장님이 사진 교체에 관리자 콘솔을 계속 쓴다.

## 해야 할 일

### 1. 플래그 한 곳

`src/shared/lib/feature-flags.ts` 를 새로 만든다.

```ts
/**
 * 제출판 모드. true 면 관리자 콘솔·즐겨찾기·여행기 작성 입구를 숨긴다.
 * 기능 코드는 그대로 남는다 — 심사 화면을 본질 기능으로만 좁히기 위한 스위치다.
 * Vercel 환경 변수 VITE_SUBMISSION_MODE=true 로 켠다. 없으면 false (개발 중엔 다 보인다).
 */
export const SUBMISSION_MODE = import.meta.env.VITE_SUBMISSION_MODE === 'true';
```

`src/shared/types/env.d.ts` 에 `readonly VITE_SUBMISSION_MODE?: string;` 을 추가한다.
`.env.example` 에 주석과 함께 `VITE_SUBMISSION_MODE=""` 줄을 추가한다 (`.env.local` 은 건드리지 않는다).

### 2. 숨길 입구 (정확히 이 다섯 곳만)

| 어디 | 무엇 | 어떻게 |
| --- | --- | --- |
| `src/pages/MenuPage.tsx` 약 324행 | 「관리자 콘솔」 버튼 | `canEnterAdmin && !SUBMISSION_MODE` |
| `src/app/routes/router.tsx` | `/admin`, `/admin/sites/:siteId` 라우트 | `SUBMISSION_MODE` 면 두 라우트를 등록하지 않는다 (`...(SUBMISSION_MODE ? [] : [ ... ])`) → 직접 주소를 쳐도 404 |
| `src/pages/SiteDetailPage.tsx` 약 332행 | 하트(즐겨찾기) 버튼 | `SUBMISSION_MODE` 면 버튼을 그리지 않는다 |
| `src/pages/ExplorePage.tsx` 약 58~70행 | 「즐겨찾기」 절 | `SUBMISSION_MODE` 면 절을 그리지 않는다 (훅 호출은 그대로 둬도 됨) |
| `src/pages/RecordsPage.tsx` 약 196행 | 여행기 쓰기(`LogComposer`) 버튼·작성 화면 | `SUBMISSION_MODE` 면 쓰기 버튼을 그리지 않는다. 이미 쓴 여행기 **읽기는 그대로** |

주석은 한국어로, "왜"를 남긴다 (예: `// 제출판: 본질 기능만 보이게 — T-013`).

## 완료 조건 (각각 어떻게 확인하는지)

1. `VITE_SUBMISSION_MODE=true npm run build` 뒤 `npx vite preview --port 4173` 로 띄워
   헤드리스 크롬으로 확인 → 개발기록에 결과를 적는다:
   - `/menu` 에 「관리자 콘솔」 버튼 없음 (관리자 계정 로그인이 안 되면 "로그인 없이 확인, 코드 조건으로 판단" 이라고 적는다)
   - `/admin` 이 404 화면(`NotFoundPage`)
   - 성지 상세에 하트 버튼 없음, `/explore` 에 즐겨찾기 절 없음, `/records` 에 쓰기 버튼 없음
2. 플래그 없이(`npm run dev`) 위 다섯 곳이 **모두 예전처럼 보인다** → 스크린샷 1장 이상
3. `npm run verify` 통과 → 마지막 10줄
4. 바꾼 파일 목록을 개발기록에 표로

## 범위 밖 — 하지 말 것

- 기능 코드·훅·테이블·마이그레이션 삭제 금지. 숨기기만 한다
- 홈 화면·탭·상단바는 건드리지 않는다 (지시자가 따로 작업 중)
- 쉼터·축제·붐빔 피하기·AI 가이드는 이 작업의 대상이 아니다
- `git add / commit / push / checkout / reset / stash / clean` 금지 — 지시자가 커밋한다
- `.env.local` 을 읽거나 쓰지 않는다. Vercel 환경 변수는 사장님이 넣는다
