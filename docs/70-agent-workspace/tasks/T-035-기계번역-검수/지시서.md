# T-035 — 성지 이름·소개·역사의 es·fr·pt·it 기계 번역을 **읽고** 이상한 것만 골라낸다

작성 2026-09-21 05:10 · 담당: Codex (이 문서만 보고 일한다) · 결과 반영: Claude

## 왜

`holy_site_translations` 의 es·fr·pt·it 206곳은 `translation_status = machine`(사람 감수 전)이다.
검사기(`npm run translate:check`)는 빈 칸·영어 복사·한글·연도 누락만 잡고, **뜻이 틀린 문장·잘못된 용어·어색한 문장은 못 잡는다.**
824건을 사람이 다 읽을 수 없으니, 네가 읽고 **고쳐야 할 것만** 목록으로 만든다.

## 입력

`data/translations/{es,fr,pt,it}-all.todo.json` — 언어당 206항목. 각 항목:

```json
{ "siteId": "…", "diocese": "대전",
  "source":   { "name": "한국어 이름", "description": "한국어 소개", "history": "한국어 역사", "location": "…" },
  "sourceEn": { "name": "검수된 영어 이름", "description": "영어 소개", "history": "영어 역사", "addressRomanized": "…" },
  "target":   { "name": "번역 이름", "description": "번역 소개", "history": "번역 역사", "addressRomanized": "…" } }
```

`target` 이 검수 대상이다. 기준은 **한국어 원문(source)** 이고, `sourceEn` 은 로마자 표기의 기준이다.

## 무엇을 잡나 (이것만)

| 표시 | 뜻 | 예 |
| --- | --- | --- |
| `[뜻 다름]` | 원문과 내용이 다르거나 사실이 바뀜 — 인물·연도·장소·사건이 원문과 불일치 | 원문 "1866년 순교" → 번역 "1886" · 원문 "다블뤼 주교" → 번역이 다른 사람 |
| `[빠짐]` | 원문에 있는 문장·사실이 번역에 없음 (한두 낱말이 아니라 문장 단위) | 원문 3문장, 번역 2문장 |
| `[덧붙임]` | 원문에 없는 내용이 번역에 생김 | 원문에 없는 "매년 축제가 열린다" |
| `[용어]` | 로마자 표기가 `sourceEn` 과 다름, 성인 세례명 관용 표기 틀림, 미카엘 이름 틀림 | Galmaemot 를 Galmaemos 로 · es 에서 Andrew 를 Andrea 로 · fr 에서 Miguel |
| `[어색]` | 그 언어 화자가 읽기 불편한 문장 — 기계 번역 티가 심한 것만. 취향은 적지 않는다 | 영어 어순 그대로, 관사 오류가 문장마다 |

**잡지 않는 것:** 문체 취향, 더 나은 표현 제안, 주소(`addressRomanized` 는 영어 값 그대로가 맞다), 한국어 원문 자체의 오류(그건 따로 적는다 — 아래 「원문 의심」).

## 어떻게

1. 언어 하나씩, 항목을 **순서대로** 읽는다. 항목마다 `source.name/description/history` 와 `target` 을 대조한다.
2. 문제가 있으면 아래 형식으로 결과 파일에 **바로 추가**한다(한 번에 모아 쓰지 말 것 — 중간에 끊겨도 남게).
3. 한 언어가 끝나면 그 언어의 요약 줄(읽은 수 · 문제 수 · 종류별 수)을 적는다.
4. 네 언어가 끝나면 맨 위 요약 표를 채운다.

## 결과 파일 — `docs/70-agent-workspace/tasks/T-035-기계번역-검수/검수결과.md`

```markdown
# T-035 검수결과 — (시작 시각) ~ (끝 시각)

## 요약
| 언어 | 읽은 항목 | 문제 항목 | 뜻 다름 | 빠짐 | 덧붙임 | 용어 | 어색 |
| es | 206 | … |

## es
| # | 성지 (siteId 앞 8자) | 칸 | 표시 | 무엇이 문제인가 (원문 ↔ 번역, 한 줄) | 고친 문장 제안 |
| 1 | 갈매못 순교성지 (4877a452) | history | 뜻 다름 | 원문 "1866년" ↔ 번역 "1886" | …1866… |

## 원문 의심 (한국어 source 자체가 이상한 것)
| 성지 | 칸 | 무엇 |
```

「고친 문장 제안」은 **그 언어로** 문장 전체를 쓴다 — Claude 가 그대로 DB 에 넣을 수 있게.

## 완료 조건

- 네 언어 × 206항목 = 824항목을 **전부** 읽었다(요약 표의 「읽은 항목」이 206·206·206·206).
- 문제가 없는 항목은 적지 않는다. 문제 0이면 "문제 없음"이라고 그 언어 절에 적는다.
- 결과 파일이 위 형식이고, 표의 「고친 문장 제안」이 비어 있지 않다(어색 은 비워도 됨).

## 범위 밖 (하지 말 것)

- **JSON 파일이나 DB 를 고치지 않는다.** 읽고 적기만 한다.
- 번역을 새로 만들지 않는다 — 문제 있는 문장의 고친 제안만.
- 로컬 모델(Ollama·hermes 등)·외부 번역 API·자동 번역 스크립트 금지. **네가 직접 읽는다.**
- `tsx`·`npm run` 실행 금지(이 환경에서 ENOMEM). 파일은 `JSON.parse` 로만 읽는다.
- 한 언어 안에서 20항목마다 결과 파일을 저장하고 이어 간다. 3번 연속 진전이 없으면 멈추고 어디까지 했는지 적는다.
