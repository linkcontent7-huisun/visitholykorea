# T-012 — px 로 못 박힌 작은 글자를 rem 으로 바꾼다

작성 2026-09-12 · 담당 Codex · 지시자 Claude

## 목표

글자 크기 소·중·대(`html[data-text-size]`, 2026-09-12 도입)를 골랐을 때 **모든 글자가 같은 비율로**
커지게 한다. 지금은 `text-[10px]` 처럼 px 로 못 박힌 글자 158곳(29개 파일)이 따라오지 않아
「대」에서 제목만 커지고 부제·설명은 그대로라 편차가 심하다.

## 해야 할 일

`src/**/*.tsx` 안의 아래 클래스를 **아래 치환표대로만** 바꾼다. 16px = 1rem.

| 지금 | 바꿀 것 | 곳 수(9/12 실측) |
| --- | --- | --- |
| `text-[9px]` | `text-[0.5625rem]` | 13 |
| `text-[10px]` | `text-[0.625rem]` | 50 |
| `text-[11px]` | `text-[0.6875rem]` | 58 |
| `text-[12px]` | `text-[0.75rem]` | 26 |
| `text-[13px]` | `text-[0.8125rem]` | 11 |

**바꾸지 말 것 (예외)** — 아래 파일은 화면의 "틀"이라 px 로 고정하는 것이 의도다.
- `src/app/layouts/TopNav.tsx` — 상단바 (2026-09-12 에 일부러 px 로 고정)
- `src/app/layouts/BottomNav.tsx` — 하단 탭
- `src/shared/i18n/TextSizePicker.tsx`, `src/shared/i18n/LanguagePicker.tsx`
- `src/pages/AdminPage.tsx`, `src/pages/AdminSitePage.tsx` — 관리자 화면(순례자용 아님)
- 테스트 파일(`*.test.tsx`)에 문자열로 들어 있는 클래스

## 완료 조건 (각각 어떻게 확인하는지)

1. 예외 파일을 뺀 나머지에서 `grep -rE "text-\[(9|10|11|12|13)px\]" src --include=*.tsx` 결과가
   **예외 파일 것만** 남는다 → 명령 출력을 개발기록에 붙인다.
2. `npm run verify` 통과 → 마지막 10줄을 개발기록에 붙인다.
3. `npm run dev` 로 띄운 뒤 헤드리스 크롬으로 홈·성지 상세를 **소와 대** 두 상태에서 찍어
   개발기록 폴더에 png 로 남긴다(`대` 는 `localStorage.setItem('vhk_text_size','lg')` 후 새로고침).
   대 에서 부제·설명 글자도 함께 커졌는지 눈으로 확인했다고 적는다.
4. 바꾼 파일 목록과 곳 수를 개발기록에 표로 적는다.

## 범위 밖 — 하지 말 것

- `px-[...]`, `h-[...]`, `w-[...]`, `gap-[...]` 등 **글자 크기가 아닌** px 값은 건드리지 않는다
- `text-sm`, `text-lg` 같은 Tailwind 기본 크기는 이미 rem 이다 — 손대지 않는다
- 문구·색·간격·구조를 바꾸지 않는다. 치환표에 없는 값(`text-[14px]` 등)은 그대로 둔다
- `git add / commit / push / checkout / reset / stash / clean` 금지 — 지시자가 커밋한다
- `.env.local` 을 읽거나 쓰지 않는다
