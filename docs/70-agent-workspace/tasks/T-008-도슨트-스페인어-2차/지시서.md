# T-008 — 도슨트 원고 스페인어 2차 (3곳)

작성 2026-09-06 · 담당 **Codex** · 앞선 작업 T-005(명동·절두산·전동성당) 완료

## 목표

**서소문 밖 네거리 순교성지 · 새남터순교성지 · 해미순교성지** 세 곳의 도슨트 원고에
스페인어를 넣는다. 세 곳 모두 이미 영어(`En`)가 다 들어 있으므로, 그것과 짝이 되는
`Es` 칸을 채우는 일이다.

## 왜 이 세 곳인가

WYD 2027 주최 언어가 스페인어다. 서소문은 한국 최대 순교터이고, 새남터는 김대건
신부가 순교한 곳이며, 해미는 교황 방문지라 해외 순례단이 실제로 가장 많이 찾는다.

## 고칠 파일 — 이 세 개만 만진다

```
data/docent/서소문-밖-네거리-순교성지.json
data/docent/새남터순교성지.json
data/docent/해미순교성지.json
```

## 완료 조건 — 각 항목을 어떻게 확인하는지까지

1. **세 파일이 여전히 올바른 JSON 이다.**
   확인: `node -e "JSON.parse(require('fs').readFileSync('data/docent/새남터순교성지.json','utf8'))"`
   세 파일 각각에 대해 돌려 오류가 없어야 한다.

2. **`En` 이 있는 자리마다 `Es` 가 하나씩 있다.** 개수가 정확히 같아야 한다.
   확인: 각 파일에서 아래 네 쌍의 개수를 세어 좌우가 같은지 본다.
   - `narrationEn` ↔ `narrationEs`
   - `titleEn` ↔ `titleEs`
   - `locationEn` ↔ `locationEs`
   - `lookForEn` ↔ `lookForEs`

   현재 `narrationEn` 개수는 서소문 7 · 새남터 6 · 해미 7 이다.
   (`intro` 와 `outro` 의 `narration` 도 포함한 수다 — 빠뜨리지 말 것.)

3. **`Es` 값 안에 한글이 한 글자도 없다.**
   확인: `grep -o '"[a-zA-Z]*Es": "[^"]*"' <파일> | grep -P '[가-힣]'` 가 아무것도
   출력하지 않아야 한다.

4. **한국어 원본(`narration`, `title`, `location`, `lookFor`)과 영어(`En`)는
   한 글자도 바뀌지 않았다.**
   확인: `git diff` 에서 `-` 로 지워진 줄이 하나도 없어야 한다. 추가(`+`)만 있어야 한다.

5. **`npm run verify` 가 통과한다.** (타입 검사 · 린트 · 테스트 334개)

## 번역할 때 지킬 것

- **한국어 원본을 번역한다.** 영어를 다시 번역하면 뜻이 두 번 흔들린다.
  영어는 "이 자리에 무엇이 들어가는지" 참고용으로만 본다.
- 성인·복자 이름은 스페인어권 가톨릭 표기를 쓴다
  (예: 김대건 안드레아 → `San Andrés Kim Taegon`, 정하상 바오로 → `San Pablo Chong Hasang`).
- **낭독용 원고다.** 귀로 듣는 글이므로 문장을 짧게 끊고, 괄호와 각주를 쓰지 않는다.
- 지명은 로마자 표기 뒤에 필요하면 짧은 설명을 붙인다
  (예: `Seosomun`, `la Puerta Oeste de la antigua Seúl`).
- 길이는 한국어 원문과 비슷하게. 요약하거나 늘리지 않는다.
