# T-008 개발기록

작성일: 2026-09-07

## 작업 전 상태

`git status --short`로 확인했다. `.claude/agent-memory/`와 작업 범위 밖의 두 파일은 이미
다른 작업에서 수정된 상태였으며, 이 작업에서는 건드리지 않았다.

## 수행 내용

- `data/docent/서소문-밖-네거리-순교성지.json`
- `data/docent/새남터순교성지.json`
- `data/docent/해미순교성지.json`

세 원고의 한국어 `narration`, `title`, `location`, `lookFor`를 기준으로 각각 짝이 되는
스페인어 `Es` 필드를 추가했다. 낭독할 때 자연스럽도록 존댓말 문장으로 옮기고, 성인명은
스페인어권 가톨릭 표기를 사용했다.

## 완료 조건 확인

1. JSON 형식

   `node -e`로 세 파일을 각각 `JSON.parse(require('fs').readFileSync(..., 'utf8'))` 하도록
   실행했다. 오류 없이 모두 읽혔다.

2. 영어와 스페인어 필드 개수

   Node 검사 결과는 다음과 같다.

   | 파일 | narration En/Es | title En/Es | location En/Es | lookFor En/Es |
   | --- | --- | --- | --- | --- |
   | 서소문 | 7/7 | 5/5 | 5/5 | 5/5 |
   | 새남터 | 6/6 | 4/4 | 4/4 | 4/4 |
   | 해미 | 7/7 | 5/5 | 5/5 | 5/5 |

3. Es 값의 한글 여부

   세 파일을 순회하며 `Es`로 끝나는 모든 값에 `[가-힣]`이 있는지 검사했다. 세 파일 모두
   `Es 한글 없음`으로 확인됐다.

4. 원문과 영어의 보존

   `git diff --check`은 출력 없이 통과했다. 대상 세 파일의
   `git diff --numstat` 결과는 새남터 `18/0`, 서소문 `22/0`, 해미 `22/0`으로, 총 62줄을
   추가하고 삭제는 0줄이었다. `git diff --unified=0`에서도 추가 줄만 확인됐다.

5. 전체 검증

   `npm run verify`를 실행했다. 이 실행 환경은 명령 한 번에 약 60초 제한이 있어
   `typecheck` 단계 출력 뒤에 세션이 종료되어 lint와 334개 테스트까지의 완료 결과를
   얻지 못했다. 같은 이유로 `npm run typecheck` 단독 실행도 제한 안에 완료 결과를 반환하지
   못했다. 로컬 개발 환경에서 `npm run verify`를 한 번 끝까지 실행해 최종 확인이 필요하다.
