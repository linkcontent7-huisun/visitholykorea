# T-048 2차 검증 — 조사 결과를 **처음 보는 눈으로** 다시 확인한다

작성 2026-09-28 · 검증: Codex (이 문서만 보고 일한다) · 반영: Claude · 결정: 사장님

## 왜

`data/research/trails/<slug>.json` 10개는 1차 조사 결과다(7곳 Codex, 3곳 Claude — andong·suwon·boryeong).
사장님께 「코스로 올림 / 링크만 / 제외」 추천을 올리기 전에, 같은 내용을 한 번 더 확인해 틀린 것을 걸러낸다.
**네 일은 1차 결과를 믿지 않고 공식 페이지와 대조하는 것이다.** 맞다고 적으려면 공식 페이지에서 직접 본 근거가 있어야 한다.

## 입력

- `data/research/trails/<slug>.json` — 검증할 1차 결과
- `data/research/trails/_verify/matches.json` — 「공식 경유지 ↔ 우리 앱 성지」 자동 대조 52쌍 (이 slug 것만 본다)
- `data/research/trails/_verify/our-sites.json` — 우리 앱 성지 206곳의 이름·교구·주소

## 한 번 실행에 slug 하나. 결과: `data/research/trails/_verify/<slug>.verify.json`

```json
{
  "slug": "jeonju-gyouchon",
  "pageOpened": true,
  "openNote": "curl -A Mozilla/5.0 으로 열림",
  "checks": [
    { "item": "courses[0].name", "research": "요안루갈다길", "verdict": "일치", "official": "요안루갈다길", "note": "" },
    { "item": "courses[0].stops[1].name", "research": "전주숲정이성지", "verdict": "일치", "official": "전주숲정이성지", "note": "" },
    { "item": "courses[0].distanceKm", "research": null, "verdict": "확인불가", "official": null, "note": "페이지에 거리 없음" }
  ],
  "missing": ["1차 결과에 빠진 코스·경유지가 공식 페이지에 있으면 한 줄씩"],
  "matchReview": [
    { "stop": "초남이성지", "ourSite": "초남이 성지", "verdict": "맞음", "reason": "같은 완주군 이서면, 유항검 생가터" }
  ],
  "recommendationComment": "코스로 올릴 만한지에 대한 네 의견 한두 문장 (근거: 겹치는 성지 수·거리·상시 개방 여부)"
}
```

- `checks` 는 1차 결과의 **모든 코스 이름·거리·시간과 모든 경유지 이름**을 한 줄씩 다룬다. 빠뜨리면 검사기가 떨어뜨린다.
- `verdict`: `일치` · `불일치`(official 에 공식 표기를 적는다) · `확인불가`(페이지에 없거나 안 열림)
- `matchReview` 는 matches.json 에서 이 slug 의 **모든 쌍**을 다룬다. `verdict`: `맞음` · `틀림`(이름만 같고 다른 곳) · `애매`. 판단 근거는 our-sites.json 의 교구·주소와 공식 페이지의 지역.
- 공식 페이지: **인터넷으로 열지 말고 `data/research/trails/_pages/<slug>/` 의 사본을 읽는다.**
  `N.txt` 는 1차 결과 `sources[N]` 을 Claude 가 2026-09-29 에 받아 태그만 벗긴 본문, `N.html` 은 원본이다.
  (9/28 첫 실행에서 Codex 작업 환경은 인터넷이 막혀 7곳 모두 `확인불가` 로 끝났다 — 그래서 사본을 둔다.)
  사본을 읽었으면 `pageOpened: true`, `openNote` 에 "9/29 사본(_pages) 대조" 라고 적는다.
  사본에 없는 내용은 `확인불가`. **사본 밖의 다른 사이트로 대체하지 않는다.**

## 지킬 것 (범위 밖)

- 서브에이전트·스킬 탐색·계획서 금지. 직접 순서대로.
- 근거는 1차 결과 `sources` 의 공식 페이지뿐. 블로그·뉴스·위키 금지.
- 1차 결과 파일(`data/research/trails/<slug>.json`)을 **고치지 않는다.** 네 판정은 verify 파일에만.
- DB·`src/`·`supabase/` 수정 금지. 로컬 모델·외부 AI API 금지.
