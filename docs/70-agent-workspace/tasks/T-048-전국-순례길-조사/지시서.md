## 왜

(가) 경유지까지 우리 코스로 올릴 수 있는지, (나) 공식 링크만 걸 수 있는지, (다) 뺄지를 사람이 판단할 재료를 만든다.

**이 작업은 조사만 한다. DB·앱 코드는 절대 건드리지 않는다.** (공모전 심사 기간이라 배포본이 바뀌면 안 된다.)

## 결과 파일

`data/research/trails/<slug>.json` 하나를 쓴다. 형식:

```json
{
  "slug": "hanti-gil",
  "name": "한티가는길",
  "operator": "천주교 대구대교구",
  "operatorType": "diocese",
  "region": "경북 칠곡",
  "officialUrl": "https://hantigil.or.kr/index",
  "urlWorks": true,
  "summary": "공식 페이지 내용을 네 말로 2문장 이내 요약. 문장을 베끼지 않는다.",
  "courses": [
    {
      "name": "1코스 돌아보는 길",
      "distanceKm": 8.5,
      "duration": "약 3시간",
      "courseUrl": "해당 코스 공식 페이지 URL",
      "stops": [
        { "order": 1, "name": "가실성당", "address": "경북 칠곡군 …", "sourceUrl": "이 경유지를 본 페이지 URL" }
      ]
    }
  ],
  "unknowns": ["확인 못 한 것을 한 줄씩 — 예: 3코스 거리 표기 없음"],
  "sources": ["실제로 연 페이지 URL 전부"]
}
```

- `operatorType`: `diocese`(교구) · `local`(지자체) · `other`(민간단체 등)
- 숫자·주소가 페이지에 없으면 **`null`** 로 두고 `unknowns` 에 적는다. 추측해서 채우지 않는다.
- `stops` 는 페이지에 **순서가 적힌 경유지만**. 순서 없이 나열만 돼 있으면 `stops` 를 비우고 `unknowns` 에 「순서 없음」이라고 적는다.
- 공식 페이지가 열리지 않으면 `urlWorks: false`, `courses: []`, `unknowns` 에 오류 내용을 적고 끝낸다. 다른 사이트로 대체하지 않는다.

## 지킬 것 (범위 밖)

- **서브에이전트·스킬 탐색·계획서 작성 금지.** 직접 순서대로 연다.
- 근거는 **시작 URL 과 같은 운영기관 도메인의 페이지**뿐이다. 블로그·뉴스·위키·「가톨릭 길동무」 앱 데이터는 근거로 쓰지 않는다.
- 페이지 문장을 길게 옮겨 적지 않는다(저작권). `summary` 는 네 말로 2문장.
- 로컬 모델(Ollama)·외부 AI API·번역기 금지.
- DB·`src/`·`supabase/` 수정 금지. `data/research/trails/` 밖에 파일을 만들지 않는다.
- 다른 slug 를 조사하지 않는다.
