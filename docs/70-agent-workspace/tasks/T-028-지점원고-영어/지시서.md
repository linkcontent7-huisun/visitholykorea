# T-028 지시서 — 「지금 이야기」 지점 원고 영어 번역 (+ 대산 성당 한국어 신규 1곳)

작성 2026-09-20 · 실행자 Codex · 발주 Claude · 결정 사장님("사진 있는 곳부터, 원고 없는 것부터")

## 목표

`data/docent/*.json` 의 한국어 지점 원고에 영어(`…En` 필드)를 채운다. 순서는 `대상목록.md` **A(사진 있는 84곳) → B(사진 없는 4곳)**.
그 전에 **대산 성당 복자 구한선 타대오 성지**(사진 있음, 원고 없음) 한국어 원고를 T-024 규칙으로 먼저 쓴다.

## 🔴 절대 규칙

1. **번역만 한다.** 한국어 원고의 사실·순서·문장 수를 그대로. 내용을 더하거나 빼지 않는다. 한국어 필드는 절대 고치지 않는다.
2. 채울 필드: `intro.narrationEn`, 각 `points[].titleEn`·`narrationEn`·`lookForEn`(원문이 null 이면 null)·`locationEn`(있으면), `outro.narrationEn`. **한 성지의 영어는 전부 채우거나 전부 비운다** — 반쪽이면 앱이 영어 투어를 안 낸다.
3. 말투: 안내자가 옆에서 말하는 정중한 구어체("Look at …", "You are standing …"). TTS 로 읽힌다.
4. 고유명사: 지명은 로마자(Supjeongi, Naepo, Galmaemot), 관청은 로마자+짧은 풀이(the Hyeongjo, the Right Police Bureau), 성인 이름은 영어 가톨릭 관행(**St. Andrew Kim Taegon**, Fr. Thomas Choe Yang-eop, Bishop Daveluy). `Kim Dae-geon` 표기 금지. 이미 영어가 있는 19곳(`data/docent/명동대성당.json` 등)의 표기를 따른다.
5. **한글이 영어 필드에 섞이면 실패.** 괄호 속 한글도 금지.
6. **10곳마다 `PYTHONIOENCODING=utf-8 python scripts/docent-check-points.py`** → 실패 0 → 다음 10곳.
7. 서브에이전트·스킬 탐색·계획서·웹 검색 금지. 순서대로 직접 번역만 한다.
8. 커밋·푸시·DB·`.env.local` 금지. 끝나면 `개발기록.md` 에 곳수와 검사 출력 그대로.

## 대산 성당(한국어 신규) 규칙

T-024 지시서 절대 규칙 그대로(출처 URL 필수, 숫자·이름은 자료에 있을 때만, 3~6지점, 위치는 "마당" 수준). 자료: `data/docent/소개글/대산-성당-복자-구한선-타대오-성지.md` 의 출처 URL 과 굿뉴스 성지 안내. `siteId` 는 대상목록 맨 위에 적어 둔다: `335e638e-f115-4158-a097-36b2ec261490`.
