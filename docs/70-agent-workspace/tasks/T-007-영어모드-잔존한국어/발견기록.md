## 한국어로 남아도 되는 것

주변 맛집·숙박·볼거리의 **이름과 주소**(`명동교자`, `서울특별시 중구 …`)는
TourAPI 원본 값이다. 우리가 번역할 수도, 저장할 수도 없다. 그대로 두는 것이 맞다.

## 의심되는 버그 하나 (확인 필요)

히어로의 주소가 **두 줄이 겹쳐 보인다** — `서울시 중구 명동길 74` 위에
`74 Myeongdong-gil, Jung-gu, Seoul` 이 포개져 그려졌다(스크린샷
`docs/10-product/모두의창업-이미지/06a-영어모드-성지상세.png`).
페이지 텍스트로는 두 줄로 분리돼 있으므로 **줄간격·높이 CSS 문제**로 보인다.
한국어 모드에서는 한 줄뿐이라 드러나지 않는다.
