# T-049 검증 — Claude 초안을 사본과 대조한다 (Codex)

`data/research/missing-sites/drafts.json` 의 `sites` 10곳을 **처음 보는 눈으로** 확인한다.
근거는 `data/research/missing-sites/_pages/<cbck_code>/` 사본뿐이다(`sourceFiles` 에 적힌 파일부터).
인터넷을 쓰지 않는다. 다른 사이트·블로그·기억으로 판단하지 않는다.

## 할 일

곳마다 다음을 본다.

1. `name` · `diocese` · `location` · `phone` 이 사본과 맞는가.
2. `description` 의 **문장 하나하나**가 사본에 근거가 있는가. 사본에 없는 사실·과장·연도 오류를 찾는다.
   `description` 이 null 이면, 사본에 쓸 만한 소개가 정말 없는지만 본다.
3. `notes` 의 주장이 사본과 맞는가.

## 결과: `data/research/missing-sites/_verify.json`

```json
{
  "checkedAt": "2026-09-29",
  "sites": [
    {
      "cbck_code": "201008913",
      "verdict": "OK",
      "problems": [],
      "sentences": [
        { "text": "1954년 홍천 본당에서 나뉘어 설립된 본당이다.", "verdict": "근거있음", "evidence": "사본의 해당 구절을 그대로 짧게" }
      ]
    }
  ]
}
```

- `verdict`: `OK`(고칠 것 없음) · `고칠것`(problems 에 무엇을 어떻게) · `확인불가`(사본이 부족).
- `sentences`: description 의 모든 문장. 문장 verdict 는 `근거있음` · `근거없음` · `틀림`. `evidence` 는 사본 원문 인용.
- 10곳 모두 다룬다.
