## 검증

- `python -m py_compile scripts/crawl/cbck.py` 통과.
- `npm run verify`를 다시 실행했다. `typecheck`는 통과했고, `lint`는 이 작업 범위 밖인 `src/shared/i18n/dictionary.ts:4293`의 미종결 문자열 오류로 중단됐다(라우터의 fast-refresh 경고 2건도 함께 표시됨). 따라서 `test` 단계는 실행되지 않았다.
- `npx tsx scripts/crawl/cbck-load.ts --dry-run`은 `.env.local`을 읽어 DB에 접속하는 코드라, 작업 규칙의 `.env.local` 접근 금지 및 DB 스크립트 금지에 따라 실행하지 않았다. 적재기 실제 실행·마이그레이션 적용도 지시자 범위다.
