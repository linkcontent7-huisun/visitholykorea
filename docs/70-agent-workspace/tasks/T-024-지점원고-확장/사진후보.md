# T-024 사진 후보 — 결론 (2026-09-18 18:40 실측)

**위키미디어 공용에는 115곳 중 쓸 만한 사진이 사실상 없다.** 이름 검색 21곳에 후보가 잡혔지만 눌러 보면 전부 동명 지명·역·산·군 훈련 사진이다(아래 표). 이 115곳이 지금까지 사진이 없는 이유가 그것이다.

남은 길:

1. 국가유산포털(공공누리) — 등록문화유산인 5곳은 사진이 있을 가능성이 높다: 대안리 공소(140호) · 소양로 성당(161호) · 수분 공소(189호) · 어은 공소(28호) · 신성 공소(전북 문화유산자료 180호). 확인 필요.
2. 교구·성지 홈페이지 사진 — 사용 허락을 받아야 한다(저작권). 교구별 문의 창구는 노션 자료집 참고.
3. 팀 촬영 — `docs/30-content-ops/` 촬영 가이드.
4. 그때까지 언어별 임시 이미지(`public/placeholders/`) 유지 — 이미 적용돼 있다.

Codex 가 처음 낸 "115곳 후보 없음" 표는 검색 없이 9/15 조사 파일을 옮겨 적은 것이라 폐기했고, 아래는 `scripts/photo-candidates.py` 가 위키미디어 API 를 직접 조회한 결과다.
