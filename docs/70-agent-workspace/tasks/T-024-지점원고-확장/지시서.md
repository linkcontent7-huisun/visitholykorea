# T-024 지시서 — 「지금 이야기」 지점 원고 확장 + 사진 후보 조사

작성 2026-09-18 · 실행자 Codex · 발주 Claude(메인 세션) · 결정 사장님

## 목표 (한 문장)

`대상목록.md` A 의 74곳에 현장 지점 원고(한국어 JSON)를 쓰고, B 의 115곳에 저작권 자유 사진 후보를 표로 만든다.

## 🔴 절대 규칙 — 어기면 전부 폐기된다

T-023 에서 네가 173곳을 틀 문장으로 채워 하루치 작업이 통째로 버려졌다. 그 규칙을 그대로 적용한다.

1. **출처 없는 문장은 쓰지 않는다.** 지점마다 `sourceNote` 에 실제로 읽은 URL 을 적는다. 성지 공식 홈페이지·교구 홈페이지·굿뉴스(maria.catholic.or.kr)·주교회의 주소록(directory.cbck.or.kr)·가톨릭신문·가톨릭평화신문·국가유산청·위키백과 순으로 신뢰한다. 블로그는 위치 확인용으로만 쓰고 사실의 근거로 쓰지 않는다.
2. **모르면 모른다고 쓴다.** 조각상의 작가, 제작 연도, 높이, 문화재 번호 등 숫자·이름은 출처에 있을 때만 쓴다. 없으면 그 문장을 빼거나 "확인 못 함"을 `sourceNote` 에 적는다. **그럴듯하게 지어내는 것이 가장 나쁜 결과다.**
3. **위치는 애매하게 써도 된다.** 사장님 지시: "정확한 위치는 빼고 '성모상은 ~' 이런 애매한 느낌으로만이라도". 즉 `location` 은 "성당 마당", "입구 쪽", "제대 뒤" 수준이면 충분하다. 어느 벽 몇 번째 창인지 모르면 쓰지 않는다.
4. **다른 성지에도 붙는 문장은 한 줄도 쓰지 않는다.** "고요히 기도하며 걸어보세요", "순교자들의 신앙을 느껴보세요" 같은 문장은 금지. 문장마다 그 성지에서만 참인 사실이 들어가야 한다.
5. **자료가 부족하면 지점 수를 줄이거나 그 성지를 건너뛴다.** 건너뛴 곳은 `개발기록.md` 에 "자료 부족: 이름 — 무엇을 못 찾았는지" 로 남긴다. 억지로 채우지 않는다.
6. **기존 파일은 건드리지 않는다.** `data/docent/*.json` 19곳, `data/docent/소개글/` 전부, 영어 파일 전부 — 읽기만.
7. **커밋·푸시·DB·`.env.local` 금지** (AGENTS.md). 파일만 쓴다. 적재·커밋은 Claude 가 한다.
8. **답변은 사실만.** 끝나면 "몇 곳 썼고, 몇 곳 건너뛰었고, 검사 결과가 무엇인지" 를 실제 명령 출력 그대로 보고한다. 하지 않은 일을 했다고 쓰지 않는다.

## A. 지점 원고 (74곳)

### 형식

`data/docent/_템플릿.json` 을 그대로 따른다. 파일 이름은 `data/docent/<성지이름-하이픈>.json` (기존 19곳과 같은 방식, 예: `공세리성지성당.json`, `배티-순교성지.json`).

- `siteId`: `대상목록.md` 의 값을 **그대로 복사**한다. 지어내면 DB 적재가 실패한다.
- `siteName`: 대상목록의 이름과 정확히 일치.
- `surveyedAt`: 오늘 날짜. `surveyedBy`: `"Codex (문헌 초안 2026-09-18)"`. `status`: `"draft"`.
- `intro.narration`: 2~4문장. 여는 말. 이 성지가 무엇이고 오늘 무엇을 보게 되는지.
- `points`: **3~6개**. 자료가 3개 지점을 못 채우면 그 성지는 건너뛴다.
  - `title`: "입구 — 순교탑" 형식.
  - `location`: 애매해도 됨(규칙 3).
  - `narration`: 3~6문장, **안내자가 옆에서 말하는 존댓말 구어체** ("~보세요", "~입니다"). TTS 로 읽힌다. 문어체 "~였다" 금지.
  - `lookFor`: 눈여겨볼 디테일 한 가지. 출처에 있는 것만. 없으면 `null`.
  - `forEveryone`: 비신앙인·외국인용 한 줄. 없으면 `null`.
  - `photos`: `[]` 로 둔다.
  - `sourceNote`: 읽은 URL. 필수.
- `outro.narration`: 1~3문장.
- 영어(`narrationEn` 등)는 **쓰지 않는다.** 영어는 Claude 가 한다.

### 무엇을 지점으로 잡나

성지 안에서 순례자가 실제로 마주치는 것: 성당 건물(외관·종탑), 제대·감실·스테인드글라스, 순교자 묘·현양비·기념탑, 성모상·십자가의 길, 기념관·전시물, 옛 공소·생가터, 우물·바위·나무처럼 이야기가 붙은 자연물. 출처가 그 사물을 언급해야 지점이 된다.

### 작업 단위

**10곳 쓰고 → `npm run docent:check` (또는 `npm.cmd run docent:check`) → ✗ 0 확인 → 다음 10곳.** 검사기가 JSON 도 읽는지 먼저 확인하고, 안 읽으면 소개글 규칙(틀 문장·반말·출처 url)을 스스로 대조한다.

## B. 사진 후보 (115곳)

`docs/70-agent-workspace/tasks/T-024-지점원고-확장/사진후보.md` 한 파일에 표로 만든다.

| siteId | 성지 | 후보 URL | 출처 사이트 | 라이선스 | 무엇이 찍혔나 | 비고 |

- 찾는 곳 순서: 위키미디어 공용(commons.wikimedia.org) → 국가유산청 국가유산포털(공공누리) → 한국관광공사 포토코리아(공공누리) → 각 교구·성지 홈페이지(저작권 문의 필요로 표시).
- **라이선스 칸은 출처 페이지에 적힌 문구를 그대로** 적는다(예: `CC BY-SA 4.0`, `공공누리 1유형`, `저작권 표시 없음 — 문의 필요`). 추측으로 "자유"라고 쓰지 않는다.
- 한 곳에 후보 1~3개. 없으면 "후보 없음"으로 한 줄. 빈칸으로 두지 않는다.
- 사진을 내려받거나 저장소에 넣지 않는다. URL 만.
