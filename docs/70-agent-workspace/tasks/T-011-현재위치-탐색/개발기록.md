# T-011 현재 위치 기반 성지 탐색 개발기록

완료 2026-09-11 · 담당 Codex

## 구현 결과

- 메뉴에서 사용자가 직접 누를 때만 `navigator.geolocation.getCurrentPosition()`을 호출한다.
- 좌표는 `gpsLocation` React 상태로만 유지한다. localStorage·Supabase 요청·위치 이력 저장은 없다.
- 위치 요청 성공 시 홈, 탐색, 빈 여권 미리보기의 거리 계산이 GPS 좌표를 우선 사용한다.
- 메뉴에서 현재 위치를 해제하면 저장된 출발 지역 기준으로 즉시 돌아간다.
- 권한 거부, 브라우저 미지원, 기타 위치 오류는 각각 안내하고 기존 지역 선택을 막지 않는다.

## 확인

1. `git diff`로 GPS 좌표가 `SettingsProvider`의 React 상태에만 있고 저장·전송 호출이 없음을 확인했다.
2. 메뉴 코드에서 GPS 버튼만 `requestGpsLocation`을 호출해 자동 권한 요청이 없음을 확인했다.
3. 탐색·홈·여권에서 `gpsLocation ?? regionCoords(origin)` 우선순위를 확인했다.
4. `npm run verify`를 실행했다. 타입 검사 통과, 린트 오류 0건, 기존 Fast Refresh 경고 2건, 테스트 통과.

## 인수인계

- 실제 기기에서는 메뉴의 「현재 위치 사용」을 눌러 브라우저 권한 허용·거부를 각각 한 번 확인한다.
- 정밀 GPS는 배터리를 더 쓰므로 `enableHighAccuracy: false`를 유지했다. 현재 목적은 길 안내가 아니라 가까운 순 정렬이다.
- OS 또는 브라우저 설정에서 권한을 바꾸면 다시 「현재 위치 사용」을 눌러 새 좌표를 요청할 수 있다.
