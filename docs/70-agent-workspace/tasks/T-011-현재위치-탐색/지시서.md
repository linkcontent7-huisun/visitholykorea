# T-011 — 현재 위치 기반 성지 탐색

작성 2026-09-11 · 담당 Codex

## 목표

사용자가 직접 요청한 경우에만 브라우저 현재 위치를 받아 가까운 성지를 정렬한다.
위치 정보는 서버나 localStorage에 저장하지 않고, 열린 브라우저 탭의 메모리에서만 쓴다.

## 범위

- `SettingsProvider`와 설정 컨텍스트의 GPS 상태·좌표 처리
- 메뉴의 현재 위치 사용·해제와 권한 거부 안내
- 홈·탐색·여권 미리보기의 거리 계산에서 GPS 좌표 우선 사용
- 6개 언어 안내 문구 및 기존 테스트 목 갱신
- `docs/이어서-할-일.md` 및 이 폴더의 개발기록

## 완료 조건

1. 위치 권한을 사용자가 메뉴에서 눌렀을 때만 요청한다.
2. 성공하면 GPS 좌표가 기존 지역 중심 좌표보다 우선한다.
