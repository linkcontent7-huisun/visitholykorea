# T-026 지시서 — 소개글 스페인어·이탈리아어·포르투갈어·프랑스어 번역

작성 2026-09-19 · 실행자 Codex · 발주 Claude · 결정 사장님("코덱에게 번역 시켜")

## 목표 (한 문장)

`data/docent/소개글/en/*.md` 206곳의 영어 소개글을 es → it → pt → fr 순으로 번역해 `data/docent/소개글/<lang>/<같은 파일명>.md` 로 저장한다. 영어본이 원문이다(한국어 원문과 뜻이 같게 이미 감수됨).

## 🔴 절대 규칙

1. **한 파일 = 한 성지, 3문단, 문단마다 큰따옴표.** 영어 파일의 구조를 그대로 옮긴다. 문단을 합치거나 나누지 않는다.
2. **내용을 더하거나 빼지 않는다.** 연도·이름·숫자는 영어본 그대로. 모르는 고유명사는 영어본 로마자 그대로 둔다(예: Supjeongi, Naepo). 성인·신부 이름은 그 언어 가톨릭 관행(Andrés Kim Taegon / Andrea Kim Taegon / André Kim Taegon 등)을 따르되 확신 없으면 영어 표기 유지.
3. **한글·영어 문장이 섞이면 실패다.** 검사기가 잡는다.
4. **머리말(front-matter)은 영어 파일을 복사하고 `language:` 만 바꾼다.** `writtenBy: Codex 번역 2026-09-19 (영어본 기준)`.
5. **20곳 쓰고 → `npm run docent:check` → 그 언어 실패 0 → 다음 20곳.** 실패가 있으면 그 파일만 고친다.
6. 서브에이전트·스킬 탐색·계획서 금지. 순서대로 직접 한다. 웹 검색 불필요.
7. 커밋·푸시·DB·`.env.local` 금지. 파일만 쓴다. 끝나면 `개발기록.md` 에 언어별 곳수와 검사 출력 그대로.

## 순서

es 206곳 → it 206곳 → pt 206곳 → fr 206곳. 한도에 걸려 끊기면 다음 실행이 이어서 하도록, **파일이 이미 있는 성지는 건너뛴다.**

## 완료 조건

- `ls data/docent/소개글/{es,it,pt,fr}/*.md | wc -l` 이 각 206
- `npm run docent:check` 전 언어 실패 0
- 개발기록.md 갱신
