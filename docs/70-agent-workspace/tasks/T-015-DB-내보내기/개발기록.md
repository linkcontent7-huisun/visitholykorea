## 구현 근거

- `scripts/db-export.ts`는 `.env.local`을 직접 열지 않고 기존 `scripts/lib/env.ts`를 통해
  접속 정보를 읽는다. DB 연결 직후 `begin read only`를 실행하므로 표·스키마·Storage 목록을
  조회하는 동안 쓰기 SQL이 실행되지 않는다.
- `public` 스키마의 모든 BASE TABLE을 찾아 JSON·CSV로 내보내고, `information_schema`의 열·제약을
  `schema.md`에 정리한다. `storage.objects`는 CSV 목록으로만 남기며, `site-photos`만 공개 URL로
  내려받고 `pilgrim-photos`는 비공개라 건너뛴다.

## 검증

- `npm run typecheck` 통과.
- 처음 `npm run verify`는 샌드박스가 Vite 설정의 상위 경로 읽기를 막아 실패했고, 권한을
  올려 재실행했다. 재실행 시 공유 작업공간에서 다른 작업이 추가한 `scripts/db-export.ts`
  성지 `image_url` 내려받기 코드의 `TS2532`(197행)로 타입 검사가 실패했다.
- 따라서 내보내기 실행 자체는 성공했지만, 최종 `npm run verify` 통과는 그 동시 변경을
  정리한 뒤 다시 확인해야 한다. 다른 에이전트의 변경을 덮어쓰지 않기 위해 해당 파일은
  더 수정하지 않았다.
