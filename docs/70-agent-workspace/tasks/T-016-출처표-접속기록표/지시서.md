## 2. `events` — 누가 언제 무엇을 봤나 (이름 없이)

| 열          | 형                                                                                                          | 설명                                               |
| ----------- | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| id          | bigint generated always as identity pk                                                                      |                                                    |
| occurred_at | timestamptz not null default now()                                                                          |                                                    |
| visitor_id  | text not null                                                                                               | 브라우저에 저장한 익명 ID (uuid 문자열)            |
| user_id     | uuid → auth.users(id) on delete set null                                                                    | 로그인했을 때만                                    |
| kind        | text not null check (kind in ('view_site','search','view_route','stamp','ai_ask','compass_done','install')) |                                                    |
| target_id   | uuid                                                                                                        | 성지·코스 ID                                       |
| query       | text                                                                                                        | 검색어·AI 질문 (200자 넘으면 잘라 넣는 건 화면 몫) |
| language    | text                                                                                                        | ko/en/…                                            |
| device      | text                                                                                                        | mobile/desktop                                     |

인덱스: `(occurred_at desc)`, `(kind, occurred_at desc)`, `(target_id)`.
RLS: **insert** 는 anon·authenticated 모두 허용하되 `with check (visitor_id <> '' and (user_id is null or user_id = auth.uid()))`.
**select** 는 `public.admin_role()` 만. update/delete 정책 없음.
보관: 이 마이그레이션에서는 만들지 않고, 파일 주석에 "1년 지난 행은 관리자가 지운다(추후 cron)" 라고 적는다.
**이 표에 쓰는 화면 코드는 이 작업 범위가 아니다** (9/21 제출 후, 개인정보처리방침 갱신과 함께).

## 3. `translation_coverage` 뷰 — 성지 × 언어 채움 현황

```sql
create or replace view public.translation_coverage as
select s.id as site_id, s.name, s.diocese,
  bool_or(t.language = 'en' and coalesce(t.name,'') <> '') as has_en,
  bool_or(t.language = 'es' and coalesce(t.name,'') <> '') as has_es,
  bool_or(t.language = 'fr' and coalesce(t.name,'') <> '') as has_fr,
  bool_or(t.language = 'pt' and coalesce(t.name,'') <> '') as has_pt,
  bool_or(t.language = 'it' and coalesce(t.name,'') <> '') as has_it,
  bool_or(t.language = 'en' and coalesce(t.history,'') <> '') as has_en_history
from public.holy_sites s
left join public.holy_site_translations t on t.site_id = s.id
group by s.id, s.name, s.diocese;
```

(`bool_or` 가 null 이 되지 않게 `coalesce(..., false)` 로 감싼다.) 뷰는 `security_invoker = true` 로 만들어 기존 RLS 를 따른다. 읽기는 누구나(성지·번역 표가 이미 공개 읽기).
