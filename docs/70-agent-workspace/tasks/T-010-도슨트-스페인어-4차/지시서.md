# T-010 — 도슨트 원고 스페인어 4차 (마지막 4곳)

작성 2026-09-07 · 담당 **Codex** · 앞선 작업 T-005(3곳)·T-008(3곳)·T-009(3곳) 완료

## 목표

**나주 순교자 기념성당 · 배티 순교성지 · 여우목 성지 · 오륜대 순교자 성지**
네 곳의 도슨트 원고에 스페인어를 넣는다. 네 곳 모두 영어(`En`)가 이미 다 들어 있으므로,
그것과 짝이 되는 `Es` 칸을 채우는 일이다.

**이 작업이 끝나면 도슨트 원고 13곳 전부에 스페인어가 들어간다.** 마지막 묶음이다.

## 고칠 파일 — 이 네 개만 만진다

```
data/docent/나주-순교자-기념성당.json
data/docent/배티-순교성지.json
data/docent/여우목-성지.json
data/docent/오륜대-순교자-성지.json
```

## 완료 조건 — 각 항목을 어떻게 확인하는지까지

1. **네 파일이 여전히 올바른 JSON 이다.**
   확인: 각 파일에 대해
   `node -e "JSON.parse(require('fs').readFileSync('<파일>','utf8'))"` 가 오류 없이 끝난다.

2. **`En` 이 있는 자리마다 `Es` 가 하나씩 있다.** 개수가 정확히 같아야 한다.
   확인: 각 파일에서 네 쌍의 개수를 세어 좌우가 같은지 본다.
   - `narrationEn` ↔ `narrationEs`
   - `titleEn` ↔ `titleEs`
   - `locationEn` ↔ `locationEs`
   - `lookForEn` ↔ `lookForEs`

   현재 `narrationEn` 개수는 나주 7 · 배티 7 · 여우목 7 · 오륜대 7 이다.
   (`intro` 와 `outro` 의 `narration` 도 포함한 수다 — 빠뜨리지 말 것.)

   🔴 **`lookFor` 가 `null` 인 지점을 조심한다.** 볼거리가 없는 지점은 원본이
   `"lookFor": null, "lookForEn": null` 로 되어 있다. 그런 자리에는 **없는 내용을
   지어내지 말고 `"lookForEs": null` 을 적는다.** 키를 통째로 빼면 개수가 어긋난다
   (T-009 솔뫼성지에서 실제로 이 일이 있었다).

3. **`Es` 값 안에 한글이 한 글자도 없다.**
   확인: `grep -o '"[a-zA-Z]*Es": "[^"]*"' <파일> | grep -P '[가-힣]'` 가
   아무것도 출력하지 않아야 한다.

4. **한국어 원본(`narration`·`title`·`location`·`lookFor`)과 영어(`En`)가 한 글자도
   바뀌지 않았다.**
   확인: `git diff --numstat` 에서 **삭제된 줄이 0** 이어야 한다. 추가만 있어야 한다.

5. **`npm run verify` 가 통과한다.** (타입 검사 · 린트 · 테스트 334개)
   `src/app/routes/router.tsx:40:10` 의 Fast Refresh 경고 1건은 원래 있던 것이라 무시한다.

6. **`개발기록.md` 를 이 폴더에 쓴다.** 위 다섯 항목을 **각각 어떤 명령으로
   확인했고 결과가 무엇이었는지** 적는다. "코드에 있으니 됐다"는 근거가 아니다.

## 번역할 때 지킬 것

- **한국어 원본을 번역한다.** 영어를 다시 번역하면 뜻이 두 번 흔들린다.
  영어는 "이 자리에 무엇이 들어가는지" 참고용으로만 본다.
- 성인·복자 이름은 스페인어권 가톨릭 표기를 쓴다
  (예: 김대건 안드레아 → `San Andrés Kim Taegon`,
  최양업 토마스 → `Padre Tomás Choe Yang-eop`,
  이윤일 요한 → `San Juan Yi Yun-il`).
- **낭독용 원고다.** 귀로 듣는 글이므로 문장을 짧게 끊고, 괄호와 각주를 쓰지 않는다.
- 지명은 로마자 표기 뒤에 필요하면 짧은 설명을 붙인다
  (예: `Baeti`, `un valle donde se refugiaron los cristianos perseguidos`).
- 길이는 한국어 원문과 비슷하게. 요약하거나 늘리지 않는다.

## 범위 밖 — 하지 말 것

- 위 네 개 말고 다른 성지 원고 파일
- `src/` 아래 코드 전부
- 프랑스어·포르투갈어·이탈리아어 (원고 번역은 스페인어까지만)
- **git 명령 중 쓰기 전부** — `add`·`commit`·`push`·`checkout`·`reset`·`stash`·`clean`.
  읽기(`status`·`diff`·`log`)만. 스테이징과 커밋은 지시자가 한다.
- `.env.local` 을 읽지도 쓰지도 않는다.
