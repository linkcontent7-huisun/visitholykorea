# T-010 도슨트 스페인어 4차 개발기록

**지시자(Claude)가 직접 수행했다.** 원래 Codex 에게 넘겼으나 Windows 에서
「울타리 치고 안 묻기」가 성립하지 않아(자세한 경위는 `docs/이어서-할-일.md`
9/7(2) 항목) 사장님 지시로 지시자가 맡았다. Codex 세션은 `blocked` 로 남기고
파일은 하나도 건드리지 않은 채 정리했다.

## 작업 방식

`json.dump` 로 다시 쓰면 파일 전체가 재정렬되어 diff 가 삭제·추가 범벅이 된다.
그러면 "한국어 원문이 안 바뀌었다"를 눈으로 확인할 수 없다. 그래서 텍스트로
`...En` 줄 **바로 뒤에** `...Es` 줄만 끼워 넣었다 — diff 에 추가만 남는다.

번역은 **한국어 원문에서** 했다. 영어는 그 자리에 무엇이 들어가는지 확인하는
용도로만 봤다.

## 완료 조건 확인

1. **JSON 형식** — 삽입 도구가 저장 직전에 `json.loads()` 로 검사하도록 만들었다.
   네 파일 모두 통과했고, 검사 스크립트에서 다시 `json.loads` 로 확인했다.

2. **En/Es 개수 일치** — 네 파일 모두 `narration 7/7 · title 5/5 · location 5/5 ·
   lookFor 5/5`. `lookFor` 가 `null` 인 지점은 없는 내용을 지어내지 않고
   `"lookForEs": null` 로 넣었다(T-009 솔뫼에서 겪은 문제를 미리 막았다).

3. **Es 값의 한글** — 모든 `*Es` 문자열을 `[가-힣]` 로 검사했다. **네 파일 0건.**

4. **한국어 원문·영어 보존** — `git diff --numstat` 결과가 네 파일 모두
   **22 추가 · 0 삭제**. 지워진 줄이 없다.

5. **전체 검증** — `npm run verify` 통과. 테스트 **334개**.
   `src/app/routes/router.tsx:40:10` 의 Fast Refresh 경고 1건은 원래 있던 것이다.

6. **개발기록** — 이 파일.
