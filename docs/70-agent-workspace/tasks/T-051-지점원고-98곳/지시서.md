# T-051 — 지점 원고(오디오 가이드) 없는 98곳 채우기

사장님 지시(2026-10-02): 「206곳 오디오 가이드 원고가 다 됐는지 보고, 부족한 곳은 찾아서 작성해 둬라. 1번부터 차례로 다 해라.」

## 목표

DB 실측(10/2) 지점 원고 108곳 → 206곳. 원고는 **파일로만** 만들고 DB 반영은 심사 기간 동결이 풀린 뒤.

## 절차 (`.claude/skills/new-site-audio-guide/SKILL.md` 그대로, 경로만 다름)

| 무엇 | 경로 |
| --- | --- |
| 대상 목록·진행표 | `대상목록.md` (이 폴더) · `data/research/docent-gap/targets.json` |
| 근거 사본 | `data/research/docent-gap/_pages/<slug>/*.txt` |
| 원고(한·영) | `data/research/docent-gap/docent/<slug>.json` — `siteId` 는 DB 값 |
| 검증 결과 | `data/research/docent-gap/docent/_verify/<slug>.verify.json` |
| 검사 | `PYTHONIOENCODING=utf-8 python scripts/docent-check-points.py data/research/docent-gap/docent` |
| 검증(Codex) | `bash scripts/run-docent-verify.sh` 와 같은 방식 — 지시서는 T-050 `검증-지시서.md`, 경로만 이 폴더 |

## 완료 조건 (곳마다)

1. 사본 1개 이상(글자 수 300 이상)이 `_pages/<slug>/` 에 있다.
2. `intro` · `points` 3~6개 · `outro`, 한국어+영어, `sourceNote` 에 URL+사본 경로.
3. 검사기 실패 0 · 틀 문장 0.
4. Codex 검증 `OK` 또는 고칠 것을 Claude 가 반영한 뒤 재검증 `OK`.
5. 자료가 3개 지점을 못 채우면 **보류**로 표에 적고 이유를 남긴다. 지어내지 않는다.

## 범위 밖

4개 국어 번역(검증 끝난 곳을 모아서 따로), DB 반영, `src/` 변경.
