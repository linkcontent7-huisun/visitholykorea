# T-047 개인정보처리방침 근본 조치

근거: GitHub 이슈 #47과 2026-09-20 사용자 요청.

## 목표

- 개인정보처리방침의 미완성 문구를 실제 운영 절차와 확정된 연락처로 교체한다.
- 로그인 회원이 앱에서 계정을 삭제할 수 있게 하고, 이메일 요청 창구도 둔다.
- 계정 삭제 시 사진 원본, 공개 순례 후기, 연결된 데이터를 함께 삭제한다.
- 약관·FAQ의 충돌 문구와 법적 화면의 미완성 문구를 점검한다.
- 검증 후 PR을 연다. 사용자 요청이 PR까지 명시했으므로 이 작업에 한해 브랜치 커밋·푸시를 진행한다.

## 완료 조건

1. 운영 주체·담당자·연락처가 사실로 확인되어 공개된다.
2. 보유기간과 삭제 방법이 실제 구현과 일치한다.
3. 계정 삭제에서 사진 원본과 연결된 기록이 정리되고 실패 시 계정 삭제를 중단한다.
4. 법적 화면에 미완성 문구가 남지 않는다.
5. 가능한 검증을 실행하고 결과와 제한을 개발기록에 남긴다.
6. PR이 열린다.

## 범위 밖
