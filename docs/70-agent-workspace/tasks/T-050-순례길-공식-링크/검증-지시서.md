# T-050 검증 — 순례길 공식 링크가 맞는 페이지인가 (Codex)

`data/research/route-links/links.json` 에서 `status: "found"` 인 항목을 확인한다.
항목 번호 i = `ourCourses` 다음에 `nationwide` 를 이어 붙인 목록의 순서(0부터). 사본은 `data/research/route-links/_pages/<i>.txt`.
인터넷을 쓰지 않는다. 사본만 근거로 한다.

곳마다 본다:
1. 사본이 그 순례길(또는 그 코스)을 **직접 안내하는 페이지**인가 — 메인 화면·다른 코스 페이지면 틀림.
2. `owner`(운영 주체) 가 사본에 드러나는가.
3. `note` 의 주장(거리·코스 수 등)이 사본과 맞는가.

결과 `data/research/route-links/_verify.json`:
```json
{ "items": [ { "i": 0, "url": "...", "verdict": "OK", "reason": "사본 제목·본문 근거 한 줄" } ] }
```
verdict: `OK` · `다른페이지`(더 맞는 링크가 사본 안에 보이면 reason 에 적기) · `확인불가`.
`found` 항목 모두 다룬다. links.json·사본은 고치지 않는다. 서브에이전트·계획서 금지.
완료 조건: `python scripts/route-links-verify-check.py` 가 OK.
