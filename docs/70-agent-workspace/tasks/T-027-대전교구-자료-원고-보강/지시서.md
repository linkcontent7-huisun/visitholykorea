# T-027 지시서 — 대전교구 제공 자료로 지점 원고 새로 쓰기·보강

작성 2026-09-19 · 실행자 Codex · 발주 Claude · 결정 사장님

## 배경

2026-09-18 대전교구 홍보국(크란시아 자매)이 성지 사진과 문서를 보내 왔다. hwp 문서 48건을 텍스트로 뽑아
`data/research/대전교구-자료-텍스트/` 에 두었다. **교구가 직접 쓴 공식 자료**이므로 웹 검색보다 우선한다.
핵심 파일: `…__대전교구 성지 소개 글(홈페이지 내용 수정 전).txt` — 대전교구 성지 25곳의 공식 소개(주소·미사·역사·볼거리).

## 목표

`대상목록.md` A 14곳에 지점 원고(`data/docent/<이름>.json`)를 새로 쓰고, B 13곳의 기존 원고를 교구 자료로 보강한다.

## 🔴 절대 규칙 (T-024 와 같다)

1. **출처는 교구 자료 파일 이름을 적는다.** `sourceNote: "대전교구 홍보국 제공 자료(2026-09-18): <파일명> — 굿뉴스 https://…"` 처럼 파일명 + 보조 URL. 교구 자료에 없는 사실은 굿뉴스·교구 홈페이지에서 확인한 것만 쓰고 URL 을 적는다.
2. **숫자·이름·작가·문화재 번호는 자료에 있을 때만.** 없으면 빼거나 "확인 못 함". 지어내지 않는다.
3. **위치는 "마당·입구 쪽·성당 안" 수준.** 자료에 위치가 적혀 있으면 그대로 옮긴다.
4. **다른 성지에도 붙는 문장 금지.** 문장마다 그 성지에서만 참인 사실.
5. **안내자 1인칭 존댓말 구어체**("~보세요", "~입니다"). TTS 로 읽힌다.
6. **형식은 `data/docent/_템플릿.json`.** `siteId` 는 대상목록에서 복사. `surveyedBy: "Codex (대전교구 자료 초안 2026-09-19)"`. `status: "draft"`. 영어(`narrationEn`)는 쓰지 않는다.
7. **B 보강은 기존 파일을 고쳐도 된다**(이 작업만 예외). 단 기존 지점의 사실을 지우지 말고, 교구 자료에서 확인되는 사물·이야기를 지점으로 **추가**하거나 문장을 **보태는** 방식. 지점 4~6개가 되게.
8. **10곳마다 `PYTHONIOENCODING=utf-8 python scripts/docent-check-points.py`** → 실패 0 → 다음.
9. 서브에이전트·스킬 탐색·계획서 금지. 커밋·DB·`.env.local` 금지. 끝나면 `개발기록.md` 에 쓴 곳·보강한 곳·검사 출력 그대로.

## 순서

A 14곳(자료가 있는 곳부터: 남방제·대흥봉수산·삽티·서짓골·도앙골·배나드리·성거산·원머리·정산·지석리·진산·황무실 → 산막골·작은재(자료 없음, 굿뉴스로) → 덕산(자료 없음, 굿뉴스로)) → B 13곳.

## 자료 찾는 법

- 공식 소개글: 위 핵심 파일에서 성지 이름(예 `남방제성지`) 으로 찾는다. 각 성지 절에 주소·미사·역사·볼거리가 이어진다.
- 성지별 자료집: 파일명이 `<폴더>__<제목>.txt` 다. 예 `도앙골__홍산도앙골과인근교우촌그리고최양업.txt`, `청양다락골__20091221_다락골_자료집.txt`, `신평원머리_…연구발표회…txt`, `강경성지…`, `상홍리공소…`, `해미…`, `정산성지…`.
- `CBCK 성지 책자…` 는 hwp 변환 실패로 없다. 대신 같은 이름의 pdf 가 `대전교구사진-크란시아자매님/` 에 있다 — 필요하면 pdf 를 읽어라.
