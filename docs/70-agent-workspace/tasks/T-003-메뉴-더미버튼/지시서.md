# T-003 · 메뉴 화면의 죽은 버튼 4개를 고친다

- 작성: 2026-09-05
- 담당: developer
- 근거: `docs/70-agent-workspace/tasks/T-002-화면단순화-조사/조사기록.md`
  "MenuPage" 절 — 눌러도 반응 없는 버튼 4개가 CLAUDE.md 더미 UI 금지
  규칙을 어기고 있다는 조사 결과.

## 목표

`src/pages/MenuPage.tsx` 의 `onClick` 없는 메뉴 항목 4개를 전부 없앤다 —
①실제로 동작하게 만들거나 ②정말 필요 없으면 항목 자체를 지운다.
"화살표는 있는데 눌러도 안 움직이는" 상태를 하나도 남기지 않는다.

## 각 항목의 처리 방법 (오케스트레이터가 조사해서 미리 정함 — 다시 판단하지 말 것)

1. **`id: 'settings'` (일반 설정, `Settings` 아이콘, 120행 부근)**
   → **항목 자체를 지운다.** 같은 화면 "앱 설정" 섹션에 언어·큰 글자·출발지가
   이미 다 있어서 "일반 설정"이 가리킬 별도 내용이 없다 — 중복이다.

2. **`id: 'intro'` (서비스 소개, `aboutServiceSub`)** 와
   **`id: 'help'` (고객센터, `customerSupportSub`)**
   → 둘 다 **`paths.faq` (자주 묻는 질문)로 연결**한다. `onClick: () =>
   navigate(paths.faq)` 를 추가한다 (`useNavigate` 는 이미 다른 곳에서
   쓰고 있으면 그걸 재사용, 없으면 `react-router-dom` 에서 새로 가져온다).
   두 항목을 하나로 합치지는 않는다 — 라벨과 부제 문구는 그대로 두고
   목적지만 연결한다. (진짜 별도의 소개 페이지·고객센터 채널은 이번
   범위가 아니다 — 필요하면 별도 작업으로 연다.)

3. **`id: 'share'` (앱 공유하기, `Share2` 아이콘, 128행 부근)**
   → **`navigator.share` 로 실제 공유를 구현한다.** 제목은 `document.title`
   또는 앱 이름, url 은 `window.location.origin`. `navigator.share` 가
   없는 브라우저(데스크톱 크롬 등)에서는 `navigator.clipboard.writeText`
   로 링크를 복사하고 "링크를 복사했어요" 같은 짧은 안내를 보여준다
   (기존 프로젝트에 있는 토스트/알림 방식이 있으면 그걸 따르고, 없으면
   `alert` 이 아니라 화면 안에 짧게 뜨는 문구로 — `alert` 금지).

## 완료 조건

- [ ] `MenuPage.tsx` 에 `onClick` 없는 메뉴 항목이 하나도 없다
- [ ] "일반 설정" 항목이 화면에서 사라졌다
- [ ] "서비스 소개"·"고객센터"를 누르면 자주 묻는 질문 화면으로 이동한다
- [ ] "앱 공유하기"를 눌렀을 때: 공유 시트가 뜨는 기기에서는 공유 시트가,
      안 되는 환경에서는 링크가 복사되고 사용자가 알아볼 수 있는 안내가 뜬다
- [ ] `alert()`/`confirm()` 을 새로 쓰지 않는다
- [ ] `npm run verify` 통과
- [ ] 모바일 375px 에서 세 버튼(FAQ 이동 2개, 공유 1개)을 실제로 눌러보고
      확인 — 공유는 실제 기기 공유 시트가 안 뜨는 브라우저 환경이면
      "복사됨" 분기가 타는 것으로 확인해도 된다

## 범위 밖 (하지 말 것)

- 진짜 "서비스 소개" 전용 화면이나 "고객센터" 채널(이메일·카카오 채널 등)을
  새로 만들지 않는다 — FAQ 로 연결하는 것으로 이번 작업은 끝이다
- 이 작업에서 발견한 SiteDetailPage·RecordsPage 관련 사항은 건드리지 않는다
  (별도 작업 T-004 등에서 다룬다)
- MenuPage 의 다른 부분(프로필 카드, 앱 설정 섹션 등)은 손대지 않는다
