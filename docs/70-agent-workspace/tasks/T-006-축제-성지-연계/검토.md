### 고쳐야 할 것 (우선순위 순)

1. **`src/pages/FestivalsPage.tsx:28` — 기본 필터가 「전체」가 아니라 저장된 출발지다. 지시서와 다르다.**
   ```ts
   const [region, setRegion] = useState<Region | null>(origin);   // ← origin 은 vhk_origin(localStorage)
   ```
   지시서 「만들 것 → 2. 화면에 나오는 것」에 **"시·도 필터 … 기본은 전체"** 라고 명시돼 있는데
   코드는 출발지를 기본값으로 쓴다. 개발기록의 「판단한 것」 6개 항목에도 이 판단이 없어,
   기록만 읽으면 드러나지 않는다. 실제 영향도 있다 — 오늘 실측 기준 **광주·울산·세종은 0건**이라,
   출발지를 그 세 곳으로 저장해 둔 사용자는 **화면을 열자마자 빈 상태**를 본다(전국에는 60건이 있는데도).
   → 기본값을 `null`(전체)로 되돌리거나, 출발지 기본값을 유지하려면 지시자 승인을 받고
   그 근거를 개발기록에 남긴다. (규칙 위반이 아니라 **지시서 이탈**이다.)

2. **`src/features/festivals/api/use-festivals.ts:8, 26` — 주석의 호출 수가 실제와 다르다.**
   주석은 "전국 축제 조회 **1회**가 전부다" / "TourAPI **1회**" 라고 단정하는데,
   검토자 실측은 **2회**였다(`getOngoingFestivals` 가 300건을 채우면 다음 페이지를 더 받는다. 최대 3회).
   개발기록에는 2회라고 정확히 적혀 있으나 코드 주석이 틀렸다. CLAUDE.md 는 확인되지 않은 수를
   단정해 적지 말라고 못 박고 있으므로, "축제 수에 따라 1~3회(성지 수와 무관)"처럼 고친다.
