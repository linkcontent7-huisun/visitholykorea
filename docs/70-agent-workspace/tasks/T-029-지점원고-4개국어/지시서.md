# T-029 지시서 — 지점 원고 스페인어·이탈리아어·프랑스어·포르투갈어

## 목표

`data/docent/*.json` 중 영어(`narrationEn`)가 채워진 모든 성지에 `…Es`·`…It`·`…Fr`·`…Pt` 필드를 채운다.
순서: **T-028 대상목록 A(사진 있는 곳) → B → 나머지**. 언어 순서: es → it → pt → fr. 이미 그 언어가 채워진 성지는 건너뛴다(기존 19곳 일부는 Es 가 있다).

## 🔴 절대 규칙 (T-028 과 같다)

1. **영어본을 원문으로 번역만 한다.** 사실·순서·문장 수 그대로. 한국어·영어 필드는 손대지 않는다.
2. 채울 필드(언어별): `intro.narration<Xx>`, `points[].title<Xx>`·`narration<Xx>`·`lookFor<Xx>`(원문 null 이면 null), `outro.narration<Xx>`. **한 성지·한 언어는 전부 채우거나 전부 비운다.**
3. 안내자 구어체 존댓말(usted / Lei / vous / você). 지명은 로마자 그대로(Solmoe, Galmaemot), 성인 이름은 그 언어 가톨릭 관행(Andrés Kim Taegon / Andrea Kim Taegon / André Kim Taegon / André Kim Taegon). `Kim Dae-geon` 금지.
4. 한글이 섞이면 실패. 영어 문장이 그대로 남아도 실패.
5. **10곳마다 `PYTHONIOENCODING=utf-8 python scripts/docent-check-points.py`** → 실패 0.
6. 서브에이전트·스킬 탐색·계획서·웹 검색 금지. 커밋·푸시·DB 금지. 끝나면 `개발기록.md` 에 언어별 곳수와 검사 출력.
