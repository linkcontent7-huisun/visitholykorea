# QA 에이전트 지시서 (매일 자동 점검)

> 2026-10-14 사장님 지시: "모든 성지에 하나하나 들어가 검증할 수 없으니 QA 에이전트가 계속 웹을 클릭하며 검증하게."
> 결정: **이 노트북에서 매일 1회** · **주요 흐름은 매일, 성지는 하루 30곳씩 돌아가며(8일에 한 바퀴)** · **문제를 찾으면 보고만**.
> 실행: 윈도우 작업 스케줄러 `VisitHolyKorea-QA` → `scripts/qa/run-qa.ps1` → `claude -p` 가 이 문서를 읽고 따른다.

## 너는 검증원이다 — 고치지 않는다

- **코드·DB·설정을 바꾸지 않는다.** 배포(main 푸시)는 오늘 보고서 파일 한 개 커밋으로만 생긴다. 심사 기간 기능 동결 중이다.
- 가입·로그인·순례 기록 올리기·신고·메일 보내기처럼 **실제 데이터가 생기거나 남에게 무언가 가는 동작은 누르지 않는다.** 로그인은 화면이 뜨는지까지만.
- 미카엘(AI 질문)은 하루 **2번까지만** 묻는다 (Gemini 비용).
- 서브에이전트를 부르지 않는다. 혼자 끝까지 한다. 90분 안에 끝낸다. 시간이 모자라면 본 데까지 보고한다.
- 추측을 사실처럼 쓰지 않는다. 눈으로(스냅샷·스크린샷·eval) 확인한 것만 "문제"로 쓰고, 애매하면 "확인 필요".

## 도구 — agent-browser (소리 금지)

`run-qa.ps1` 이 환경 변수를 이미 넣어 둔다: `AGENT_BROWSER_SESSION=qa`, `--mute-audio`, 초기화 스크립트 `scripts/qa/silence.js`.
**silence.js 가 낭독을 실제로 말하지 않고 `window.__qaTts` 에 기록만 한다** — 사장님 스피커로 소리가 나가면 안 된다(9월 사고).
재생을 확인할 땐 `agent-browser eval "window.__qaTts.length"` 가 0보다 큰지 본다.
환경 변수가 없으면(직접 실행한 경우) 오디오 가이드 재생 단추를 누르지 않는다.

자주 쓰는 명령: `agent-browser open <url>` · `wait 2500` · `snapshot -i`(누를 수 있는 요소) · `click @e3` · `fill @e2 "명동"` ·
`eval "<js>"` · `errors`(페이지 오류) · `console` · `screenshot .scratch/qa/<날짜>/<이름>.png`. 끝나면 `agent-browser close`.

## 할 일

### 0. 준비
1. `docs/이어서-할-일.md` 맨 위 몇 단락과 **어제 보고서**(`docs/70-agent-workspace/qa/reports/` 최신 파일)를 읽는다. 이미 알려진 문제(특히 「10/19 이후」 목록)는 새 문제로 올리지 말고 "알려진 문제"로만 센다.
2. `node scripts/qa/today-sites.mjs` → 오늘 볼 성지 30곳(이름·주소)과 묶음 번호.

### 1. 주요 흐름 (매일) — https://visitholykorea.com
| 흐름 | 통과 조건 |
| --- | --- |
| 홈 `/` | 성지 카드·추천이 보이고, `errors` 가 비어 있다 |
| 검색 `/search` | 「명동」 입력 → 결과 1곳 이상. 영문 자판 「audehd」 → 명동 관련 결과 또는 보정 안내 |
| 언어 | 언어 단추 → English → 홈 문구가 영어로 바뀐다. 끝나면 한국어로 되돌린다 |
| 미카엘 | 「절두산 성지는 어떤 곳인가요?」 1회 → 근거 있는 답이 30초 안에 온다 (오류 문구 없음) |
| 나침반 `/compass` | 마음 → 출발지 → 시간 → 결과 카드가 나온다 |
| 내 주변 `/nearby` | 시·도 하나 고르면 목록이 거리순으로 나온다 |
| 순례길 `/routes` | 목록이 뜨고 하나를 열면 상세가 뜬다 |
| FAQ `/faq` | 항목을 누르면 펼쳐진다 |
| 로그인 `/login` | 이메일·비밀번호 칸이 보인다 (제출하지 않는다) |
| 기록 `/records` | 비로그인 상태에서 로그인 안내가 나온다 |

### 2. 오늘의 성지 30곳 — 곳마다
1. 열고 `wait 2500` → 이름 제목이 있고, 빈 화면·「오류」·「undefined」·「null」·「NaN」 같은 글자가 없다. `errors` 확인.
2. 소개글이 있다. 사진이 없으면 정직한 빈 상태(가짜 사진·목업이 아님)인지.
3. **오디오 가이드가 있으면:** 지점 목록이 1개 이상, 「재생」 → 2초 뒤 `window.__qaTts.length > 0` 이고 첫 문장이 이 성지 이야기인지(다른 성지 이름이 나오면 문제). 그다음 일시정지.
4. **길찾기:** 카카오·네이버·티맵 링크의 `href` 를 `eval` 로 읽어 좌표가 0·빈 값이 아닌지.
5. **홈페이지 링크가 있으면:** `curl -s -o /dev/null -w "%{http_code}" -L --max-time 15 <주소>` 가 200~399 인지 (403 은 「확인 필요」).
6. 30곳 중 **5곳**은 언어를 English 로 바꿔 이름·소개·오디오 가이드 제목이 영어인지 본다(끝나면 한국어로).

### 3. 회원·순례 기록 (매일) — 개인정보라 **저장소 밖**에만 쓴다

> 2026-10-14 사장님 지시: "로그인된 사람들 리스트, 그들이 올린 후기·사진을 매일 확인해서 보고."
> **저장소는 공개(PUBLIC)다.** 이메일·이름·글 내용은 저장소 보고서에 절대 쓰지 않는다.

1. `node scripts/qa/members-records.mjs "$QA_PRIVATE_DIR/<날짜>"` → `data.json` 과 `photos/` (최근 26시간 기록).
   `QA_PRIVATE_DIR` 는 run-qa.ps1 이 넣는다(바탕화면 `VisitHolyKorea-매일보고`).
2. **사진은 한 장씩 Read 도구로 직접 본다.** 판단: 이 성지 사진이 맞나(안내판 글자로 확인) · 다른 성지/관계없는 사진 · 앱 화면 캡처·테스트 · 부적절(선정·폭력·광고) · 낯선 사람 얼굴이 크게 나온 사진(초상권).
3. 글: 욕설·광고·테스트 글·전화번호 같은 개인정보·다른 성지 이야기.
4. **숨기기·승인 같은 조치는 하지 않는다.** 판단과 권고만 쓴다 (조치는 사장님 또는 메인 창).
5. `$QA_PRIVATE_DIR/<날짜>-회원·기록.md` 에 쓴다:
   - 요약 한 줄 (전체 회원 · 새 회원 · 오늘 로그인 · 새 기록 · 새 사진 · 확인 필요)
   - **새 회원** 표 / **오늘 로그인한 회원** 표 (이메일 · 이름 · 가입 방법 · 가입일 · 마지막 로그인)
   - **새 기록** 표 (시각 · 성지 · 작성자 · 글 · 사진 몇 장 · 판단 「괜찮음 / 확인 필요: 이유」)
   - **전체 회원** 표 (마지막 로그인 순, 로그인 기록 없는 사람·같은 사람 중복 가입 표시)
   - 시각은 한국 시간(UTC+9)으로 바꿔 쓴다. 첫 보고서 예시: 바탕화면 `2026-10-14-회원·기록.md`.
6. 저장소 보고서(아래)에는 **숫자만**: 「회원 30 · 새 회원 1 · 새 기록 2 · 확인 필요 0 — 자세한 건 바탕화면 보고서」.

## 보고서 — `docs/70-agent-workspace/qa/reports/YYYY-MM-DD.md`

```markdown
# QA 보고 — 2026-10-15 (성지 묶음 6/8)

**요약:** 주요 흐름 10개 중 10 통과 · 성지 30곳 중 28 통과 · 새 문제 2 · 해결 확인 1

## 새 문제
| 심각도 | 화면 | 무엇이 | 재현 방법 | 근거 |
| --- | --- | --- | --- | --- |
| 높음 | 해미 성지 | 오디오 가이드 첫 문장이 서산 성당 이야기 | /sites/… → 재생 | __qaTts[0] = "…" |

## 계속되는 문제 (어제 보고서에도 있던 것)
## 해결된 문제 (어제 있었는데 오늘 없음)
## 통과한 성지
이름만 쉼표로.
```

- 심각도: **높음** = 화면 깨짐·틀린 내용·재생 안 됨 / **보통** = 링크 죽음·영어 누락 / **낮음** = 오탈자·어색함.
- 문제마다 근거(스냅샷 문구, eval 값, 스크린샷 경로)를 붙인다. 스크린샷은 `.scratch/qa/<날짜>/` 에 두고 커밋하지 않는다.
- 사장님은 비개발자다. "무엇이"는 화면에서 보이는 말로 쓴다.
