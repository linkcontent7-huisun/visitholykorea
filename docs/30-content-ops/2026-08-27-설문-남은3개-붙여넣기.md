> **질문 문구를 바꾸지 말 것.** 응답 집계 도구가 질문 제목으로 열을 찾는다.

## ① 불편했던 점

**넣을 자리** Q7(설명 부족) 바로 뒤 · **유형** 체크박스 · **필수 아님**

질문

```
다녀오시면서 불편했던 점이 있다면 골라주세요. (여러 개 고르셔도 됩니다)
```

보기 — 구글폼 보기 칸에 한 줄씩 붙여넣으면 자동으로 나뉜다

```
가는 길과 교통편을 찾기 어려웠다
문이 닫혀 있거나 개방 시간을 알 수 없었다
미사·전례 시간을 알기 어려웠다
화장실·주차·앉아 쉴 곳이 마땅치 않았다
비신자나 외국인이 이해할 안내가 없었다
어디부터 어떻게 봐야 할지 몰랐다
특별히 불편한 점은 없었다
```

## ② 순례지 주변에 함께 필요한 것

**넣을 자리** ① 바로 뒤 · **유형** 체크박스 · **필수 아님**

질문

```
성지에 가실 때 주변 정보도 함께 있으면 좋겠다 싶은 것을 골라주세요. (여러 개)
```

보기

```
근처 맛집·식당
숙박 (피정의집·게스트하우스·호텔)
주변 관광지·명소
카페·쉴 곳
주차장·대중교통 안내
지역 특산물·기념품
함께 묶어 볼 만한 다른 성지
```

## ③ 마지막 문항 문구 교체

**넣을 자리** 맨 마지막 장문형 문항 · 질문 제목만 바꾼다

바꾸기 전

```
이 앱이나 성지 순례에 대해 하고 싶은 말씀이 있으면 자유롭게 적어주세요.
```

바꾼 뒤 — **따옴표까지 그대로**

```
"이런 게 있으면 좋겠다" 싶은 것을 적어주세요.
```

## 다 넣은 뒤

1. 미리보기(👁)로 처음부터 끝까지 한 번 넘겨본다
2. **게시** → 응답 링크를 받는다
3. 서너 명에게 먼저 보내 문항을 시험한다
4. 마지막 주일 미사 후 본당 단톡방에 보낸다 — 응답률이 가장 높은 시점

목표 **30명**. 통계적으로 유의한 수는 아니지만, 심사위원에게 "물어봤다"와
"안 물어봤다"는 완전히 다른 이야기다.
