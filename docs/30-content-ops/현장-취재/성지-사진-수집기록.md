#### 2026-08-28 에 자동 수집 경로를 전부 시험했다 — 결론: 소진됐다

**남은 161곳은 기술로 못 채운다. 촬영하거나 교구에 요청해야 한다.**
아래는 실제로 돌려본 결과다. 같은 길을 다시 파지 않기 위해 남긴다.

| 경로 | 결과 | 판단 |
| --- | --- | --- |
| **국가유산청 공개 API** | 후보 7곳 → **6곳 적용** | ✅ 쓸 만했다. 아래 방법 참고 |
| 위키미디어 재조사 잔여분 | 3곳 중 **2곳 적용**, 1곳은 함정 | ✅ 소진 |
| **TourAPI 실시간 이미지** | 162곳 중 적중 7곳, 그중 **유효 1곳** | ❌ **막다른 길.** 온천·시장·향교가 잡힌다 |
| 위키미디어 좌표 검색(geosearch) | 절두산 반경 500m 에 공중화장실·주민센터 사진뿐 | ❌ 한국은 커먼즈 좌표 데이터가 희박하다 |

**국가유산청 API 방법** (다시 쓸 수 있다):

- 목록 `https://www.khs.go.kr/cha/SearchKindOpenapiList.do?ccbaMnm1=<이름>` (인증키 불필요)
- 이미지 `https://www.khs.go.kr/cha/SearchImageOpenapi.do?ccbaKdcd=&ccbaAsno=&ccbaCtcd=`
- `imageNuri` 가 라이선스다 — **A = 공공누리 제1유형(출처표시)만 쓴다.**
  B·D 는 상업적 이용 금지, **F 는 AI 생성**이라 우리 원칙(가짜 사진 금지)에 어긋난다
- 이미지 URL 은 `http://` 로 오므로 `https://` 로 바꿔야 한다 (안 그러면 혼합 콘텐츠로 차단)

> ⚠️ **매칭은 좌표만으로 하면 안 된다.** 700m 안에서 좌표만 보면
> "김범우의 집터 ← 서울 명동성당(329m)", "진무영 순교성지 ← 성공회 강화성당"처럼
> **옆 건물 사진**이 붙는다. 좌표(1차) + 이름 일치(2차) 두 관문을 다 통과시켜야 하고,
> 시·군 이름만 겹치는 것은 제외해야 한다("나주 순교자 기념성당 ← 나주읍성").
> 그리고 **넣기 전에 반드시 이미지를 열어 본다** — 이번에도 위키미디어
> `Gusan Cathedral.jpg` 가 간판에 "대한예수교장로회 **구산교회**"라고 적힌
> **개신교 교회** 사진이었다. 8/23 FBI 경찰관 사고와 같은 유형이다.

#### ⚠️ 사진 용량 규칙 (2026-08-28 사고에서 나온 것)

**image_url 에 원본 주소를 그대로 넣으면 안 된다.** 8/28 실측에서 홈 화면이
이미지 12MB 를 내려받고 있었다(여사울 8.5MB·신리 13MB·홍주 13.2MB 등 원본 저장).
"링크가 멈춘다"는 제보의 원인이었다. 규칙:

- **700KB 를 넘는 사진을 넣지 않는다**
- 위키미디어는 원본이 아니라 **1280px 축소판**
  (`…/commons/thumb/<h>/<hh>/<파일>/1280px-<파일>`) 주소를 넣는다
- 국가유산청 등 축소판이 없는 출처는 **1600px 로 리사이즈해 `public/images/sites/` 에
  내장**하고 `/images/sites/…` 경로를 넣는다 (공공누리 제1유형은 변형 허용,
  출처 표기는 image_source 에 유지)
- 넣은 뒤 `scripts/tmp-image-size-audit.ts` 방식(Range 요청)으로 용량을 재확인한다

**사진이 없는 동안의 화면**: 상세 화면은 분류별 진한 색 판 + 상징으로 채운다
(`SiteThumbnail intensity="deep"`). 8/28 이전에는 밝은 회색 위에 흰 제목이라
**제목이 읽히지 않았다.** 목록 카드는 밝은 판(`light`)을 그대로 쓴다.

교구별 분포는 위 1번 표의 `사진` 열에 있다. **한 장도 없는 교구가 5개**다 —
**8/30 추가 시도 — 위키데이터 P18 경로 (6번째 경로, 2곳 건짐):**
위키데이터에서 한국의 성당·종교시설 중 대표 이미지(P18)가 붙은 1,806건을 받아
좌표 700m + 이름 일치 + 종류 관문(석탑·향교 등 배제)에 걸었다. 3건 통과 중
강릉 대도호부 관아는 옆 임당동성당 사진이라 버리고 2곳 반영:
김포 성체성지(옛 성전 석조 건물, 눈으로 확인), 용산 성직자 묘역(옛 용산신학교·
원효로성당 — 묘역 자체가 아니라 경내 건물이라 출처 문구에 그렇게 밝혔다).
둘 다 CC BY-SA 4.0 (Jjw). **이로써 자동 수집은 정말 소진** — 남은 157곳은 현장 촬영뿐이다.

⚠️ 위키미디어가 2026-08 무렵부터 임의 썸네일 크기를 거부한다(640px 실패,

새로 넣을 때 1280px 외의 크기를 쓰면 깨진다.

부산 11곳 · 안동 10곳 · 청주 7곳 · 광주 6곳 · 군종 1곳. 서울(12/25)과

#### AI 로 성지 사진을 만들지 않는다 (2026-08-27 결정)

2차적저작물이라 저작권이 안 풀리고, 무엇보다 **AI 가 그린 배티 순교성지는
배티 순교성지가 아니다.** 실제 순교지 자리에 지어낸 그림을 올리는 것은
CLAUDE.md 의 "더미 데이터를 화면에 남기지 않는다"에 정면으로 걸린다.
**사진이 없는 편이 가짜 사진보다 낫다.**
인스타 사진은 게시자에게 DM 으로 허락을 받는 것이 유일하게 안전한 길이다.

> `data/research/image_sourcing_summary.md` 는 **195곳 기준의 옛 집계**라
> 숫자를 쓰면 안 된다. 위 표가 최신이다.

```sql
select count(*) filter (where image_url is not null) as 사진있음,
       count(*) as 전체
from holy_sites;
```

촬영 로드맵은 `docs/30-content-ops/SNS-홍보/인스타그램-서울-콘텐츠-플랜.md` 에 5회차 동선으로 있다.

조사에서 발견 — 혼자 성지 사진 프로젝트를 하는 개인 계정이 있다(24번째 성지 진행 중).
핸들은 확인 못 했다. 인스타에서 `천주교 성지 사진 프로젝트` 로 찾아 협업을 검토할 만하다.
**무단 사용 금지. 정식 연락이 먼저다.**

| 로그인(SSO) 벽이라 첫 화면부터 못 봄 | 수원 · 부산 · 광주 |
| 주소 접속 실패(도메인 바뀐 듯, 확인 못 함) | 대구 · 인천 · 원주 · 전주(빈 페이지) |

안동교구는 성지 9곳 전부 사진이 있지만 출처·이용 안내가 없다. 사진은 있어도
**교구에 서면(이메일) 사용 허락을 받은 뒤에만** 넣는다. 지금 DB 의 사진 53장은 전부
라이선스(CC·공공누리)가 명시된 것이라 이 원칙을 여기서 깨면 안 된다.
허락을 받으면 `image_source` 에 "○○교구 제공(허락일)" 을 적고 1600px 로 줄여 내장한다(위 용량 규칙).

부수 발견: `catholic_directory` 에 TourAPI 이미지 주소(`tong.visitkorea.or.kr`) 38행이 저장돼 있다.
화면에는 안 쓰이지만 ADR 0002 원칙상 지워야 한다 — 아직 안 지웠다.
