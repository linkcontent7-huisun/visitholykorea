## 근거 — 수요조사 n=23 (2026-09-15 집계)

- 50대 이상 **87%** (20/23) → 짧은 영상, 큰 자막, 카카오톡으로 전달
- 가장 필요한 기능 1위 **성지 해설 56.5%**, 설명이 부족했던 경험 **100%** → 첫 메시지는 "해설"
- 가족·지인과 간다 **52%** → 한 사람이 링크를 보내면 일행이 함께 들어온다
- 못 간 이유 1위 "시간 없어서" 39%, 2위 "혼자 가기 부담" 26%
- 베타 테스터 지원 **14명, 연락처 12건 (모두 휴대전화 번호)**
- 자유의견: "순례자의 소감을 올려 다른 순례자가 참고하면 좋겠다" → 이미 있는 기능(성지 상세의 익명 소감 목록, `site_visit_notes` 뷰)

## 목표 숫자와 근거

**8주 뒤: 소감을 남긴 사람 20명 / 소감 50건.**

모두 **가정**이다. 1~4주 실제 수치를 보고 5주 차에 고친다.

| 단계 | 계산 | 결과 |
| --- | --- | --- |
| 테스터 | 연락처 12명 × 실제로 성지 가서 소감 남김 60% | 약 7명 |
| 지인 공유 | 7명 × 링크 받은 사람 평균 3명 × 소감까지 남김 25% | 약 5명 |
| 광고 | 50만 원 ÷ 클릭당 약 500원(**단가 확인 필요**) = 약 1,000클릭 × 소감 남김 1% | 약 10명 |
| **합계** | | **약 22명 → 목표 20명** |

소감 건수는 1인 평균 2.5곳(수요조사상 최근 1년 3곳 이상 순례 9/23명)으로 보고 50건.

**지금 몇 명인지(출발점)는 확인 못 했다.** 실행 첫날 로컬 세션에서 DB 의
`stamps` 중 `note` 가 비어 있지 않은 행 수·사람 수를 재서 여기에 적는다.

## 사용법 영상 3편 (각 15초 안팎)

사장님 제안은 9초였으나 **15초로 조정**. 50대 이상은 화면에서 누를 곳을 찾는 시간이 더 필요하다.

공통 원칙

- **실제 앱 화면 녹화** (휴대폰 기본 화면 녹화). AI로 만든 화면은 실제 앱과 달라 보여 쓰지 않는다
- 세로 화면, **큰 자막**, 누르는 곳에 동그라미 표시
- 소리 없이 봐도 이해되게 (단톡방에서는 대개 무음 재생)
- 마지막 2초는 항상 같은 화면: `visitholykorea.com` + "설치 없이 링크로"
- 녹화는 설정의 **큰 글자 모드를 켠 상태**로 (보는 사람이 자기 폰에서 똑같이 따라 할 수 있게)

### ① 성지에서 해설 듣기

| 초 | 화면 | 자막 |
| --- | --- | --- |
| 0~3 | 성지 앞 풍경 (직접 찍은 것) | "성지에 가도 설명이 없어서 아쉬우셨죠?" |
| 3~7 | 앱에서 성지 찾기 → 성지 상세 열기 | "링크를 누르고 성지를 고르세요" |
| 7~12 | 「오디오 가이드」 누르기 → 재생 | "이어폰을 끼고 걸으며 들으세요" |
| 12~15 | 마무리 화면 | "지금 108곳에서 들을 수 있어요" |

오디오 가이드가 있는 곳 수(108곳)는 9/20 기준이다. 촬영 전에 다시 잰다.
녹화할 성지는 **오디오 가이드가 있는 곳**으로 고른다.

### ② 스탬프 찍고 소감 남기기

| 초 | 화면 | 자막 |
| --- | --- | --- |
| 0~4 | 성지 상세 → 「순례 기록 남기기」 | "다녀오셨으면 도장을 찍으세요" |
| 4~9 | 「순례 스탬프 찍기」 → 한 줄 소감 쓰기 | "느낀 점 한 줄이면 충분해요" |
| 9~13 | 「내 순례 기록」에 도장이 쌓인 화면 | "다녀온 성지가 여권처럼 쌓여요" |
| 13~15 | 마무리 화면 | |

로그인이 필요한 단계다. 자막 한 줄로 "처음 한 번만 로그인"을 넣을지는 녹화하며 판단한다.

### ③ 지인에게 링크 보내기

| 초 | 화면 | 자막 |
| --- | --- | --- |
| 0~4 | 하단 넷째 탭 「홈화면 추가」 | "함께 갈 분께 보내 주세요" |
| 4~9 | 「링크 공유」 → 카카오톡 선택 | "카카오톡으로 바로 보낼 수 있어요" |

| 13~15 | 마무리 화면 | |

## 소감 → 카드뉴스

- 소감은 성지 상세에 이미 익명으로 공개된다. 그래도 **SNS에 옮길 때는 당사자에게 한 번 묻는다**
  (신앙 고백에 가까운 글이라 본인 뜻이 중요하다)
- 틀: 성지 사진 1장 + 소감 한 줄 + 성지 이름 + `visitholykorea.com`
- 사진은 **우리가 찍었거나 출처가 분명한 것만** (`SNS-레퍼런스-조사.md` 0장의 저작권 원칙)
- 올리는 곳: 카카오톡 채널, 네이버 밴드(50대 이상 이용이 많음), 페이스북

## 광고 50만 원 쓰는 법

| 순서 | 내용 | 금액 |
| --- | --- | --- |
| 1 | 소감 카드뉴스 2종으로 5일 시험 (50대 이상·천주교 관심사) | 10만 원 |
| 2 | 클릭당 비용과 **실제 소감으로 이어진 수**가 나은 쪽에 집중 | 40만 원 |

채널 후보는 **메타(페이스북·인스타그램) 광고**와 **카카오 광고**. 50대 이상 도달 비용과 종교 관심사
타깃 가능 여부는 **확인 필요** — 5주 차 전에 두 곳 광고 관리자에서 실제 단가를 보고 정한다.
클릭 수가 아니라 **소감 수**로 판단한다. 클릭은 많은데 소감이 0이면 그 광고는 끈다.

## 업데이트 때 테스터 자동 알림

연락처가 전부 휴대전화 번호라 **이메일 알림은 쓸 수 없다.**

| 방법 | 자동인가 | 비용 | 판단 |
| --- | --- | --- | --- |
| **카카오톡 채널 + 공지 메시지 (권장, 1단계)** | 반자동 — 업데이트 때 사장님이 3분 들여 발송 | 무료~소액 (**확인 필요**) | 지금 바로 준비 가능, 코드 변경 없음 |
| 앱 안 "새 소식" 표시 | 자동 — 배포하면 다음 접속 때 보임 | 0원 | 기능 추가라 **동결 뒤** |
| 웹 푸시 알림 | 자동 | 0원 | 아이폰은 홈화면 추가한 사람만 받음, 기능 추가라 **동결 뒤** |
| 알림톡 (카카오 비즈 메시지) | 완전 자동 | 건당 요금 + 사업자 인증 | 12명 규모엔 과하다 |

**권장 순서:** 지금 카카오톡 채널을 만들고 테스터에게 친구 추가를 부탁한다(첫 메시지에 넣음).
동결이 풀리면 앱 안 "새 소식"을 붙여, 채널 공지와 앱 안 표시가 같이 나가게 한다.
완전 자동(배포하면 채널 메시지가 저절로 나가는 것)은 카카오 채널 API 조건을 **확인한 뒤** 결정한다.
