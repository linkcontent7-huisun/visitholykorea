# SNS 레퍼런스 조사 — 성지·성당·가톨릭 콘텐츠

조사일: 2026-08-07

`인스타그램-서울-콘텐츠-플랜.md` 를 쓸 때 레퍼런스 없이 트렌드 자료만 보고 짰다.
실제로 이 주제를 다루는 계정들이 무엇을 어떻게 하는지 확인하고, 플랜에서 틀린 부분을 잡는다.

## 0. 조사 방법과 한계 — 먼저 읽을 것

**남의 사진과 캡션을 가져와 모아 두지 않았다.** 두 가지 이유다.

1. **저작권.** 다른 계정의 사진·글은 그들의 저작물이다. 우리 저장소에 복제해 두면
   나중에 우리 콘텐츠에 섞여 들어갈 위험이 있고, 공모전 제출물에 남의 저작물이
   들어가면 그것만으로 실격 사유가 된다.
2. **기술적 제약.** 인스타그램은 스크래핑 도구가 지원하지 않는다(Firecrawl 명시적 미지원).
   검색 엔진에 노출된 게시물 제목·설명 수준만 확인 가능했다.

그래서 이 문서가 담은 것은 **"누가 무엇을 어떤 방식으로 하는가"** 다.
사진이 필요하면 우리가 찍는다(촬영 로드맵). 글이 필요하면 우리 DB에서 쓴다.
레퍼런스는 **참고할 접근법**이지 가져다 쓸 소재가 아니다.

계정을 직접 보시려면 아래 표의 핸들로 인스타그램에서 검색하시면 된다.

## 2. 해시태그 실측 — 플랜의 오류를 발견했다

### ⚠️ `#성지순례` 는 가톨릭 태그가 아니다

기존 플랜은 `#성지순례` 를 **고정 5개** 중 하나로 넣었다. 실제로 검색해 보니
이 태그는 완전히 오염돼 있다.

| 실제로 이 태그를 쓰는 것 | 예시 |
| --- | --- |
| 애니메이션 성지순례 | 오사카 애니 성지순례, 체인소맨 로케이션 |
| 아이돌 팬덤 | `#btspilgrimage` — BTS 연고지 순례, 게시물 1천여 건 |
| 개신교 | 이스라엘 성지순례 |
| 불교 | 33관음성지순례 |
| 맛집·핫플 | "인스타 성지" — 카페·거리 |
| 밈 | 연예인 SNS에 몰려가 댓글 다는 행위 |

고정 태그 다섯 자리 중 하나를 **엉뚱한 유입에 쓰고 있었다.** 도달이 흩어지고,
들어온 사람도 우리 콘텐츠와 무관해 이탈한다.

### 실제 가톨릭 계정들이 쓰는 태그

검색 결과에서 관찰된, 실제로 가톨릭 성지 게시물에 붙는 조합:

```
#천주교성지순례   #한국천주교성지순례   #성당순례
#순례스타그램     #성지순례기록        #가톨릭  #천주교
#평화를빕니다
```

`#순례스타그램` 은 이 커뮤니티가 실제로 쓰는 자생 태그다(마석성당 등에서 확인).

### 수정안

```diff
  [고정 5개 — 항상]
- #비지트홀리코리아 #visitholykorea #성지순례 #서울성지 #천주교
+ #비지트홀리코리아 #visitholykorea #천주교성지순례 #서울성지 #천주교

  [커뮤니티 태그 2~3개 — 새로 추가]
+ #순례스타그램 #한국천주교성지순례 #성당순례
```

`#성지순례` 를 완전히 버리진 않는다. **장소 태그 자리에서 가끔** 쓰면
바깥 유입을 노릴 수 있다. 다만 고정 자리에서는 뺀다.

## 3. WYD 2027 — 이게 축을 바꾼다

조사 중 계속 걸린 것이 **2027 서울 세계청년대회**다. 확인된 사실만 적는다.

| 항목 | 확정 내용 |
| --- | --- |
| 본대회 | **2027년 8월 3일 ~ 8일**, 서울 |
| 교구대회 | **2027년 7월 29일 ~ 8월 2일** (4박5일), **서울 제외 15개 교구** |
| 예상 참가 | 최대 80만 명 (자료에 따라 70만~100만), 해외 참가자 20만~30만 명 추산 |
| 수호성인 | 요한 바오로 2세, **성 김대건 안드레아와 동료 순교자**, 프란치스카 카브리니, 조세피나 바키타, 카를로 아쿠티스 |
| 성지 프로그램 | **솔뫼성지** 젊은이와의 대화, **해미읍성** 관련 일정 |
| 개최지 후보 | 서울월드컵경기장·광화문광장 (개막), 올림픽공원·여의도한강공원 (폐막) |

출처: 나무위키, 가톨릭신문(2025-08-04), CBCK 공식 발표, wydseoul.org

### 왜 이게 결정적인가

**우리 앱이 겨냥해야 할 수요가 날짜와 규모까지 확정된 채로 존재한다.**

1. **교구대회가 15개 교구로 흩어진다.** 우리 DB가 커버하는 범위가 정확히 그
   15개 교구 208곳이다. 우연이 아니라, 한국 천주교의 행정 단위가 그렇다.
2. **해외 청년 20~30만 명이 온다.** 그들에게 한국어 성지 설명은 읽히지 않는다.
   **영어 번역 206곳(51,899자)이 왜 필요한지**에 대한 답이 여기 있다.
3. **수호성인이 김대건 신부와 순교자들이다.** 우리 DB의 순교사 콘텐츠가
   곧 WYD 학습 자료가 된다.
4. **솔뫼성지·해미읍성이 공식 일정에 들어 있다.** 둘 다 우리 DB에 있다.
5. **분산이 실제 과제가 된다.** 수십만 명이 좁은 기간에 몰린다. "붐비는 곳 대신
   조용한 성지"라는 우리 기능이 가상의 문제가 아니라 실제 문제를 푼다.

오늘(2026-08-07) 기준 **교구대회까지 약 356일** 남았다.

### 콘텐츠에 어떻게 쓸 것인가

- **D-day 카운터**를 정기 코너로. "WYD까지 D-356, 오늘의 성지" 형식은
  매일 발행하는 명분과 긴장감을 동시에 준다.
- **수호성인 5인 시리즈**. 김대건 신부는 우리 DB에 자료가 많다.
  카를로 아쿠티스(2006년 선종, 밀레니얼 성인)는 10·20대 관심을 끌 소재다.
- **교구대회 15개 교구 소개 시리즈**. 우리 DB가 그대로 목차가 된다.
- **영어 병기**를 지금부터. 해외 청년들이 검색을 시작하면 이미 쌓여 있어야 한다.

## 4. 참고할 접근법 — 관찰된 것들

레퍼런스 계정들에서 **방식**으로 배울 점만 뽑았다. (소재를 베끼지 않는다.)

| 관찰 | 우리에게 주는 시사점 |
| --- | --- |
| 드론·항공 앵글이 반응이 좋다 (치명자산성지 릴스에서 확인) | 서울 성지는 도심에 있어 드론이 어렵다. 대신 **고층 건물 대비 성당** 같은 대조 구도로 대체 |
| 한·영 병기 캡션을 쓰는 계정이 이미 있다 (`[KOR/ENG]` 표기) | WYD 대비 표준으로 삼을 것 |
| "함께 순례하고 싶은 분에게 공유하세요" 식 CTA | 공유율이 알고리즘의 핵심인데, 이 계정들은 이미 직접 요청하고 있다. 우리도 넣는다 |
| 건축 정보(설계자·건축연도)를 캡션에 넣는 패턴 | 우리 DB의 `history` 필드가 이 용도에 그대로 맞는다 |
| 순례 배지·스탬프 수집 문화가 존재 | 우리 앱의 순례 여권(스탬프) 기능과 정확히 맞물린다. 콘텐츠로 밀 만하다 |
| 접근성 후기(차량 진입, 경사)가 자발적으로 공유됨 | 수요가 검증된 정보. DB에 필드로 넣을 값어치가 있다 |

## 6. 확인하지 못한 것 — 정직하게 남긴다

- **개별 게시물의 실제 참여 수치**(좋아요·공유·저장). 인스타그램 스크래핑이
  막혀 있어 확인 불가. 벤치마크 수치가 필요하면 계정에 직접 들어가 눈으로 세야 한다.
- **성지 사진 프로젝트 계정의 핸들.** 게시물은 검색에 잡히나 계정명이 확인되지 않았다.
  협업을 검토한다면 인스타그램에서 `천주교 성지 사진 프로젝트`로 직접 찾아야 한다.
- **본당 단위 계정의 전체 규모.** 표본만 확인했다. 전수 조사는 하지 않았다.
