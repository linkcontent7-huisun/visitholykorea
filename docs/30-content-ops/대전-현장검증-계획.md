## 🗺️ 대전교구 27곳 실측 현황 (2026-08-12, DB 직접 조회)

> **이 절은 처음에 추측으로 쓰였다가 실측으로 다시 썼다.**
> 이전 판은 "좌표 미확보 5~7곳"이라 적고 여사울성지·계산동 성당·목동성당·상당산 성지를
> 대상으로 올려 두었다. 실제로는 **좌표가 27곳 전부 있고**, 뒤 세 곳은 대전교구
> `holy_sites` 에 아예 없는 이름이다(상당산은 청주교구). 그대로 갔으면
> 있지도 않은 성지를 찾아 헛걸음할 뻔했다.

### 결측 요약 — 병목은 좌표가 아니라 **사진**이다

| 항목 | 확보 | 미확보 | 판정 |
| --- | --- | --- | --- |
| 좌표 (`lat`/`lng`) | **27 / 27** | 0 | ✅ 갈 필요 없음 |
| 감정 태그 | **27 / 27** | 0 | ✅ 현장에서 **검증만** |
| 소개글 · 역사 | **27 / 27** | 0 | ✅ |
| 영어 번역 | **27 / 27** | 0 | ⚠️ 전부 `machine`(기계 초벌) — 사람 검수 필요 |
| **대표 사진** | **4 / 27** | **23** | 🔴 **현장에 가야만 생긴다 = 이번 출장의 목적** |
| 전화번호 | 23 / 27 | 4 | 🟡 현장에서 받아오면 됨 |

**사진이 이미 있는 4곳**: 공세리성지성당 · 솔뫼성지 · 신리성지 · 여사울성지
→ 촬영 우선순위 낮음. 다만 기존 이미지의 **출처·라이선스 확인**은 따로 필요하다.

**전화번호 없는 4곳**: 공세리성지성당 · 산막골·작은재 성지 · 천주교 대흥동 교회 · 해미순교성지
→ 현장 게시판에서 받아온다. (산막골·작은재는 관리 주체 자체를 확인해야 한다)

### 좌표는 이미 DB 값을 믿어도 된다

이전 판에 적혀 있던 좌표 몇 개가 실제 DB 값과 달랐다 —
솔뫼 `36.8667,126.6667`(문서) vs `36.8202,126.7862`(DB), 갈매못 `36.3972,126.545` vs `36.4355,126.5180`.
**문서 쪽이 어림값이었다.** 현장에서는 DB 값을 기준으로 삼고,
50m 이상 어긋날 때만 재측정한다(→ 「좌표 정확도」 절).

## ✅ 현장 검증 체크리스트

각 성지 방문 시 확인할 항목:

### 1️⃣ **위치 정보** (검증만 — 수집할 것이 아니다)
```
□ 앱 화면의 좌표가 실제 위치와 50m 이내인지만 본다
□ 어긋나면 그때만 GPS 재측정 + 구글맵 핀 대조
□ 전화번호는 아래 4곳에서만 받아온다:
   공세리성지성당 · 산막골·작은재 성지 · 천주교 대흥동 교회 · 해미순교성지
```

### 2️⃣ **사진 촬영**
```
□ 정면 전경 1장 (홈 화면 카드용)
□ 입구/표지판 1장 (위치 확인용)
□ 주요 시설 2-3장 (상세 페이지용)
□ 스탬프/안내판 1장 (순례자 정보용)
□ 접근성 정보 1장 (주차/화장실 위치)

촬영 가이드:
- 해상도: 최소 1920×1440 (고밀도 스크린 대응)
- 시간: 오전 9-11시, 오후 3-5시 (역광 피하기)
- 포맷: JPG (압축), WebP (차후 최적화)
- 저장: Supabase 또는 로컬 /photos/{diocese}/{site-id}
```

### 3️⃣ **붐빔 지수 검증**

방문 당일 **오늘의 쉼표 화면**에서:
```
□ 계산된 붐빔 지수 기록
□ 실제 현장 인파 수준 기록
   └ 0 = 아무도 없음
   └ 1 = 5명 미만
   └ 2 = 10명 미만
   └ 3 = 20명 미만
   └ 4 = 50명 이상
   └ 5 = 붐빔 (주차 어려움)

□ TourAPI "주변 관광지" 실제 거리 확인
   └ 반경 1km 내 실제 명소/음식점 개수
   └ API와 현실 괴리도 기록

□ 축제/행사 유무 확인 (당일 근처에서 열리는 것)
```

### 4️⃣ **접근성 정보**

고령 순례자 기준:
```
□ 주차장 위치 (성지 바로 앞인가? 100m 떨어졌는가?)
□ 화장실 (성지 내 / 근처 / 없음)
□ 경사도 (평탄 / 완만 / 가파름)
□ 도보 거리 (주차장 → 성지 메인 시설)
□ 휠체어 접근 가능 여부
```

### 5️⃣ **감정 태그 검증** (부여 아님 — 27곳 전부 이미 부여되어 있다)

기존 규칙:
```
- 위로: 고난 역사 + 순교 의미가 강한 곳
- 새출발: 부활/희망 메시지 (부활성지, 새로운 시작 기원)
- 평온: 자연 풍경 + 조용한 분위기
- 치유: 영적 위로 + 휴식 기능 (명상, 기도 공간)
- 감사: 은총과 축복 관련 지점

현장에서 확인:
□ 기존 태그가 맞는가?
□ 추가 태그가 필요한가? (예: 자연 성지는 '평온' + '치유')
```

## 🔑 중요 체크포인트

### 1️⃣ **시간 관리**

⏰ **각 성지당 예상 체류 시간: 30분**

```
도착 (5분)
  ↓
좌표/사진 (10분)
  ↓
앱에서 붐빔 지수 기록 (5분)
  ↓
관계자 인터뷰 & 감정태그 확인 (10분)
  ↓
떠남

한 날짜 3-4곳 방문 가능
```

### 2️⃣ **데이터 신뢰성**

```
✅ 이상했던 지수:
   - 죽림동 순교성지: 74점 (춘천 워터페스티벌 때문)
   - 갈매못: 15.2점 (보령머드축제 때문)
   
   → 현장에서 실제 인파 확인 필수
   
⚠️ 좌표 미확보 지점: 없음 (27곳 전부 DB에 있음, 2026-08-12 실측)
   → 좌표는 "채우는" 항목이 아니라 "50m 이상 어긋나는지 보는" 항목이다
   → 산지(성거산·다락골 등)에서 GPS가 흔들리면 DB 값을 그대로 둔다
```

### 3️⃣ **안전 & 예의**

```
□ 성지 관계자에게 방문 목적 설명 (순례 앱 데이터 검증)
```

## 💡 팁

### 효율적인 촬영

```
아침(9-11시) → 햇빛 각도 좋음, 관광객 적음
     ↓
정면 + 입구 기본 촬영
     ↓
오후(3-5시) → 조명 변할 때 다시 한 번
     ↓
RAW + JPG 동시 저장 (나중에 색감 조정 가능)
```

### 좌표 정확도

```
GPS만 믿지 말고:
1. 구글맵 핀과 비교
2. 현지 표지판과 비교
3. 3개 위치 모두 일치하면 확정
4. 차이 > 50m면 재측정 또는 관계자 문의
```

### 데이터 손실 방지

```
매일 끝나면:
1. 사진 → Google Photos 자동 백업
2. 구글 시트 → 시간 자동 저장 (확인)
3. GPS 데이터 → JSON export
4. 노트북에도 사본 저장
```
