# 벤치마킹 — 칠곡군 「시간여행자의 고백 Go-Back」 (2026-10-19)

> 사장님이 10/17(토) 5회차에 직접 참가. 자료: 안내문 이미지·카카오 오픈채팅 캡처·칠곡군 인스타 캡처(10/19 오전 11:19~11:20 촬영).
> 방법은 `.claude/skills/program-benchmark/SKILL.md`. 채팅 캡처의 참가자 이름은 개인정보라 옮기지 않았다.

## 1. 프로그램 개요 (✅ 안내문·타임테이블)

- 주관: 칠곡군 생생국가유산 운영사무국. 후원 로고: 국가유산청 · 경상북도 · 칠곡군.
- 13:50 왜관역 집결 → 신나무골성지 → 가실성당 → 왜관수도원 → 석식(자유) → 버스로 대구 → 계산성당 → 청라언덕 야행(~21:00). 투어 차량 번호까지 안내.
- 참가비 2만원 중 1만원을 지역 상품권으로 돌려받아 석식에 사용 (**사장님 말씀** — 안내문에는 「칠곡사랑상품권 배부」만 확인).

## 2. 일곱 칸 분석

| 칸 | 칠곡이 한 것 | 근거 |
|---|---|---|
| 발견 | 군 공식 인스타(@lucky7_chilgok)에 **코스 소개 10장 캐러셀**(10/1) + 「D-1 관전 POINT」 + 회차별 모집 + **영어판** 모집 카드 | ✅ 게시물·프로필 격자 캡처 |
| 신청 | 프로필 링크의 **네이버폼**, 모집 카드의 **QR(탑승권 모양)** | ✅ 프로필·모집 카드 |
| 가격 | 2만원 → 1만원 환급(식사). 지역 상권으로 돈이 돌아가는 구조 | 주장 |
| 사전 안내 | 카드뉴스형 안내문(집결지 **위성 지도에 표시**) + 글 안내, 오픈채팅방 개설 | ✅ |
| 당일 운영 | 「6:10에 이 자리에서」 식 시각 공지, 맛집 리스트 4장, 운영진이 단체사진·현장 사진 묶음 공유 | ✅ 채팅 |
| 사후 | 감사 메시지, **인증 이벤트**(해시태그 3 + 계정 태그, **10/20까지 링크를 단체방에 제출**, 5명 추첨 5천원 쿠폰) | ✅ 채팅 |
| 신뢰 | 모든 카드 하단에 후원기관 로고 | ✅ |

**캐러셀 구조(10장)**: 표지 → 코스 개요 → 장소별 카드 1장씩(사진 1 + 설명 3줄) → 야행 자유 관람 → 요약 문구. 같은 일러스트 틀을 모든 카드에 씀.

## 3. 수치와 해석

- 칠곡군 계정: 게시물 370 · 팔로워 4,484 · 팔로잉 223 (10/19 캡처 값).
- 코스 소개 캐러셀: 좋아요 20 · 리포스트 1 · 공유 3 (10/1 게시, 10/19 캡처). 같은 계정 버거페스타 게시물은 좋아요 41 · 공유 17.
- **❓ 추측**: 좋아요 20은 팔로워의 약 0.4%라 **인스타 반응만으로 모집이 됐다고 보기 어렵다.** 군 계정의 신뢰, 국가유산청·도 후원, 1만원 환급으로 실부담 1만원이라는 가격이 더 컸을 가능성. ⏳ 실제 모집 인원·마감 속도는 확인 못 함.
- 비지트홀리 계정(@visitholykorea, 같은 시각 캡처): **게시물 0 · 팔로워 1 · 팔로잉 4.** 자체 도달이 아직 없다.

## 4. 비지트홀리 적용안 (게시는 화면을 안 바꾸므로 동결과 무관)

| 우선 | 칠곡에서 가져올 것 | 비지트홀리 버전 |
|---|---|---|
| 1 | 프로필 링크 한 개로 끝나는 동선 | 링크 = 웹앱 주소 하나. 소개문에 「성지 213곳·6개 국어·오디오 가이드」(213곳은 10/14 실측) |
| 2 | **코스 1개 = 캐러셀 10장** | 도슨트 원고가 끝난 성지부터 「성지 순례 코스」 카드. 장소 1곳 = 사진 1 + 3줄. 마지막 장 = 웹앱 링크/QR |
| 3 | 영어판 병행 | 앱이 이미 6개 국어 — 같은 카드를 영어로 한 벌 더 (칠곡 영어판 카드 확인됨) |
| 4 | 「D-1 관전 포인트」 연재 | 「순례 가기 전날 챙길 것」 시리즈 (전례 시간·복장·주의) — ❓ 내용은 사실 확인 후 |
| 5 | 인증 이벤트(해시태그+계정 태그+마감+링크 제출) | 앱의 「순례 기록 남기기」와 연결. 경품은 **사장님 예산 결정 필요** (소액 쿠폰 vs 비금전 보상) |
| 6 | 후원기관 로고로 신뢰 | 로고가 없으니 카드마다 **근거 출처 한 줄**(공식 성지 자료) |

**규모 차이 대응**: 팔로워가 없으므로 첫 4주는 ① 팔로잉 중인 가톨릭 청년·교구 계정과 협업·공유 요청 ② 사장님 지인·본당 공유로 첫 팔로워를 모은다 (❓ 효과는 해 봐야 안다).

## 5. 사장님 결정이 필요한 것

1. 경품 예산을 쓸지, 쓴다면 얼마까지.
2. 비지트홀리가 순례 **행사를 직접 열 계획**이 있는지 (있으면 모집·가격·당일 운영 칸까지 적용, 없으면 인스타·인증 이벤트만).
3. 첫 코스로 어느 성지를 쓸지.
