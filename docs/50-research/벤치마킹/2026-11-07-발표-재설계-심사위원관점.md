## 1. 심사위원이 좋게 볼 점 → 앞에 크게
| 강점 | 어디서 보여 주나 |
|---|---|

| 접수 → 집계 → 엑셀이 **오늘 실제로 작동**(11/7 시험 접수·엑셀 확인) | 8번 장 실제 화면 캡처 + 시연 |

## 2. 질문할 점 → 답을 미리 슬라이드나 말에 넣음
| 예상 질문 | 답(한 줄) | 어디에 |
|---|---|---|
| 성심당·성당과 협의됐나? | 아직. 아이디어 단계이며 협의 순서는 12번 장 | 12번 장 |
| 누가 돈을 내나? | 기관·지자체의 운영 위탁(활용사업 예산의 홍보물비·업무위탁 항목). 금액은 협의 | 10번 장 |
| 이미 같은 코스 기사·빵시투어가 있는데? | 기사는 소개만, 우리는 대기시간 맞춤 이야기 + 등록→접수→집계를 한 번에 | 3·4번 장, 말로 |
| 신자가 아니어도 오나? | 국가등록문화유산·문화재 체험여행. 대상은 가족·성인·어르신 누구나 | 4번 장 말로 |
| 혼자 운영 가능한가? | 이미 혼자 AI 와 함께 사이트를 운영 중. 2호부터는 같은 틀 반복 | 9번 장 말로 |
| AI 가 틀리면? | 우리 자료 안에서만 답, 사람이 출처 검수 | 10번 장 |
| 수요가 진짜 있나? | 성심당 하루 약 2만 5천 명(기사). 실제 접수 실적은 아직 없음 — 정직하게 | 2번 장, 말로 |

## 3. 나쁘게 볼 점 → 줄이거나 정직하게
| 약점 | 대응 |
|---|---|
| 기능이 8가지나 돼서 산만해 보임 | 표를 빼고 「본선에선 약속한 3가지」만 크게(7번 장). 8가지는 제출 제안서에 있음 |
| 협의가 안 된 상태 | 숨기지 않고 「아직 정할 것」 한 장(12번)으로 |
| 종교 편향으로 보일 수 있음 | 「성당」보다 「문화유산·이야기·하루 여행」을 앞에 |
| 숫자 근거가 기사 1~2건 | 숫자는 2번 장에만, 출처를 작게 표시 |
| 슬라이드가 AI 티(색 띠·동그라미 번호·알약 모양·장마다 꼬리말) | 실제 화면 캡처를 크게, 장식 줄이고, 꼬리말은 출처가 필요한 장에만 |
