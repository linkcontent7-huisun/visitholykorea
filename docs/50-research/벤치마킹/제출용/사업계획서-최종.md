# 사업계획서 — 함께 가는 성지 하루

**아이디어명**: 함께 가는 성지 하루 — 아이와 떠나는 가톨릭 국가유산 체험 코스·접수 앱  
**팀명(대표자)**: visitholykorea (【대표자 이름】)

## 1. 문제인식 (Problem)

**누가, 어떤 불편을 겪는가**

주말에 아이와 갈 체험을 찾는 부모는 정보를 여러 사이트에서 따로 찾고, 코스를 직접 짜고, 신청도 곳곳에서 따로 합니다. 국가유산으로 등록된 가톨릭 성지·성당은 건축과 역사가 풍부하고 체험 프로그램도 늘고 있지만, 종교가 없는 부모는 "아이와 가도 되는지, 무엇을 하는지, 근처에서 뭘 더 볼 수 있는지"를 한곳에서 알 수 없습니다. 운영 기관도 프로그램을 올리고 접수받을 창구가 따로 없습니다.

**문제가 있다는 근거**

| 근거 | 출처 |
|---|---|
| 국가유산청은 「2026년 우리고장 국가유산 활용사업」 379건을 선정했습니다(전년보다 24건 증가). 이 중 생생 국가유산 135건에 가톨릭 유산 사업이 최소 4건 있습니다(칠곡 홀리데이, 당진 성지의 숨결, 수원 2027 세계청년대회 기념 순교 터 이야기, 아산 공세리). | 국가유산청 보도 2025.9.12 (thefestival.co.kr/news/all/4081) |
| 경북 칠곡 "왜관 홀리 페스티벌"(2026.9.4~6, 무료)은 수도원 투어, 스탬프 투어, 묵주·키링 만들기, 어린이 공연, 왜관수도원~가실성당 셔틀을 한 행사로 묶었습니다. | 한국관광공사 대한민국 구석구석 축제 페이지 (2026.8.4 수정) |

| 충남 당진시는 2026년 생생국가유산 사업으로 솔뫼성지·합덕성당·신리성지를 잇는 성지 트레킹, 김대건 신부 RPG 미션, 머그컵·향수 만들기를 운영합니다. 기사는 2027 천주교 세계청년대회를 앞둔 순례객 유치 기반으로 설명합니다. | 뉴스코리아 2026.6.30 |
| 성인 대상 가톨릭 체험인데도 아동을 동반한 가족의 신청이 많다는 현장 관찰. 수치는 아직 없어, 시범 운영에서 접수 시 아동 수·나이를 집계해 확인합니다. | 대표자의 현장 관찰 |

가톨릭 국가유산 체험을 코스로 엮고 접수까지 이어 주는 창구는 우리가 찾아본 범위에서는 확인되지 않았습니다.

## 2. 실현가능성 (Solution)

성지·성당과 인근 관광지를 AI가 아이 연령에 맞춰 하루 코스로 엮고, 기관이 올린 체험 프로그램을 눌러 접수하는 반응형 웹앱입니다.

**핵심 기능과 사용 흐름**

| 단계 | 방문자(부모) | 제공자(수도원·본당·문화원) |
|---|---|---|
| ① | 지역과 성지를 고르고 아이 나이·소요 시간 선택 | 체험 이름·장소·날짜·정원·대상 연령·가격 등록 |
| ② | AI가 인근 관광지·식당을 엮은 하루 코스 생성 | 등록 즉시 방문자 목록에 카드로 표시 |
| ③ | 코스 안의 체험 카드를 눌러 접수(성인·아동 수, 아동 나이) | 접수 현황과 정원 확인 |
| ④ | 접수 후 코스·스탬프를 앱에서 확인 |  |

**벤치마킹을 기능에 반영한 부분**

| 벤치마킹 대상의 방식 | 우리 기능 |
|---|---|
| 백제문화원: 구별로 주제를 정한 답사 코스 | 코스에 테마 선택(건축, 순교·박해 역사, 근대 유산, 자연·순례길) |
| 백제문화원: 사전교육, "왜 여기 있을까?"로 묻는 탐정놀이식 해설 | 출발 전 아이용 미리 보기 카드, 현장에서 질문하는 AI 가이드 |
| 백제문화원: 폴라로이드로 기록하는 체험 | 스탬프·인증샷 기록 |
| 백제문화원: 초등 교과서 연계, 정규·방학 편성 | 아동 연령별 코스, 방학·주말 시즌 추천 |
| 왜관 홀리 페스티벌: 수도원~성당 셔틀로 묶은 확장 코스 | 인근 명소를 자동으로 잇는 코스 생성 |
| 놀토: 대상별 카드와 접수 | 카드형 프로그램 목록과 접수 |

**AI 바이브코딩으로 만든 것**

이미 만든 것(기존 앱): 한국 가톨릭 성지 200여 곳 데이터, 출발지·시간 조건으로 성지와 주변 관광지를 엮는 코스 추천(관광공사 정보는 실시간 호출), 순례 여권(스탬프), AI 가이드, 6개 언어 화면. 웹·Android·iOS를 한 코드베이스로 지원하며 https://visitholykorea-app.vercel.app 에 배포되어 있습니다.

이번 대회에서 만들 것: ① 아이 동반 조건의 가족 코스 생성, ② 제공자 프로그램 등록 화면, ③ 방문자 접수 화면과 접수 목록. 결제는 제외하고 접수만 구현합니다.

사용한 AI 도구: Claude Code, Codex. 기능을 말로 설명하고 AI가 작성한 코드를 실행·확인하는 방식으로 앱 전체(성지 화면, 지도, 코스, AI 가이드, 다국어)를 만들었습니다. 앱 안의 AI 가이드는 Claude를 사용합니다.

결과물 화면: 【캡처 3장 삽입 — 홈, 성지 목록, 지도】

**코스 예시(본선 시연용)**

아산 공세리성당(충청남도 기념물 제144호)을 출발점으로 인근 관광지를 엮은 하루 코스. 이동 시간은 지도 기준으로 코스 화면에 표시합니다.

**접수 항목과 개인정보**

보호자 이름·연락처, 성인·아동 수, 아동 연령대, 개인정보 동의, 취소 정책 확인만 받습니다. 아동 이름과 생년월일은 받지 않습니다. 만 14세 미만 아동 정보는 개인정보 보호법 제22조의2에 따라 보호자의 동의를 받습니다.

**신뢰 장치**

AI 답변은 직접 수집한 성지 데이터 안으로 제한하고, 데이터에 없으면 "모른다"고 답합니다(종교·역사 정보 오류 방지). 한국관광공사 관광 정보는 저장하지 않고 요청 때마다 실시간으로 불러옵니다.

## 3. 성장전략 (Scale-up)

**목표 고객**

| 구분 | 내용 |
|---|---|
| 핵심 | 초등학생 전후 자녀와 하루 나들이를 가는 부모(종교 무관) |
| 제공자 | 수도원, 본당, 성지 관리 기관, 문화원 |
| 발주자 | 국가유산 활용사업을 운영하는 지자체 |

**알리는 방법**

① 지자체 국가유산 활용 행사에 코스·접수 창구로 연결(왜관 홀리 페스티벌처럼 행사별 접수 페이지), ② 체험 후 스탬프·인증샷 SNS 공유, ③ 맘카페·학부모 커뮤니티·지역 문화원 채널.

**단계별 계획**

| 시기 | 내용 |
|---|---|
| 1단계 | 대전·충남 가톨릭 국가유산 3~5곳에서 시범 운영, 기관 의견 수집 |
| 2단계 | 지역 확대(성지 200여 곳 전체), 지자체·문화원 행사 접수 대행 |
| 3단계 | 천주교 외 종교·역사 유산으로 확장, 해외 방문객(다국어 화면) 대응 |

**수익화 계획(검토 중)**

① 지자체·문화원의 코스 기획·접수 관리 대행, ② 기관 이용료(초기 무료), ③ 소액 유료 체험 수수료, ④ 스탬프·배지 굿즈. 구체적 금액은 시범 운영 후 정합니다.

**위험과 대응**

성당·성지 소유 기관(교구 등)과의 협의가 필요하므로 시범 단계에서 먼저 합의합니다. 접수 시 개인정보는 동의를 받고 최소한만 수집하며, 아동 정보는 나이만 받습니다.
