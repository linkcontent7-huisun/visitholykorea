# 아이디어 제안서 — Visit Holy Korea

**가톨릭 국가유산과 인근 문화재·볼거리를 잇는 체험여행 프로그램을 계속 만들어 가는 플랫폼 (1호: 「하늘에서 빵이 내린다면」, 대전)**  
**제안자**: visitholykorea (노희선)

## 1. 한 줄 아이디어

이미 운영 중인 **Visit Holy Korea(https://visitholykorea.com)**를 거점으로, 국가·시도 지정과 등록으로 보호받는 가톨릭 문화유산과 그 **인근 문화재·볼거리를 엮은 체험여행 프로그램을 계속 개발하고, 홍보하고, 접수**한다. 1호는 대전의 「하늘에서 빵이 내린다면」이다.

## 2. 고객은 누구인가

| 고객 | 누구 | 지금의 불편 |
|---|---|---|
| **돈을 내는 고객** | 프로그램을 여는 기관(성당·문화원·전시관)과 문화유산 활용사업을 신청하는 지자체 | 프로그램을 열고, 알리고, 접수받고, 결과를 모으는 일을 따로따로 해야 한다 |
| **쓰는 사람** | 성당·성지와 인근 명소를 하루 여행으로 즐기려는 아이 동반 가족, 성인, 노인 동반 가족 | 가톨릭 문화유산 정보와 인근 볼거리, 신청이 흩어져 있다. 서울 도보 순례는 선착순·계좌이체 접수이고, 대전 성심당→대흥동성당 코스는 기사로만 소개되어 있어 체험과 접수로 이어진 곳을 찾기 어렵다(찾아본 범위) |

## 3. 고객에게 주는 가치

| 고객 | 받는 가치 |
|---|---|
| 기관·지자체 | ① **이미 운영 중인 사이트가 홍보 창구**가 된다(성지 200여 곳, 6개 언어 화면) ② 프로그램을 **한 번 등록하면** 접수 페이지, 안내 문자, SNS 카드가 만들어지고 참가자 수·연령대·만족도가 한 화면에 모인다 |
| 방문자 | ① 성당 정보와 **인근 문화재·볼거리를 하루 코스로 한곳에서** 본다 ② 성인·아동·노인 수를 **한 화면에서 바로 접수** ③ 이야기가 있는 체험을 **계속 새로 만난다**(시리즈) |

**1호 「하늘에서 빵이 내린다면」(대전)**: 성심당 대기시간에 맞춘 오디오 이야기(**줄 사이 20분**), 대흥동성당 **종지기를 찾습니다**(작은 종 기념품), 선비의 집과 선교사 집을 비교하는 **두 집 비교 관찰**(동춘당·한남대 선교사촌), 조부모와 손주의 **3세대 질문 카드**. 대흥동성당은 국가등록문화유산이고, 옛 충남도청 일대와 한남대 선교사촌(대전시 문화유산자료)이 이어진다. 코스는 **원도심 도보**(대전역·성심당 → 대흥동성당 → 전시관)와 **대덕구**(계족산 황톳길 한 구간 → 동춘당 → 한남대 선교사촌을 살짝 둘러보기) 중에서 고를 수 있다.

## 4. 바이브코딩으로 어떻게 구현하나

**이미 만든 것**: Visit Holy Korea 사이트·앱(웹·Android·iOS 한 코드베이스), 성지 200여 곳 데이터, 출발지·시간 조건으로 인근 관광지를 엮는 코스 추천(관광공사 정보를 실시간 호출), 순례 여권, AI 가이드, 6개 언어 화면.

**이번에 새로 만들 5가지** (Claude Code와 Codex에 기능을 말로 설명하고, AI가 쓴 코드를 직접 실행해 확인하는 방식)

| # | 만들 것 | 만드는 방법(구상) |
|---|---|---|
| 1 | 프로그램 카드와 접수 화면 | 성인·아동·노인 수, 이동 편의, 동의 항목을 정해 말로 설명 → AI가 화면·저장 코드 작성 |
| 2 | 오디오 이야기 재생 | 원고는 AI가 초안, **사람이 출처를 확인해 확정**. 앱 안에서 재생 |
| 3 | 대기시간 → 이야기 추천 | 분 단위 입력에 맞춰 이야기 길이와 다음 장소를 고르는 **간단한 규칙** |
| 4 | 기관 화면: 등록과 집계 | 등록 폼 → 접수 목록 → 연령대·인원 집계 한 화면 |
| 5 | 결과 카드 공유 | 방문 결과를 이미지 카드로 만들어 SNS에 공유 |

**계속 개발하는 방법(같은 틀 반복)**: ① 국가유산포털에서 지정·등록된 가톨릭 문화유산을 고른다 → ② 기존 코스 추천으로 인근 문화재·볼거리 후보를 뽑는다 → ③ AI가 이야기·체험 초안을 쓰고 **사람이 출처를 검수**한다 → ④ 기관과 협의한 뒤 등록·접수한다. 2호 이후 후보는 **논산 강경**(강경성당 등록문화재 제650호와 근대 거리), **공주**(중동성당·황새바위·기독교박물관), **아산 공세리**(세곡미 창고 터의 성당)다.

**AI의 역할과 안전**: AI 가이드는 우리가 모은 데이터 안에서만 답하고 없으면 "모른다"고 한다. 녹음은 기기 안에만 저장하고, 아동 이름·생년월일은 받지 않는다. **본선(11/12) 시연**은 줄 사이 20분(대기시간은 입력식)과 기관 등록→접수→집계다.

## 5. 아직 확인하지 못한 것

성당·성심당·한남대·대덕구·중구와는 **협의 예정**이며 협의된 것은 없다. 국가유산으로 지정·등록된 가톨릭 문화유산이 전국에 몇 곳인지는 아직 집계하지 못했다. 원도심과 대덕구 사이 이동 시간, 맨발 걷기의 어린이·노인 안전, 선교사촌 방문 가능 여부는 확인이 필요하다.
