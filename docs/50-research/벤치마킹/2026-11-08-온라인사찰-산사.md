> 조사: 2026-11-08 저녁, 로컬 세션. 사장님 지시 「산사 사이트에 들어가서 벤치마킹할 부분을 살펴봐」.
> 표기: ✅ 직접 확인 / 주장(기사·사장님 말) / ❓ 추측 / ⏳ 확인 안 함.
> 이어지는 시안: 「촛불 하나」 이야기 시안(저장소 `design/촛불하나/3-story.html`, 인터넷 없이 열리는 판은 노트북 `바탕 화면\모두의창업-복구\촛불-시안\`, 비공개 링크는 사장님 claude.ai 에).

## 0. 어떻게 봤나 (한계 먼저)

- ✅ **화면 구조(접근성 트리)**: agent-browser 로 접속해 버튼·안내 문구를 읽음(11/8 17시대, 「산사 서버 3 · 28명 함께 있는 중」).
- ✅ **화면 문구 전체**: 사이트가 공개로 내려 주는 화면 코드(`/assets/game-*.js`)에서 한국어 문구 421개를 뽑아 읽음.
- ✅ **실제 화면 모습**: 사장님이 보내 준 캡처 1장(「산사 02 · 33/50」, 내 이름 「은은한 달빛」).
- ⏳ **직접 캡처는 실패**: 3D 화면이 무거워 agent-browser·Aside 모두 화면 캡처가 시간 초과(각 2회). 소리는 사장님 스피커로 나가므로 일부러 켜지 않음 → **소리 경험은 확인 안 함.**
- 주장(기사): 공개 사흘 만에 90만 명(동아일보 11/2), 하루 10만 명 이상(매일경제), 개발자는 비신자 취준생, 대만·베트남·태국 유입 많음(나무위키가 연합뉴스 인용).

## 2. 사람을 붙잡는 장치 (✅ 문구로 확인)

| 장치 | 산사에서 실제로 하는 것 | 왜 효과가 있나 (❓ 추측) |
|---|---|---|
| **의식은 버튼 하나** | 절하기·합장·목탁·염주. 염주는 「이번 바퀴 n알, 모두 n알」「n바퀴 돌렸어요」(108알) | 처음 온 사람도 3초 안에 할 일을 앎 |
| **향 올리기 — 차례 기다리기** | 향로가 하나라 「앞에 n명이 있어요 · 차례가 되면 다가갑니다」→「고요한 마음을 한 자루에 담아」→「내 향이 이곳에서 조용히 타오릅니다」→「잠시 머물며 가늘게 흐르는 연기를 바라봐요」→「다음 분을 위해 잠시 이동합니다」 | 줄을 서는 것 자체가 「함께 있음」. 우리 촛불과 거의 같은 의식 |
| **커피 세 가지** | 무소유(내가 안 마시고 **다른 방문자에게 건넴**) · 풀소유(**절 25번 하면** 나에게) · 배달(**사랑하는 이에게** 이미지로) | 낯선 사람에게 주는 기쁨 + 노력의 보상 + 바깥으로 퍼뜨리기를 한 장치로 |
| **말 없이 주고받기** | 「커피 요청하기」→ 상대 「건네기 / 거절」→「두 손으로 받기 / 괜찮아요」 | 채팅 없이도 관계가 생김. 거절도 부드러운 말로 |
| **바깥으로 퍼지는 카드** | 「CAFE25 × 산사 · 우리, 잠깐 쉬자. 커피 한 잔, 같이.」 + 「지금 생각나는 사람에게 한마디」→ 이미지 저장·복사 → 카톡 첨부 안내까지 | 이용자가 홍보를 대신 해 줌 |
| **정해진 시간에 함께** | 「새벽 예불」「저녁 예불」 = 공동 예불, 「공동 예불 시간 · 소리를 켜면 함께 들어요」 | 그 시간에 다시 올 이유 |
| **소리 세 갈래** | 환경음(바람과 새소리) · 효과음(종·염주·목탁) · 염불(나에게만) 각각 크기 조절. 음원은 공유마당 CC BY 4.0, 출처·가공 내역 표시 | 소리가 경험의 절반. 저작권은 정직하게 |
| **쉬는 자리** | 벤치 「앉아 쉬기」, 탭을 떠나면 「잠깐 쉬고 있어요 · 여기서 계속 쉬기」 | 아무것도 안 해도 되는 곳 |
| **캐릭터 둘** | 동자승 「꼬동이」, 고양이 「공양이」 | 귀여움이 밈이 됨 |

## 3. 「촛불 하나」로 옮길 것 (적용안)

| 산사 | 「촛불 하나」로 | 우리에게 이미 있는 것 / 없는 것 |
|---|---|---|
| 기다리는 동안 염주 | 지도를 불러오는 동안 **두 손 비비기**를 먼저 | 시안에 이미 비비기 있음 → 순서만 맞추면 됨 |
| 향 올리기 차례 | **봉헌초 받침대**: 한 받침대에 50자리, 자리가 차면 「앞에 n명」. 「내 초가 이곳에서 조용히 타오릅니다」 | 없음. 서버(실시간 접속)가 필요 |
| 무소유 커피 | **불 건네기**(시안에 있음) + 산사처럼 **요청·수락**: 꺼져 가는 쪽이 「불이 필요해요」, 건네는 쪽 「건네기」, 받는 쪽 「두 손으로 받기」 | 시안은 일방 건네기만 |
| 풀소유(절 25번) | **숨 25번 → 나를 위한 초** (지금 시안의 숨 고르기를 모아서) | 숨 고르기 있음 |
| 배달 카드 | **「오늘 당신을 위해 촛불 하나 켰어요」** 카드 → 카톡으로 | 세례명 카드 PNG 만드는 틀이 이미 있음(`design/세례명-공유카드/`) |
| 공동 예불 | **삼종기도 시간(6·12·18시)** 에 「지금 함께 불을 밝히는 중」 | 없음 |
| 자동 이름 | 「작은 등불」「새벽 별」「따스한 심지」 같은 이름 자동 | 없음, 쉬움 |
| 실제 인원 표시 | 「표시된 불빛은 실제로 켜진 촛불이에요」 | 프로젝트 규칙(더미 금지)과 같음 |
| 소리 세 갈래 | 환경음(성당 종·빗소리) · 효과음(성냥·불꽃) · 성가(나에게만). 음원은 CC 출처 표시 | 없음 |
| 나갈 때 인사 | 「따뜻하게 머물다 가셨나요. 당신의 불은 계속 타고 있어요」 | 없음, 쉬움 |

## 4. 규모 차이 (스킬 3-1)

- 산사는 **3D 공간**(나무·연못·법당). 우리는 1인 운영 → 3D 대신 **2D 그림 + 소리**로 같은 「함께 있음」을 낼 수 있는지가 관건 ❓.
- 산사의 실시간 접속(서버·방 정원)은 우리 시안에 없다. 「촛불 하나」를 실제로 열려면 **실시간 연결(예: Supabase Realtime)** 이 필요 ⏳ 비용·부하 확인 안 함.
- 브랜드 협업(CAFE25)은 산사가 유명해진 **뒤에** 붙은 것으로 보임 ❓ 날짜 확인 안 함.

## 5. 🔴 사장님 결정 필요

1. **봉헌초 받침대(한 자리에 나란히)** 장면을 넣을지 — 넣으면 실시간 서버가 필요.
2. **「오늘 당신을 위해 촛불 하나 켰어요」 카톡 카드**를 먼저 만들지 — 가장 적은 품으로 바깥 퍼짐을 시험할 수 있음(권장).
3. **후원·협업 방식** — 산사처럼 개인 후원(공양미)인지, 성지 카페·수도원 제품 같은 협업인지. 정하지 않고 선택지로만 올림.
