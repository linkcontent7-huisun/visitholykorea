## 1. 시장·마케팅 읽기

**수요는 이미 모여 있다**: 성심당 하루 2~3만 명, 대기 30분~3시간(✅ K절). 문제는 수요가 **빵에서 끝난다**는 것. 이 수요를 가톨릭 근현대사 이야기로 잇는 데 필요한 것은 새 관광지가 아니라 **"기다리는 시간·걷는 시간·SNS에 올릴 장면"을 이야기로 바꾸는 포맷**이다(❓).

**판 흐름**: 이미 코스 기사(가톨릭신문), 빵 투어(대전시 빵시투어, 민간 빵버스), 스탬프·만들기·RPG·티파티(칠곡·당진·놀토)가 있다. 새로움은 **포맷**에서 만든다. 아래 프로그램은 스탬프·만들기·티파티·해설 도보를 **주력으로 쓰지 않는다.**

**고객별 마케팅 문장**

| 고객 | 한 문장(❓) | 근거 |
|---|---|---|
| 지자체(대전 중구 등) | "원도심 상권 활성화" 목표에 맞는 **체류·동선 데이터가 남는 프로그램** | ✅ 중구의 활용 계획 |
| 기관(성당·문화원) | 프로그램 등록→접수→안내 문자·SNS 카드까지 **한 번에** | ✅ 예산에 안내·홍보비·문자·SNS 인정 |
| 방문자 | 줄 서는 시간·걷는 시간이 **이야기**가 된다 | ✅ 대기 수요 |

## 2. 프로그램 (v2, 5번 다듬은 결과는 4절)

**주력 3개 = P1, P2, P5 / 성당 단계 모듈 = P3 / 기관용 도구 = P6 / 확장 시리즈 = P7 / 삭제 = P4.**
각 항목: 대상 / 마케팅 훅 / 흐름 / 앱 기능 / SNS·마케팅 / 지자체 성과(집계 가능한 것) / 근거 / 위험·협의. (아래 본문은 v1 서술이며 R1~R5 조치가 우선한다.)

### P1 「줄 사이 20분」 — 대기시간 연동 오디오 이야기
- 대상: 전 연령(특히 가족·성인).
- 훅: "줄이 긴 날일수록 이야기가 길어진다."
- 흐름: 성심당 줄에 서면 앱에서 이어폰 오디오 3화(각 약 3분, 내용은 밀가루 두 포대 1956 — 길이·편수는 구상 ❓). 가톨릭신문 기자는 성심당 안에서 **대흥동성당 종소리를 들었다**(✅). 본점 앞 줄에서도 들리는지는 ⏳(현장 확인 필요). 구매 후 성당·전시관으로 20~30분 산책 선택.
- 앱 기능: 대기시간 입력/추정, 오디오 재생, 다음 장소 추천. (중구 실시간 대기 데이터 연동은 협의 ⏳, 시연은 입력식)
- SNS: "오늘의 한 줄" 이미지 카드 공유.
- 성과: 시작 수, 완주 수, 산책 이어진 비율.
- 근거: ✅ 대기·방문객, ✅ 중구 데이터 활용 계획, ✅ 종소리 이야기(가톨릭신문).
- 위험: 중구·성심당 협의 필요(협의 예정). 줄 서는 곳 안전·소음.

### P2 「종지기를 찾습니다」 — 후계자 모집 캠페인형
- 대상: 성인·가족.
- 훅: "대흥동성당 종은 2019년까지 사람이 쳤고, 후계자를 못 찾았다."(✅)
- 흐름: 종 이야기 + "종소리 한 번 듣기" 체험. (종을 직접 치는 체험은 교구 협의 ⏳, 불가하면 종소리 듣기와 종지기 이야기로 한정)
- 앱 기능: 종소리 시각 알림(시각은 ⏳), 질문 카드.
- SNS: 15초 숏폼 소재.
- **기념품(사용자 결정 10/31): 작은 종.** 참가자가 "종지기 후보"가 되어 작은 종을 받는다. 집에서도 울려 이야기가 이어지고, "종소리 인증" 사진·영상이 SNS 재료가 된다(❓ 구상).
  - 지침 점검: 일반 참가자 기념품은 구매 가능하나 **경비 편성 최소화**, 기념품 제작비는 재료비 항목에 들어갈 수 있음(✅ 활용사업 예산지원 범위). 상품권·현금성은 불가이므로 종은 해당 없음. 단가·제작처는 근거가 없어 ⏳.
  - 위험: 어린이용이면 **안전 기준(삼킴·소리 크기) 확인 필요**(❓ 법 검토), 성당 종·성물 모양 사용은 교구 협의, 비용 부담은 "무료 참가 + 기념품" 또는 "실비 유료에 포함" 중 선택 ⏳.
- 위험: 종 접근·안전.

### P3 「진짜 2점을 찾아라」 — 성당 벽화 관찰 퀴즈
- 대상: 성인·청소년·가족.
- 훅: "벽화 10점 중 원본은 단 2점."(✅ 가톨릭신문)
- 흐름: 성당 내부에서 원본과 2020년 재현의 차이를 질문으로 따라가는 관찰 퀴즈. 해설은 출처가 붙은 AI 안내.
- 앱 기능: 정답 공개 전 예측 선택, 결과 카드.
- 위험: 미사 시간·촬영 제한 ⏳.

### ~~P4 「1956 찐빵」~~ — **삭제(R2)**
- 만들기 유형이라 식상. "막걸리 반죽 찐빵"(✅ 서울신문)과 성심당 70주년 전시(✅ 12/31까지) 소재는 **P1 오디오 이야기 안으로 흡수.**

### P5 「3세대 질문 카드」 — 조부모와 손주
- 대상: 노인 동반 가족.
- 훅: "할머니의 1950년을 손주가 묻는다."
- 흐름: 대전역~성당 걷기 중 질문 카드, 어르신 답변 녹음(가족 소장). 기관 제출은 별도 동의.
- 위험: 녹음 개인정보, 전쟁 서술의 민감성.

### P6 「한 장 리포트」 — 기관·지자체용 접수~성과 자동 집계
- 대상: 기관·지자체.
- 훅: "접수부터 결과보고까지 한 번에."
- 내용: 접수, 안내 문자, SNS 카드, 연령대(아이·성인·노인) 집계, 만족도, 동선.
- 위험: 결과보고에 실제로 요구되는 항목은 ⏳.

### P7 「한 끼의 역사」 시리즈 — 대전(밀가루) · 공세리(쌀) · 강경(젓갈)
- 대상: 전 연령.
- 훅: "밀가루 두 포대, 세곡미, 젓갈: 먹을 것으로 읽는 성당 이야기."
- 흐름: 도시별 오디오 에피소드.
- 근거: ✅ 임길순, ✅ 공세곶창, ✅ 강경 근대거리·젓갈.
- 위험: 이동 거리 ⏳, 교과서 연계는 ⏳.
