# 디자인 레퍼런스 조사 — 2026-08-20

앱 화면 디자인의 방향을 잡기 위해, 실제 사이트를 브라우저로 열어 **계산된 CSS 값**을 그대로 뽑았다.
"느낌"을 말로 옮기면 흐려지므로 숫자로 남긴다.

## 조사 방법

피그마·별도 디자인 도구는 쓰지 않는다. `claude-in-chrome` 브라우저 도구로 페이지를 열고
`getComputedStyle` 로 실제 적용된 색·글꼴·여백을 읽는다. 추가 설치나 계정이 필요 없다.

> 시도했다가 접힌 것: `japan.travel` 은 CloudFront가 자동 접근을 차단한다(403).

## 1. 산티아고 순례자 사무소 (공식)

`https://oficinadelperegrino.com` — 산티아고 순례길의 공식 순례자 사무소.
크레덴시알(순례자 여권)을 발급하는 바로 그 기관이라, VisitHolyKorea의 디지털 순례여권 구상과
직접 맞닿아 있다.

| 항목 | 실측값 |
|---|---|
| 배경 | `#FFF7E5` (rgb 255,247,229) — 흰색이 아닌 **누런 종이색** |
| 본문 글자 | `#7C6E49` (rgb 124,110,73) — 검정이 아닌 **놋쇠 갈색** |
| 짙은 톤 | `#292519` (rgb 41,37,25) — 따뜻한 근사 검정 |
| 보조 | `#968863` (rgb 150,136,99) — 바랜 금색 |
| 글꼴 | `Merriweather` — **명조(세리프) 계열 단독**. 고딕 병용 없음 |
| 큰제목 | 60px / **weight 300** (가늘게) |
| 본문 | 14px / line-height 26px → **약 1.86배**, 통상(1.5)보다 훨씬 넉넉 |
| 버튼 | 배경 `#7C6E49`, 흰 글자, **border-radius 0px (각짐)**, padding 10px |

### 읽어낸 것

**일부러 "앱처럼 보이지 않게" 만들었다.** 흔한 앱 기본값과 항목마다 반대다.

| | 이 사이트 | 흔한 앱 기본값 |
|---|---|---|
| 배경 | 누런 종이색 | 흰색 |
| 글자 | 놋쇠 갈색 | 검정 |
| 글꼴 | 명조 | 고딕 |
| 굵기 | 300 (가늘게) | 600~700 |
| 모서리 | 0px | 12px |
| 줄간격 | 1.9배 | 1.5배 |

특히 **모서리를 둥글리지 않은 것**이 결정적이다. 둥근 모서리는 "친근한 서비스"를 신호하는데,
여기는 그 대신 **경건함**을 택했다. 전체 인상은 *오래된 종이에 잉크로 눌러 쓴 것*에 가깝다.

## 판단 근거로 남기는 메모

디자인 참고 목적에는 **피그마가 필요 없다.** 피그마의 쓸모는 "내가 그린 시안을 코드로 넘길 때"인데,
1인 개발이라 그 인계 단계 자체가 없다. 남의 디자인을 보는 일은 그냥 웹사이트를 여는 일이다.
firecrawl도 맞지 않는다 — 페이지의 **글자**를 긁는 도구라, 색·여백 같은 **생김새**는 못 가져온다.
