적용 방법 / How to apply

수정 파일 src/app/layouts/AppLayout.tsx · src/app/layouts/BottomNav.tsx · src/pages/HomePage.tsx
셸 AppLayout 의 max-w-lg 고정 폭을 없애고 lg:grid lg:grid-cols-[236px_minmax(0,1fr)] 로. 레일은 hidden lg:flex, BottomNav 는 lg:hidden
본문 HomePage 최상위를 xl:grid xl:grid-cols-[minmax(0,1fr)_300px] xl:gap-6. 여권·미카엘·오늘의 쉼표를 우측 열로 이동(xl:sticky xl:top-24)
그리드 코스 카드 grid-cols-1 md:grid-cols-2 xl:grid-cols-3, 성지 그리드 grid-cols-2 lg:grid-cols-3 xl:grid-cols-4
건드리지 않는 것 CourseCardItem · SiteGridCard · SiteListItem 등 카드 컴포넌트, 라우터, i18n
