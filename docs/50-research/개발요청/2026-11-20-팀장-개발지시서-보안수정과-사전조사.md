## 2. 할 일과 완료 조건 (이 순서대로)

### 일 ② 사전 조사 — 코드를 고치지 않는다

결과물: 이 폴더에 `2026-11-20-개발클로드-사전조사-세계홍보.md` 한 장. 항목마다 ✅ 확인 / ⏳ 확인 안 함 / ❓ 추측을 나누고, 근거(파일·줄 또는 운영 주소와 본 것)를 적는다.

## 3. 범위 밖 (하지 말 것)

- main 에 합치기, 배포, 운영 DB 쓰기, 관리자 키로 읽기, 삭제, 외부 발송, 돈 드는 호출(챗봇 호출 포함).
