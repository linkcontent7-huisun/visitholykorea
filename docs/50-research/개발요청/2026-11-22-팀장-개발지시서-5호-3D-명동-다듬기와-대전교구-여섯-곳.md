# 팀장 → 개발클로드: 개발 지시서 5호 — 3D 명동 다듬기, 대전교구 여섯 곳 (2026-11-22)

## 0. 사장님 말씀 (2026-11-22, 그대로)

- "우리 사이트의 완성도, 특히 3D 구현 부분이 정리가 되어야 하는데 아직 정리할 부분도, 캐릭터의 움직임도 이상해."
- "팀장 너가 개발클로드랑 얘기해서 심재학 멘토가 준 html 을 바탕으로 우리 3D 를 개선해 봐."
- "명동성당의 개발이 완료되면 그 개발된 툴을 바탕으로 대전교구에 속해 있는 성지와 대흥동 성당을 3D 로 개발해서, 대전교구 홍보과에 먼저 허락을 받아 인스타그램에 홍보하는 것을 시작하려고 해. 오늘부터 대전교구의 성지 다섯 군데와 대흥동 성당을 개발해 줘." "개발클로드에게 해서 서둘러 줘."

대회 재단에 보내는 동의 요청서는 3D 가 정리된 뒤로 미뤄졌다. 이 지시서가 지금 가장 앞이다. 지시서 3호·4호의 남은 일은 팀장이 승낙을 받는 중이니 기다리지 않는다.

## 2. 일 ① — 명동 3D 다듬기 (가장 먼저)

**목표:** 멘토 목업과 우리 명동 3D 를 나란히 놓고, 캐릭터 움직임과 정리할 곳을 찾아 고친 미리보기를 사장님이 열어 볼 수 있게 한다.

| 단계 | 완료 조건 | 확인 방법 |
|---|---|---|
| 가. 진단서 | `성지-작업/명동/2026-11-22-멘토목업-대조.md`. ① 캐릭터: 걷기·달리기·멈춤·방향 전환·팔다리·카메라 따라오기를 목업과 우리 것으로 나눠, 어디가 어떻게 다른지(코드 위치와 값). 「이상하다」의 후보를 3~5개로 좁힌다 ② 정리할 곳: 화면에 남은 시험 흔적·어색한 소품·끊긴 화살표·겹친 글자 등 ③ 멘토 계획 0단계의 숫자(드로우콜·삼각형·입장 시간) | 같은 각도의 우리 화면 사진과 목업 화면 사진을 `비교/` 에 넣는다. 추측은 [추론] 으로 적는다 |
| 나. 고치기 | 후보마다 작업 한 건. 스킬 G5 대로 전 사진 → 고침 → 후 사진 | `npx tsc --noEmit -p tsconfig.json`, `npm run build` 종료 값 0 |
| 다. 미리보기 | PR 하나(운영에 합치지 않음)와 미리보기 주소. 건마다 「전/후/되돌리는 법」 한 줄 | `gh pr checks` 전부 pass |

- 스킬 규칙 1(바꾸기 전에 보여 드린다)은 이렇게 지킨다: **진단서 가.가 나오면 바로 팀장에게 보낸다.** 팀장이 사장님께 번호 질문으로 여쭙는다. 답을 기다리는 동안 일 ②를 한다. 눈에 보이는 모습을 바꾸는 건은 답을 받은 것만 고치고, 모습이 그대로인 건(값 정리·버그·성능)은 바로 고쳐도 된다.
- 목업의 코드를 그대로 붙이지 않는다. 우리 틀(`player.ts`·`avatars.ts`·`hanji.ts`)에 맞는 값과 방식만 옮긴다. 캐릭터는 벽·물체를 뚫지 않는다(자동 충돌을 끄지 않는다).
- 틀을 고치면 명동 기준 장면을 다시 찍는다.

## 3. 일 ② — 대전교구 여섯 곳: 자료 모으기 (G1 까지, 일 ①과 나란히)

**대상(팀장의 가정 — 사장님께 확인 중):** 솔뫼성지 · 해미순교성지 · 공세리성당 · 갈매못순교성지 · 신리성지 + 대흥동 주교좌성당. 다섯 곳은 인스타 7번 카드의 다섯 곳을 따랐다. 사장님이 다르게 답하시면 바꾼다.

**목표:** 여섯 곳 각각 G1(자료) 결과물을 만들고, G0(의도) 양식의 빈칸을 사장님이 한 번에 답하실 수 있게 준비한다. **이 지시서에서는 여섯 곳의 3D 코드를 짜지 않는다.**

| 완료 조건 | 확인 방법 |
|---|---|
| 곳마다 `성지-작업/<이름>/01-자료목록.md` 와 `사진/` — 꼭 들어갈 장소 후보, 방향별 사진의 유무, 출처·사용 조건 | 스킬 G1 통과 기준. 없는 방향은 「자료 없음」 |
| 곳마다 지도(OpenStreetMap)에 어떻게 그려져 있는지, 지도에 없는 건물 목록 | 좌표와 조회 결과를 적는다 |
| 곳마다 `00-의도.md` 초안 — 사장님 말로 채울 칸은 비우지 말고 「사장님께 여쭐 것」으로 표시 | 양식 항목을 빼지 않는다 |
| 한 장 요약 `성지-작업/2026-11-22-대전교구-여섯곳-준비.md` — 곳별 자료 상태, 실내 유무, 명동 틀에서 그대로 쓸 것과 새로 지을 것, 스킬 4절의 「안 풀린 것」 세 가지(지도 받는 도구·성지 고르는 방법·야외 성지)를 어떻게 풀지의 안, 어느 곳부터 지을지의 권장 순서 | 근거 없는 견적 시간은 쓰지 않는다. 명동에서 잰 값만 |

- 사진: 사장님 폴더 `~/OneDrive/바탕 화면/교구별 장소/` 에 대전교구 사진이 있다(마케팅리더가 인스타 카드에 쓴 것). 남이 찍은 사진은 **보고 짓는 참고**로만 쓰고 화면에 넣지 않는다. 넣어야 하면 팀장에게 돌린다.
- 유료 호출·대량 수집은 하지 않는다. 필요하면 몇 번·얼마를 적어 팀장에게.
- 교구 허락은 사장님이 대전교구 홍보과에 받으신다. 허락 전에는 운영에 올리지 않는다.
