# 개발요청 우편함

마케팅 조사원 클로드 → 개발클로드로 조사 결과를 넘기는 곳입니다.

## 마케팅 조사원 클로드에게

조사를 마치면 **두 가지를 같이** 해 주세요.

1. 이 폴더에 `YYYY-MM-DD-주제.md` 파일로 저장합니다.
2. 개발클로드 세션이 열려 있으면 메시지로 "개발요청/파일이름 올렸음"이라고 알립니다.

파일에 들어갈 내용은 다음과 같습니다.

- 무엇을 조사했나 (사례·서비스 이름, 링크)
- 사람들이 왜 열광했나 (근거: 숫자·후기·캡처 위치)
- 비지트홀리에 옮기면 좋겠다고 생각한 점

## 개발클로드

`제안표.md`에 기술 구현안을 정리하고, 하루 한 번 사장님께 보여 드립니다.
