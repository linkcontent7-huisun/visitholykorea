# 팀장 → 개발클로드: 개발 지시서 4호 — 외국어 화면의 김대건 신부 이름 표기 (2026-11-21)

## 0. 왜

- 마케팅리더가 인스타 세계 홍보를 준비하다 찾았다: 프랑스어 솔뫼 소개글에 「saint Andrew Kim Taegon」(영어식). 프랑스어로는 André 다.
- 팀장이 origin/main 에서 셌다(`git grep "Andrew Kim"`): `data/docent/소개글/` 의 fr 11개 · es 8개 · it 8개 · pt 8개 파일, `data/docent/*.json` 의 Fr 칸 2개 파일 · Es·It·Pt 칸 각 1개 파일. 같은 저장소의 나바위·단내 원고는 André / Andrés / Andrea / André 로 바르게 되어 있어 표기가 섞여 있다.
- 인스타 첫 게시(8번 카드)가 솔뫼의 여섯 언어 화면으로 사람을 보낸다. 이 수정이 첫 게시의 앞 조건이다.
- 사장님: 외국어를 봐 줄 분이 없다. 기계로 교차 검증한다(3절).

## 1. 목표 (한 문장)

프랑스어·스페인어·이탈리아어·포르투갈어 소개글과 도슨트 원고에서 김대건 신부의 이름을 그 언어의 교회 공식 표기로 맞추고, PR 까지 만든다.

## 2. 완료 조건

| 완료 조건 | 확인 방법 |
|---|---|
| 용어표 한 장: 언어별 공식 표기와 출처 주소 | 바티칸(vatican.va)의 그 언어 쪽이나 그 나라 주교회의 전례력(9월 20일 기념일 이름)에서 직접 읽은 것만. 출처를 못 찾은 언어는 고치지 않고 보고 |
| 네 언어 파일에 김대건 신부를 가리키는 「Andrew Kim」 0건 | `git grep` 결과를 보고서에 붙인다 |
| 영어·한국어 글은 그대로 | `git diff --stat` 에 영어·한국어 파일이 없음 |
| 이름 말고 다른 글자는 바뀌지 않음 | 바뀐 줄을 보고서에 전부 적는다(앞뒤 관사·호칭 `saint`/`san`/`sant'`/`santo`/`père`/`padre` 가 문법에 맞는지 포함) |
| 검증 통과 | `npm run verify`, `npm run translate:check` 종료 값 0 |
| 이 파일들이 운영 화면까지 가는 길 | 빌드에 묶이는지, DB 에 따로 올려야 하는지 코드로 확인해 적는다. **DB 에 올려야 하면 올리지 말고 보고** |

결과물: PR 하나와 이 폴더에 `2026-11-21-개발클로드-외국어-이름-표기-보고.md`.

## 3. 교차 검증 방법 (원어민 없이)

1. **용어표 대조** — 고유 이름·전례 용어는 공식 출처 표기만 쓴다.
2. **가린 되번역** — Codex 에 외국어 문장만 주고 한국어로 옮기게 한 뒤 한국어 원문과 견준다. 뜻이 어긋난 줄만 본다.
3. **다른 모델의 교정** — Codex 에 그 언어의 가톨릭 매체 교정자 역할로 문법·호칭·관사만 보게 한다. 지적에는 근거를 달게 한다.
4. 둘이 어긋나면 고치지 말고 보고서에 올린다.

이번 지시서에서는 **바뀐 줄**에만 2·3을 돌린다. Codex 는 운영 스킬 5절의 명령으로(입력을 닫는다). 무료다.

## 4. 범위 밖

- 김대건 신부 말고 다른 성인·인물의 영어식 이름(예: Andrew Kim Gwang-ok, Paul Chong Hasang) — 고치지 말고 **몇 건인지 세어 보고만** 한다. 다음 지시서에서 다룬다.
- 「World Youth Day Seoul 2027 · Official Venue」 표시 — 사장님 답을 기다리는 중이다.
- main 에 합치기, 운영 DB 변경. 승낙은 팀장이 받는다.
