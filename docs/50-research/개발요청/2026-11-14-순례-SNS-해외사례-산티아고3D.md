## 2. 산티아고 순례길 3D/가상 구현 사례
| 사례 | 형태 | 특징 | 우리에게 쓸 점 |
|---|---|---|---|
| **¡Buen Camino! (Google Arts & Culture)** 🗣 | 웹, 무료 | 온라인 전시 100개 이상, 사진·영상 4,700개 이상, 360° 투어 13개, **11개 언어**, 휠체어 순례 경로 포함. 지도는 3D가 아니라 그림 지도 | 가장 큰 기준 사례. "길 위의 이야기 + 여러 언어"가 우리 본질과 같음. 3D보다 **이야기 전시**가 중심 |
| **camino-de-santiago-mapbox (GitHub)** 🗣 | 공개 코드 | Mapbox 3D 지형 위를 비행하듯 따라가는 영상형 화면 | **"3D 순례길"에 가장 가까운 것.** 우리 서울 순례길 코스를 같은 방식(지형 위 비행)으로 보여 줄 수 있음 ❓ 1~2일 |
| Camino de Santiago 360º 🗣 | 아이폰·아이패드 앱 | 인터랙티브 360° 영상 100분 이상 | 현장 360° 촬영이 필요해 비용이 큼 |
| Peregrinia 지도 / CaminoMap / tosantiago 🗣 | 웹(2D) | 15개 경로 실제 GPS, 단계별 고도, 오프라인 PWA | 우리 순례 코스 화면의 비교 기준 |
| Camino Amigo (iOS, 2026.6) 🗣 | 앱 | **디지털 여권 도장 + 공유용 경로 카드** | 우리 순례 여권·세로 카드와 같은 방향(우리가 이미 가진 것) |
| Pilgrim – A Walking Practice 🗣 | 앱, 공개 코드 | 계정 없음, **모든 이용자가 걸은 거리 합계 표시**, 걸을 때마다 일본 고슈인 같은 도장 | 산사의 "함께 n명"과 같은 장치. "오늘 전 세계 순례자가 함께 걸은 거리" ❓ |
- ⏳ 사장님이 들으신 "산티아고 3D"가 위 중 어느 것인지는 확인 못 함. 이름이나 주소를 주시면 크롬으로 열어 분석하겠습니다.

## 4. 우리 사이트에 옮기면 좋을 것 (우선순위 제안)
1. **WYD 소식 자동 반영**: cpbc「WYD 매거진」과 지금여기의 WYD 기사 → 사이트 WYD 안내와 미카엘 정보 갱신(승낙 뒤)
2. **[1분순례] 형식**: 성지마다 1분 영상·오디오. cpbc 여행사 쇼츠가 같은 길이
3. **서울 순례길 3D 비행 미리보기**: Mapbox 방식으로 코스를 지형 위에서 미리 보기
4. **"오늘 함께 걸은 거리"**: Pilgrim 앱처럼 모든 이용자 합계
