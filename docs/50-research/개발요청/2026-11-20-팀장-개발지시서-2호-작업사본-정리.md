## 3. 완료 조건

결과물: 이 폴더에 `2026-11-20-개발클로드-작업사본-정리-보고.md`.

| 사본마다 적을 것 | 확인 방법 |
|---|---|
| 가지 이름과 그 일이 운영에 들어갔는지 | PR 번호와 상태(`gh pr list --state all --head <가지>`). squash 로 합쳐졌으면 `merge-base` 로는 안 보이니 PR 로 본다 |
| 안 올린 변경이 무엇인지 | `git status --porcelain` 과 `git diff --stat`. 도구 연결(node_modules 바로가기)뿐인지, 진짜 작업인지 |
| 판정: 지워도 됨 / 남김 | 남기면 이유와 언제까지 |
| 만든 창이 살아 있는지 | `ListAgents` |

`vite-sec` 는 PR #115 가 합쳐진 뒤 지우는 것으로 적는다. 앞으로 작업 사본은 프로젝트 맨 위에 만들지 않는다 — 세션 임시 폴더(scratchpad)나 `main-app/.claude/worktrees/` 에 만든다.
