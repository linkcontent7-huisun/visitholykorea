# 팀장 → 개발클로드 `-aa`: 개발 지시서 10호 — 전국 15개 교구 설명과 입체감 있는 교구 지도 (2026-11-25)

대상은 메인 사이트(`/search` 지도 화면, `src/features/map/`). `visit-3d/` 는 건드리지 않는다. 9호(세례명)와 따로 진행하고, 9호 사장님 승낙을 기다리는 동안 이 일의 ① 을 먼저 한다.

## 0. 사장님 말씀 (2026-11-25)

화면은 `visitholykorea.com/search`(성지 찾기) 왼쪽 검색 + 오른쪽 전국 지도. 「전국의 15개 교구에 관련된 설명을 넣어 줘. 지도에 대한 설명이 너무 없고, 지도를 3D 느낌이 나게 좀 세련되게 만들어 줘.」

## 1. 지금 있는 것 (팀장이 origin/main 에서 확인)

- `src/features/map/components/DioceseLayer.tsx`: SVG 위에 교구 15개 구획(`diocese-shapes.json` 57KB, 통계청 2018 시군구 경계를 교구 관할로 합친 것)을 파스텔 색으로 깔고 흰 경계선, 교구 이름 글자. 군종교구는 영토가 없어 그리지 않는다.
- 같은 폴더 `NationalMap.tsx`(지도 본체), `DioceseProgressList.tsx`(교구별 진행), `projection.ts`(좌표). 지도에 성지 점이 찍힌다.
- 설명 글: 지도 화면에는 교구에 대한 글이 없다(교구 이름뿐). 성지 상세에는 `SameDioceseSites.tsx` 가 있다.
- **지도의 점·이름이 어느 교구인지 구분은 되지만 «이 교구가 무엇인가»를 알 수 없다**는 것이 사장님 지적이다.

## 2. 일 ① — 교구 15개 설명 글 (코드 전에, 문서 한 장)

결과물: `docs/40-knowledge/09-교구/2026-11-25-교구-15곳.md` + 이 폴더에 보고 `2026-11-25-개발클로드-교구-설명-보고.md`.

| 교구마다 적을 것 | 출처 |
|---|---|
| 한국어 이름, 영어 이름, 설정 연도(교구 설정일) | 한국천주교주교회의(cbck.or.kr)·각 교구 공식 누리집·굿뉴스. 한 곳이 아니라 서로 다른 두 곳 |
| 주교좌성당(본당 이름과 있는 곳) | 같음 |
| 관할 지역(시·도 수준) | `diocese-shapes.json` 만든 근거(천주교 주소록)와 같은 기준 |
| 우리 사이트의 성지 수 | DB 에서 실제로 센 값(언제 쟀는지 적는다). `diocese-count.ts` 사용 |
| 특징 한두 문장(이 교구가 한국 교회 역사에서 무엇으로 알려졌는가) | 위 출처. **문장은 우리가 새로 쓴다**(남의 글 복사 금지). 단정하기 어려운 평가·순위·«가장 오래된» 같은 최상급은 근거 두 곳이 없으면 쓰지 않는다 |
| 대표 성지 1~2곳(우리 DB 에 있는 것) | DB |

- 15개 교구: 서울·인천·수원·의정부·춘천·원주·대전·청주·안동·대구·부산·마산·광주·전주·제주(군종교구는 영토가 없으니 «전국 군부대» 한 줄로만 밑에 따로 써도 된다, 선택).
- 운영 스킬 5절 순서: 조사 → Codex 교차 검증(무료) → 개발 창이 다시 검증. Codex 가 틀리면 날짜를 직접 계산해 바로잡는다(9호 김대건 나이 건처럼).
- 한국어·영어를 먼저 쓰고 나머지 4개 언어는 영어로 대신 보이게 한다(운영 스킬 5절).
- 설명 글은 DB 가 아니라 코드 안 데이터 파일(예: `src/features/map/data/diocese-info.ts`)에 둔다. **운영 DB 를 바꾸지 않는다.**

## 3. 일 ② — 입체감 있는 지도 «시안 먼저»

사장님은 코드가 아니라 화면으로 판단하신다. **구현 전에 전·후 시안**을 만든다(`기획자료/교구-지도-시안/2026-11-25/` 에 `시안.html` + 사진, 9호 세례명 시안과 같은 방식).

방향(권장, 시안에서 셋 중 비교해 사장님이 고른다):

| 안 | 모습 | 비용 |
|---|---|---|
| **A (권장)** | 지도 전체를 약 25~30도 눕혀(CSS `perspective` + `rotateX`) 두께가 있는 판처럼 보이게. 교구마다 아래에 한 겹 어두운 면(압출 느낌)과 부드러운 그림자, 마우스를 올리거나 누르면 그 교구가 살짝 떠오르고 나머지는 흐려진다. 휴대폰은 기울기를 줄이고 손가락으로 눌러 선택 | 가볍다(SVG 그대로, 추가 라이브러리 없음) |
| B | A 에 더해 점(성지)이 핀으로 솟고 바다 쪽에 은은한 물결·안개 | 중간. 핀 수(200여 개)가 많아 휴대폰에서 느려지지 않는지 재야 함 |
| C | three.js 로 진짜 3D 지형 | 무겁다 — **권장하지 않음**(휴대폰 속도, 번들 크기) |

- 성지 점·이름이 눌리는 것, 확대·이동, 큰 글자 모드, 6개 언어는 그대로 동작해야 한다.
- 색은 지금의 파스텔을 바탕으로 하되, 인접 교구끼리 구분이 더 또렷하게. 글자는 읽기 쉽게(입체로 눕혀도 글자는 눕히지 않고 정면으로).
- **휴대폰 속도 기준:** 교구 구획·그림자는 SVG 요소 수가 적어 무겁지 않다. 점이 많은 B 안은 눈으로가 아니라 숫자(그리기 시간)로 확인한다.

## 4. 일 ③ — 설명을 어떻게 보여 줄지(권장안)

- 지도의 교구를 누르면(휴대폰) 또는 마우스를 올리면(PC) 그 교구가 떠오르고, **왼쪽 패널(휴대폰은 아래에서 올라오는 카드)** 에 교구 설명 카드가 뜬다: 이름·설정 연도·주교좌성당·관할·성지 수·특징 한두 문장·대표 성지(눌러서 상세로).
- 아무것도 고르지 않았을 때는 지도 위에 한 줄 안내 «교구를 눌러 보세요. 한국 천주교는 15개 교구로 나뉩니다.» 와 작은 범례(교구 수·색 뜻·점의 뜻).
- 설명 카드에 «교구란?» 한 줄(주교가 맡은 신앙 공동체 단위)을 넣는다 — 처음 보는 사람을 위한 설명이다.
- 설명을 화면 전체에 늘어놓지 않는다(휴대폰이 길어짐). 사장님 9호 결정과 같은 원칙(일정량만, 필요하면 더보기).
