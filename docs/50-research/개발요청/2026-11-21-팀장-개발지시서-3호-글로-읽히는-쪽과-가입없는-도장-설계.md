# 팀장 → 개발클로드: 개발 지시서 3호 — 글로 읽히는 쪽 넓히기, 가입 없는 도장 설계 (2026-11-21)

## 0. 왜 이 순서인가

- 마케팅리더가 11/21 에 재 보니 AI 검색(구글 AI 모드·네이버) 일반 질문 20개 가운데 우리 이름이 0건이었다(마케팅 저장소 `사업/비지트홀리코리아/조사자료/AI검색/현재위치-2026-11-21.md`).
- 팀장이 같은 날 운영을 프로그램 실행 없이 받아 봤다: 본문이 있는 쪽은 `/sites/…` 214개와 `/guide` 뿐. `/`, `/faq`, `/region/…`, `/card/…` 는 본문이 비고 제목·소개글이 첫 화면과 같다. `/card` 는 사이트맵에도 없다.
- 심재학 멘토 자료 대조(개발클로드 보고, 팀장이 origin/main 에서 다시 확인): 도장은 로그인해야만 받는다(`stamps.repository.ts` UNAUTHENTICATED), passport 에 기기 저장 코드 없음, 「미사·성사를 대신하지 않습니다」 문구 없음, `visit-3d/src` 에 visibilitychange 없음.

순위는 팀장 스킬 2절대로 ③ 순례자가 바로 쓰는 것 → ④ 3D.

## 1. 일 ① — 세례명 카드·지역·자주 묻는 질문 쪽을 글로 읽히게 (PR 까지)

**목표:** 프로그램 실행 없이 받아도 `/card/:language/:slug`, `/region/:region`, `/faq` 에 그 쪽만의 제목·소개글·본문이 들어 있게 한다. 성지 쪽에 이미 쓰는 `scripts/seo-prerender.ts`·`scripts/lib/seo-pages.ts` 를 넓힌다.

| 완료 조건 | 확인 방법 |
|---|---|
| `/card/ko/…`, `/card/en/…` 각 1쪽 이상, `/region/서울`, `/faq` 의 본문 글자가 0 이 아니고 제목이 첫 화면과 다름 | 미리보기 주소를 `node -e 'fetch(url).then(r=>r.text())…'` 로 받아 `<head>` 밖 글자 수와 `<title>` 을 적는다 |
| 세례명 카드 쪽의 `<html lang>` 이 그 언어와 같음 | 같은 방법 |
| 사이트맵에 `/card` 쪽이 들어감(개수 적기) | `sitemap.xml` 의 `<loc>` 세기 |
| 화면 동작이 그대로 | `npm run verify` 종료 값 0, 미리보기에서 카드 한 장 열어 보기 |
| 본문은 이미 화면에 있는 글만 쓴다. 새 문장을 지어 넣지 않는다 | PR 본문에 글의 출처 파일을 적는다 |

- 카드는 119종 × 6개 언어다. 전부 미리 만들지, 한국어·영어만 먼저 할지는 빌드 시간을 재 보고 정해 보고에 적는다.
- `/llms.txt` 는 이 PR 에 넣지 않는다(효과가 확인된 표준이 아님).
- 첫 화면 소개글은 마케팅리더 초안이 사장님 승낙을 받은 뒤 따로 지시한다. **`index.html` 의 제목은 건드리지 않는다**(11/16 검색 실적 측정 중).

## 2. 일 ② — 로그인 없이 도장 받기: 설계서 한 장 (코드 수정 없음)

**목표:** 로그인하지 않은 순례자가 도장을 받아 기기에 남기고, 나중에 로그인하면 계정에 합쳐지게 하려면 무엇이 바뀌는지 한 장으로 정리한다. 결과물: 이 폴더에 `2026-11-21-개발클로드-가입없는-도장-설계.md`.

적을 것:
1. 지금 흐름(어디서 로그인을 요구하는가, 도장 받는 조건 — 위치 확인이 있는지)과 바뀌는 흐름
2. 손댈 파일 목록과 손대지 않을 것. 운영 DB 구조를 그대로 둘 수 있는지(있으면 근거, 없으면 무엇이 바뀌는지)
3. 합칠 때의 규칙: 같은 성지 도장이 양쪽에 있을 때, 한 기기를 두 사람이 쓸 때
4. 잃어버리는 경우를 숨기지 않고 적는다: 브라우저 기록 삭제, 사파리의 7일 저장 제한, 홈 화면 앱과 브라우저의 저장소가 따로인 점. 화면에서 어떻게 알릴지
5. 도장 수를 쓰는 다른 기능(순위·인증·공유 등)이 있으면 영향
6. 일의 크기(PR 몇 개), 권장안과 하지 않을 것

첫 이용자는 국내 고령 교우다(`기획자료/기획서/CLAUDE.md` 3절). 가입 화면에서 돌아서는 분을 줄이는 것이 이 일의 이유다.

## 3. 대기 — 「온라인 순례는 미사·성사를 대신하지 않습니다」 안내

문구와 넣을 자리는 팀장이 사장님께 여쭌다. 답이 오면 따로 지시한다. 지금은 하지 않는다.

## 4. 보류 — 3D 가 가려지면 그리기 멈추기

지금은 하지 않는다. 이유: `visit-3d/src/main.ts` 의 그리기는 `requestAnimationFrame` 으로 도는데, 브라우저는 가려진 탭에서 이 호출을 스스로 멈춘다. 그래서 배터리가 줄어든다는 효과가 확인되지 않았다. 3D 는 순위 ④이기도 하다.
시간이 남으면 코드 수정 없이 재기만 한다: 탭을 가렸을 때 `frame` 이 초당 몇 번 불리는지, 소리·타이머가 계속 도는지. 수치가 나오면 다시 정한다.
