- 안 올린 변경: `git status --porcelain`, `git diff --stat`, `git log @{u}..HEAD`.
- `node_modules` 는 6개 모두 **바로가기**(`../../../node_modules`, main-app 것을 가리킴)다. 크기 200~250MB 는 저장소 파일(사진 등) 자체다.
