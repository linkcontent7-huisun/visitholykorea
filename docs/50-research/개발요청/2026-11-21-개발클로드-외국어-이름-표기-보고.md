## 3. 고친 뒤 `git grep` 결과

김대건 신부를 가리키는 「Andrew Kim Taegon」은 네 언어에서 0건입니다 ✅. 남은 「Andrew Kim」은 아래 두 가지뿐이며, 일부러 두었습니다.

```
fr/es/it/pt 대흥-봉수산-순교-성지.md:15  … Andrew Kim Gwang-ok …   ← 김광옥 안드레아(다른 인물). 지시서 4절, 범위 밖
fr/es/it/pt 백령도-성지.md:19           … Hospital Blessed/Beato Andrew Kim …   ← 병원 고유 이름
```

**팀장 판단 필요:** 백령도의 「Blessed Andrew Kim Hospital」은 김대건 신부의 이름을 딴 병원 이름입니다. 고유 이름이라 고치지 않았습니다. 한국어 원고를 확인하면 병원의 한국어 정식 이름을 알 수 있으니, 그 이름을 쓸지는 다음 지시서에서 정해 주세요.

## 6. 운영 화면까지 가는 길 (지시서가 물은 것)

**DB 에 따로 올려야 화면에 나옵니다.** 근거 두 가지:

1. 코드: `src/features/docent/api/docent.repository.ts` 머리 주석 「원고는 2026-09-18 부터 DB 가 기준이다. 저장소의 `data/docent/*.json` 은 원본 파일이자 DB 가 안 닿을 때의 폴백」. 소개글 `.md` 는 빌드에 묶이지 않고 `scripts/docent-load.ts`(`npm run docent:load`)로만 DB `docent_scripts` 에 들어갑니다.
2. 운영 DB 읽기 조회(공개 키, 읽기만): fr·es·it·pt 행 중 「Andrew Kim」이 든 것이 44행. 그 가운데 김대건 신부 이름이 fr 13곳 · es 9곳 · it 9곳 · pt 9곳으로, **저장소에서 고친 40곳과 정확히 같습니다.** 지금 화면에는 영어식 이름이 나오고 있다는 뜻입니다.

올리는 방법(승낙 뒤): PR 을 main 에 합친 다음, 고친 성지만 골라 올립니다.
`npm run docent:load -- 솔뫼` 처럼 성지 이름으로 거르면 그 성지의 6개 언어 행을 다시 씁니다(같은 키는 덮어씀). 바뀐 성지는 9곳입니다: 가톨릭대 성신교정, 나바위, 새남터, 석정 보름 우물, 솔뫼, 용수성지, 우포도청 터, 은이, 한국 순교자 103위 시성 터. 지점 원고가 바뀐 석정·솔뫼도 이 안에 들어 있습니다.
**저는 올리지 않았습니다.** 올린 뒤에는 위 2번 조회를 다시 돌려 0건이 되는지 확인하겠습니다.
