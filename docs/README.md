## 🔒 저장소에 없는 문서 — 링크가 안 열려도 사라진 것이 아니다

창업 지원사업 서류와 사업계획서는 `.gitignore` 로 **로컬 전용**이다.
사장님 노트북의 원래 작업 폴더에는 있지만, **저장소만 복제한 세션(웹 세션·새 포크 클론)에는 없다.**

`모두의창업-*` · `창업지원-*` · `*사업계획서*` · `코딧세이-*` · `린캔버스.md` · `모두의창업-이미지/`
· `금산_자문의뢰_기획서.md` · `대전세종관광기업지원센터_사업계획서.md` · `2026-08-26-사업-비판검토.md`

2026-09-14 점검에서 **이들을 가리키는 경로 참조가 문서 곳곳에 23곳** 있었다.
그 링크를 따라갔다가 "파일이 사라졌다"고 판단하지 말 것. `npm run docs:hub` 가 만드는 허브는
이런 경로를 링크 대신 **「로컬 전용」 배지**로 표시한다.

## 문서를 새로 쓸 때

- 파일명은 한글로 써도 된다. 공백 대신 `-`. 날짜가 있는 기록은 `YYYY-MM-DD-` 로 시작한다
- 결정을 내렸다면 ADR(`20-architecture/adr/`)에 한 장 — "무엇"보다 "왜 그때 그렇게"
- **숫자는 `이어서-할-일.md` 의 「지금 상태」 표 한 곳에만 둔다.** 다른 문서에서 인용하면 반드시 낡는다.
  꼭 적어야 하면 **잰 날짜**를 같이 쓰고, 못 잰 것은 "확인 못 함"이라고 쓴다
- 새 파일을 넣으면 그 폴더 README 표에 한 줄 추가한다 — 허브가 그 표를 읽어 그린다
- **끝난 일은 「할 일」 자리에서 빼 `00-overview/일지/` 로 옮긴다.**
  끝난 일이 할 일 자리에 남아 있으면 다음 세션이 그것을 다시 한다 (2026-08-19 사고)
