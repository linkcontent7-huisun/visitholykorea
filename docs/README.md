# 문서 안내

번호는 "읽는 순서"가 아니라 "성격"을 나눈 것이다. 처음 오는 사람은 00 → 10 → 20 순으로 보면 된다.

| 폴더               | 담는 것                                                            |
| ------------------ | ------------------------------------------------------------------ |
| `00-overview/`     | 프로젝트 개요, 원본 자료가 어디 있는지                             |
| `10-product/`      | 무엇을 언제 만들 것인가 — 로드맵, 기능 우선순위                    |
| `20-architecture/` | 왜 이렇게 만들었는가 — 시스템 구조와 결정 기록(ADR)                |
| `30-content-ops/`  | 성지 취재·촬영·블로그·유튜브 운영 매뉴얼                           |
| `40-knowledge/`    | 가톨릭 지식창고 — 순교사·영성·순례 배경지식과 비즈니스 기획 (27편) |
| `50-research/`     | 초기 리서치 메모 (현재 구현과 다를 수 있음)                        |

## 문서를 새로 쓸 때

- 파일명은 한글로 써도 된다. 대신 공백 대신 `-` 를 쓴다.
- 결정을 내렸다면 문서로 남기기 전에 ADR(`20-architecture/adr/`)에 한 장으로 적는다.
  "무엇을 정했는가"보다 "왜 그때 그렇게 정했는가"가 나중에 훨씬 쓸모 있다.
- 리서치 메모(`50-research/`)는 시간이 지나면 사실과 어긋난다. 구현이 문서를 앞질렀다면
  메모를 고치지 말고 ADR 을 새로 쓰고, 메모 상단에 "이 부분은 ADR 000X 로 대체됨"이라고 적는다.
