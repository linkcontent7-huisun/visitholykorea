수정 파일 src/app/layouts/AppLayout.tsx · (신규) src/app/layouts/TopNav.tsx · src/pages/HomePage.tsx
셸 AppLayout 을 flex min-h-screen flex-col 로 바꾸고 TopNav 를 sticky top-0 z-40 h-[72px] 로. BottomNav 는 제거하고 모바일은 상단 menu 버튼 + 기존 시트 재사용
