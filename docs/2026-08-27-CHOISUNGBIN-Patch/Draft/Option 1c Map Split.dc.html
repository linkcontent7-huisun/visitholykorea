적용 방법 / How to apply

수정 파일 src/pages/MapPage.tsx · src/pages/ExplorePage.tsx · src/features/map/*
셸 지도 화면만 lg:flex 2분할. 좌측 목록 lg:w-[452px] lg:shrink-0 lg:overflow-y-auto, 우측 지도 flex-1. 1024px 미만은 현재 지도+바텀시트 그대로
동기화 목록 hover/선택 ↔ 마커 선택 상태를 한 곳에서 관리(선택 성지 id). 마커 클릭 시 목록 항목으로 스크롤(scrollTop 계산, scrollIntoView 사용 금지)
필터 카테고리·가까운 순 토글은 ExplorePage 의 기존 상태 로직을 그대로 재사용
추가 필요 마커 클러스터링, 지도 뷰포트 기준 목록 필터, 선택 성지 카드(우하단 296px)
홈·여권 이 안은 지도 화면 전용입니다. 홈/여권 데스크톱 레이아웃은 1a 방식을 함께 적용하세요
