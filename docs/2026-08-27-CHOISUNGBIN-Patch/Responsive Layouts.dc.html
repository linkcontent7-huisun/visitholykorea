데스크톱 · 모바일 레이아웃 비교안 / Desktop & mobile layout options

현재 앱은 max-w-lg 모바일 셸 하나로 데스크톱에서도 가운데 좁은 기둥으로 보입니다. 세 방향 모두 실제 토큰(brand-blue #1e3a8a · brand-violet #7c3aed · app-bg #f8f9fa)과 현재 화면 구조를 그대로 쓰고, 데스크톱 레이아웃만 새로 정의합니다. 각 안은 데스크톱 1280 + 모바일 390을 한 쌍으로 봅니다. 채택안 하나를 골라 주시면 탐색·성지 상세·지도까지 확장합니다.
