# DSH — 작업용 개인 폴더

**이 폴더는 한 사람이 작업할 때 쓰는 개인 메모 자리다.**
다른 팀원은 **참고만** 한다 — 내용을 고치거나 여기 기준으로 판단하지 않는다.

## 왜 따로 두나

작업 중인 생각·중간 계산·임시 목록을 공용 문서에 섞으면, 읽는 사람이
"이게 결정된 것인지 메모인지"를 구분할 수 없다. 그래서 자리를 나눠 둔다.

|             | 이 폴더 (`DSH/`)                | 공용 문서 (`00-overview/` 등) |
| ----------- | ------------------------------- | ----------------------------- |
| 성격        | 작업 중 메모 · 초안 · 개인 정리 | 팀이 합의한 내용              |
| 고치는 사람 | 폴더 주인만                     | 누구나 (PR 로)                |
| 다른 사람은 | 읽기만                          | 읽고 고친다                   |
| 믿어도 되나 | **아니다** — 진행 중인 생각이다 | 그렇다                        |

## 지켜야 할 것

- **숫자를 여기에 두고 인용하지 않는다.** 성지 수·사진 수·테스트 수의 원본은
  `docs/이어서-할-일.md` 의 「지금 상태」 표 한 곳이다 (`docs/README.md` 규칙).
  여기 적은 숫자는 잰 날짜를 같이 쓰고, 공용 문서에서 이 폴더를 인용하지 않는다.
- **결정이 내려지면 여기서 빼서 제자리로 옮긴다.** 설계 결정은 `20-architecture/adr/`,
  할 일은 `이어서-할-일.md`, 끝난 기록은 `00-overview/일지/`.
  메모가 여기 남아 있으면 "아직 정해지지 않은 것"으로 읽힌다.
- **비밀 값(키·토큰·개인 이메일)을 적지 않는다.** 이 폴더도 공개 저장소 안이다.
- 파일명은 `YYYY-MM-DD-무엇.md` 로 시작하면 나중에 찾기 쉽다.

## ⚠️ `문서-허브.md` 는 이 폴더의 예외다

다른 파일과 달리 **개인 메모가 아니라 `npm run docs:hub` 이 만들어 내는 생성물**이다.
각 폴더 README 의 「확인하고 싶은 것 → 파일」 표를 읽어 그리므로, **내용을 바꾸려면
그 표를 고친다.** 이 파일을 직접 고치면 다음 실행에서 덮어써진다.

**원시 HTML 을 한 글자도 넣지 않는다.** `<details>` 로 접거나 `<sub>` 로 작게 쓰면
편집기가 "HTML, JSX 또는 MDX가 포함되어 있으므로 코드 모드에서만 편집할 수 있습니다"
하며 렌더를 포기한다 (2026-09-14 실측). 사람이 보라고 만든 문서가 코드로 보이면 뜻이 없다.
생성기가 매번 검사해서 섞이면 알려 준다.

검색·필터까지 되는 판이 필요하면 `npm run docs` — 같은 내용을 `docs/index.html` 로
만들어 브라우저에 바로 띄운다. 생성기는 `scripts/docs-hub.ts`.
