## 실행 기록 — 2026-09-16 (작업 0·1 완료)

지시서와 다르게 한 것 — 이유와 함께.

- **관광정보(tourinfo) API 사진 32장은 유형(1·3) 확인을 못 했다.** 확인 수단인 `detailImage2` 는 로컬 키가 죽어(403 "등록되지 않은 서비스키") 못 불렀고, 배포 프록시는 그 오퍼레이션을 허용하지 않는다. 대신 **32장 전부 700KB 이하라 원본 그대로(변경 없이) 내장**했다 — 1·3유형 어느 쪽이든 변경 없는 상업 이용은 허용된다. `image_license` 에 「공공누리 (제1·3유형 미확인 · 원본 무변경)」로 정직하게 적었다. 키를 살리면 `detailImage2` 의 `cpyrhtDivCd` 로 확정할 것.
- 겹치는 7곳 중 **은이·한티는 관광정보 쪽 사진**을 골랐다(관광사진 쪽이 안내판·표석 사진이라). 나머지 5곳은 관광사진(고화질·1유형).
- 교구 대표 사진은 **파일을 만들지 않고 URL 표로** 두었다 (`DIOCESE_IMAGES`). 주교좌성당 열린 사진이 없는 **부산·안동·군종**은 그 교구의 다른 성지 사진(언양성당 · 상주 신앙고백비 · 왜고개성지), **대전**은 대흥동 야경 세로 사진뿐이라 공세리성당.
- 띠는 96px 이상에서만 그린다(컨테이너 쿼리 `@[90px]`). 56px 썸네일에서는 사진 절반을 덮어 사장님 지시("가리지 않게")에 어긋난다.
- **덤으로 고친 것(범위 밖이지만 이 작업이 막혀서):** `SiteThumbnail` 이 위키미디어 축소판을 800px 로 요청하고 있었는데, 위키미디어가 정해진 크기(960·1280 등)만 내주고 800 은 **400 오류**를 낸다. 그래서 목록·카드의 위키미디어 사진 43장이 전부 「사진을 불러오지 못했어요」였다(9/16 실측 — 배포본도 같을 것). 960 으로 바꿨다. 상세 히어로는 원래 960 이라 멀쩡했다.

부수 발견(안 고침): 상세 히어로의 기존 출처 표기(`bottom-2 right-3`)는 본문 흰 판(`-mt-8`)에 가려 안 보인다. 교구 띠는 `bottom-11` 로 올려 피했다.
