## 3. 고요 속으로 — 공모전 대표 기능 (`/quiet`)

지정과제 "유명 관광지 쏠림·오버투어리즘 완화"에 답하는 화면. `src/pages/QuietPage.tsx` 머리말 그대로:

1. 방문 예정 관광지·지역을 검색 (TourAPI `searchKeyword2` — **실시간 호출**)
2. 관광데이터로 예상한 붐빔 정도를 참고 정보로 표시
3. 주변 20km 의 비교적 한적한 성지를 대안으로 제시
4. 추천 근거 · 직선거리 · 이동 부담 · **데이터의 한계**를 함께 보여줌
5. 성지 상세로 이어짐
6. 원래 장소가 이미 한적하면 이동을 권하지 않음 / 대안이 없거나 데이터가 부족하면 추천하지 않음

「붐빔 피하기」(`/alternatives`)와 홈 「오늘의 쉼표」를 이 화면 하나로 합쳤다. 붐빔 계산은 T-R03 으로
정직화(확인 부족 분리 · 이동 불필요 · 대안 없음 · 집중률 필터 · 과장 문구 제거). 쉼터 탭은 원래 유형명(레포츠·쇼핑)으로.
