# 성지순례 사업자 지도 — 누가 이미 이것으로 돈을 벌고 있는가

조사 2026-08-22. 계기: 사용자가 인스타그램에서 성지순례 기반 프로그램·비즈니스를 목격.

**조사 한계를 먼저 밝힌다.** 사용자가 본 인스타그램 계정의 핸들을 알지 못해, 그 계정을 특정하지
못했다. 대신 "성지순례를 상품으로 파는 주체"를 웹에서 역으로 찾았다. 따라서 이 문서는 사용자가
본 것과 다를 수 있고, **인스타그램에서 직접 활동하는 소규모 사업자는 빠져 있을 가능성이 높다.**
계정 핸들을 알게 되면 이 문서에 추가해야 한다.

기존 `docs/30-content-ops/SNS-레퍼런스-조사.md` 는 **콘텐츠 계정**(교구·본당·개인 기록)을
다뤘고, 이 문서는 **수익 사업자**를 다룬다. 겹치지 않는다.

## 요약 — 이 조사가 사업계획서에 미치는 영향

1. 🔴 **"가톨릭에는 조직화된 주체가 없다"는 전제가 부분적으로 틀렸다.**
   서울대교구 순교자현양위원회가 **유료 도보순례를 온라인 신청·환불규정까지 갖춰 상시 운영 중**이다.
   `사업계획서-골격.md` 5장 차별요소 1번을 고쳐야 한다.
2. 🔴 **가격 앵커가 이미 7,000원에 박혀 있다.** 우리 휴식형 제안(무료~1만 원)은 이 숫자 위에서
   정당화돼야 한다. 4장 가격 설계의 출발점이 바뀐다.
3. 🔴 **스탬프북 + 완주 인증서는 이미 존재한다** (제주교구). 우리 앱 기능은 신규성이 아니라
   **디지털화·전국 통합**이 차별점이어야 한다.
4. 🔴 **국가유산청 경로는 "가능성"이 아니라 이미 뚫린 길이다.** 칠곡군 + 왜관수도원이
   **생생국가유산 사업**으로 2년째 운영 중이고, 홀리 페스티벌에 **3일간 1만 2천 명**이 왔다.
   6장 갈래 A 전체를 다시 써야 한다. (3장 참고)
5. 🔴 **우리 프로그램 C "빛의 성당들"은 칠곡의 "빛의 성당"과 이름이 겹친다.** 개명 필요.
6. 🔴 **다국어 차별점의 유효기간이 짧다.** 서울대교구가 순례길을 **9개 국어**로
   **2026년 3월까지** 만든다. 우리는 208곳 중 72곳(35%), 감수 0곳이다. (4장 참고)
7. 🟢 **서울 순례길은 2018년 교황청 승인 아시아 최초 국제 순례지**다. 강한 카드다.
8. 🟢 **여행사는 앱이 없고, 교구는 전국 통합이 없다.** 이 틈은 실재한다.

## 1. 순례 전문 여행사 — 상품 판매형

성지순례는 이미 **여행업 등록을 하고 상품을 파는 산업**이다. 이 사실 자체가 저장소 어느 문서에도
없었다.

### 가톨릭계

| 회사 | URL | 성격 |
| --- | --- | --- |
| 가톨릭평화방송여행사 | `cpbctour.co.kr` | **가톨릭평화방송(cpbc) 계열.** 가톨릭 성지순례 전문 |
| 가톨릭신문투어 | `cttour.org` | 가톨릭신문 계열 성지순례 전문 |
| 가톨릭여행사 | `catholictravel.co.kr` | "미사와 함께하는 성지순례" — 일정에 미사를 포함 |
| 점프투어리즘 | `jumptourism.co.kr` | 국내·해외 가톨릭 성지순례 + 연수·시찰 |

> ⚠️ **주목할 것**: cpbc와 가톨릭신문은 우리가 `SNS-레퍼런스-조사`에서 "사실 확인용 소스"로만
> 분류했던 매체다. **그런데 둘 다 여행사를 갖고 있다.** 즉 교회 미디어가 이미 순례를 수익
> 사업으로 운영하고 있다. 협력 대상이자 경쟁자다.

### 개신교계 (포맷 참고용)

| 회사 | 확인된 내용 |
| --- | --- |
| 홀리랜드투어 | 김포 소재, 관광사업등록 제2018-0000002호. 해외 상품 위주 |
| 천지투어 / 로뎀투어 / 갈릴리투어 | 이스라엘·크루즈 성지순례 |

### 확인된 가격대

| 구분 | 가격 | 출처 |
| --- | --- | --- |
| 해외 성지순례 | 339만 ~ 539만 원 (터키·그리스 379만, 사우디 539만, 이집트·이스라엘 439만) | 홀리랜드투어 |
| **국내 당일 성지순례** | **6만 5천 ~ 9만 7천 원** | 당일성지순례 상품 목록 (개신교 성지 기준) |

국내 당일 상품은 **버스 + 성지 2~3곳 + 인근 일반 관광지**를 묶는 구조다.
예: 전주순례길 + 전주한옥마을 82,500원 / 화성 제암리교회 + 수촌교회 65,000원.

> **시사점**: 순례만 파는 게 아니라 **일반 관광을 끼워 파는 것이 표준 포맷**이다.
> 우리 앱의 "TourAPI 주변 관광지 연결"이 이 포맷과 정확히 같은 발상인데,
> 여행사는 이걸 오프라인 버스 상품으로 이미 팔고 있다.

## 2. 교구·성지 직영 프로그램 — 우리와 가장 가까운 경쟁자

### ⭐ 서울대교구 순교자현양위원회 — `martyrs.or.kr`

**직접 경쟁자다.** 우리가 하려는 것을 이미 하고 있다.

| 항목 | 내용 |
| --- | --- |
| 운영 주체 | 천주교 서울대교구 순교자현양위원회 |
| 프로그램 | ① 도보 성지순례 (서울 순례길 3개 코스) ② 서울 버스 순례(단체) ③ 전국 성지순례 ④ 한국·아시아 순례(준비 중) |
| **참가비** | **7,000원 / 인** |
| 포함 내역 | 해설용 **수신기 대여**, 안내책자, 기념 선물 |
| 운영 기간 | 3월~11월 |
| 회차 | 매월 첫째 화요일 / 첫째·둘째·넷째 토요일 / 마지막 수요일 (월 5~6회) |
| 접수 | 전월 마지막 월요일 09:00부터 **선착순 온라인 접수** |
| 결제 | 계좌이체 (재)천주교서울대교구유지재단 |
| 환불규정 | 3일 전 전액 / 2일 전부터 70% / 전날 16시 이후 불가 |

**여기서 읽어야 할 것:**

- 온라인 신청 시스템, 환불규정, 정기 회차, 유료화가 **전부 이미 갖춰져 있다.**
  "가톨릭에는 템플스테이 같은 게 없다"는 우리 전제는 **전국 표준화가 없다는 뜻이지,
  아무것도 없다는 뜻이 아니었다.**
- 7,000원에 수신기·책자·기념품까지 준다. **원가 이하의 사목 가격**으로 보인다.
  상업적 가격 경쟁이 불가능한 앵커다.
- 다만 **서울 3개 코스뿐**이고, ④ "한국·아시아 순례"는 아직 준비 중이다.
  **전국 단위는 비어 있다.**

### ⭐ 제주교구 "천주교 제주 순례길" — `santoviaggio.com`

**우리 앱의 핵심 기능이 이미 오프라인으로 존재한다.**

| 항목 | 내용 |
| --- | --- |
| 운영 주체 | 제주교구 |
| 코스 | **6개** — 김대건길(빛), 하논성당길(환희), 김기량길(영광), 정난주길(고통), 신축화해길(화해), 이시돌길(은총) |
| 장치 | **스탬프북** — 각 성당·성지에 스탬프 설치, 완주 후 **인증서** 발급 |
| 신청 | 스탬프북을 메일·카톡·홈페이지로 신청. 완주 후 사진 전송 → 인증서 |

> 🔴 **우리 앱은 `pilgrimage_routes` 3개 코스 + 스탬프 + 완주 인증서 PDF를 "차별 기능"으로
> 잡고 있었다. 제주교구는 이걸 6개 코스로, 코스마다 영성적 이름까지 붙여 이미 운영 중이다.**
> 게다가 코스 이름이 묵주기도 신비(빛·환희·영광·고통)와 대응한다 — 우리 "감정 태그" 발상보다
> 신학적으로 정교하다. 차별점을 "기능"이 아니라 "전국 208곳을 하나의 앱에서"로 옮겨야 한다.

### 그 밖에 확인된 것

| 주체 | 내용 |

> ⚠️ **주교회의 167곳 vs 우리 DB 208곳.** 기준이 다르다. 주교회의는 성지/사적지/순례지를
> 구분하는데 우리는 208곳을 뭉뚱그려 "성지"라 부른다. **심사·지원서에서 숫자를 대면
> "주교회의는 167곳이라는데?"라는 질문이 나온다. 분류 기준 대조가 필요하다.**

| 5축 비전 4번 "건축·예술·스테인드글라스" | **이미 상품화** — 색유리화 만들기 체험 |
| "가톨릭판 템플스테이가 없다" | **"왜관스테이"**가 있다 |
| 우리 순례 코스 3개 = 내포길·황석두길·김대건길 (전부 대전교구) | **한티가는길·제주 순례길·서울 순례길이 우리 DB에 없다.** 셋 다 스탬프·완주인증 체계를 이미 갖춘 곳이다 |

### 🟢 이 사례가 우리에게 주는 것

1. **국내 가톨릭 수요 실측치를 처음 확보했다** — 3일 **1만 2천 명**.
   템플스테이 34만 명/년과 함께 3장·4장의 근거가 된다.
   ⚠️ 단 **무료 축제**라 지불의사(WTP)는 여전히 미확인이다. 이 숫자를 매출 근거로 바로 쓰면 안 된다.
2. **지자체 + 교구 + 수도회 3자 협력이 실제로 작동한다** (한티가는길, 홀리페스티벌).
   6장 "보완자산 0건"을 푸는 템플릿이 이미 있다 — 우리가 발명할 필요가 없다.
3. **"Holy = Holiday" 프레이밍이 지자체 예산으로 검증됐다.** 우리 "쉼" 컨셉과 같은 방향이고,
   이미 언론이 "쉼과 치유"로 받아 썼다.
4. **칠곡군은 경쟁자가 아니라 1순위 협력 후보다.** 그들은 칠곡 안에서만 하고,
   우리는 전국 208곳을 다룬다. 그들의 콘텐츠를 전국 지도 위에 올려주는 쪽이 자연스럽다.

### 🔴 그런데 교구가 다국어를 직접 하기 시작했다

같은 기사에서 확인된 것:

- **천주교 서울 순례길** — **3월경까지 9개 국어 소개 홍보물 + 다국어 지원 홈페이지 제작 예정**
- **해미순교자국제성지** — 영어·중국어 등 다국어 정보 제공, **디지털역사체험관** 영상 다국어화

> **우리 5장 차별요소 4번("다국어 + WYD 2027")의 유효기간이 짧아졌다.**
> 우리는 208곳 중 72곳(35%)을 번역했고 **감수는 0곳**이다. 서울대교구는 24곳을
> **9개 국어**로 **올해 3월까지** 끝낼 계획이다. 곧 "우리만 다국어"라고 말할 수 없게 된다.
>
> **대응 방향** — 경쟁 축을 "번역했다"에서 **"208곳 전부를 한 곳에서"**로 옮겨야 한다.
> 교구는 자기 교구만 한다. 15개 교구가 각자 9개 국어로 만들어도, 그것을 가로질러
> 검색·비교·경로 설계하는 층은 여전히 없다.

파일럿은 **직접 운영보다 기존 프로그램의 통합 창구**로 시작하는 편이 현실적일 수 있다.

이것은 6장 비즈니스모델의 방향을 바꿀 수 있는 판단이므로, **결정 사항으로 남겨둔다.**
