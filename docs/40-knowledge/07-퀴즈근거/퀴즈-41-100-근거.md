# 퀴즈 41~100번 근거 (2026-11-19)

- 만든 과정: Claude 가 웹 검색으로 사실을 모아 60문항 작성 → Codex(웹 검색 사용) 1차 검증 → 지적 반영·문항 교체 → 바뀐 10문항 Codex 2차 검증 → Claude 재확인.
- 원칙: 근거를 두 번 찾아도 나오지 않은 것은 뺐다(전동성당 「약속」 촬영지, 풍수원성당 「러브레터」 촬영지). 자료마다 숫자가 갈린 것은 숫자를 뺐다(서소문 순교 복자 25위/27위, 김대중 세례 연도 1956/1957).
- 살아 있는 사람은 언론에 공개된 사실(결혼식 장소, 본인이 밝힌 세례명)만 썼다. 다니는 본당은 쓰지 않는다.
- 유래·「최초」는 해설에서 「알려져 있습니다」「전해집니다」로 쓴다.
