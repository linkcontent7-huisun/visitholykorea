# 세례명 카드 «이름의 뜻 · 이 성인은 누구인가» — 시안 5개 (2026-11-25, 개발클로드)

문장은 아래 공개 사실을 확인해 **새로 쓴 것**이다. cpbc 「모두의 세례명」의 글은 쓰지 않았다.
같은 이름의 성인이 여럿이면 대표 한 분을 적고, 다른 분은 «다른 성인»으로 짧게 적는다.

## 쓰는 규칙
- 이름 뜻은 어원이 공개 자료 두 곳에서 같을 때만 쓴다. 갈리면 성인 소개만 쓴다(사비나).
- 전승(역사로 확인 안 된 이야기)은 «~라고 전한다»로 쓴다.
- «이 이름을 받으면 이런 사람이 된다» 식 단정은 쓰지 않는다.
