# catholic_directory 테이블 구축 기록

## 무엇을 했나

VisitHolyKorea의 "마음 나침반" 추천이 195곳 안에서만 맴돌아 뻔하게 느껴진다는 문제를 해결하기 위해, 한국천주교주교회의(CBCK) 공식 주소록(directory.cbck.or.kr)을 전체 스크레이핑해서 Supabase에 새 테이블 `catholic_directory`를 만들고 채워 넣었다.

## 가져온 범위

CBCK 주소록의 아래 11개 카테고리를 전부 가져왔다 (2026-08-02 기준 수치):

| 카테고리 | 건수 |
|---|---|
| 본당 | 1789 |
| 공소 | 522 |
| 교육기관 | 360 |
| 의료기관 | 96 |
| 사회복지기관 | 1056 |
| 출판보도기관 | 59 |
| 기타단체 | 922 |
| 피정의집 | 194 |
| 성지사적지 | 192 |
| 수도회(남) | 224 |
| 수도회(여) | 504 |
| **합계** | **5918** |

## 테이블 구조

`holy_sites`(195곳, 큐레이션된 소개글·역사·감정태그가 있는 추천엔진용 테이블)와는 **의도적으로 분리**했다. `catholic_directory`는 이름·교구·연락처·주소·좌표만 있는 얕은 참조용 테이블이다. 본당·공소·일반 기관까지 `holy_sites`에 섞어 넣으면 추천 품질이 오히려 떨어지기 때문이다.

```sql
create table catholic_directory (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  category text not null,
  diocese text,
  contact_person text,
  phone text,
  address text,
  lat double precision,
  lng double precision,
  target_gender text,  -- '남'|'여'|null(전체/미상). 아직 자동으로 채워지지 않음, 수동 큐레이션 필요
  source_url text,
  created_at timestamptz default now()
);
```

## 작업 과정에서 겪은 문제와 해법

1. **Supabase 프로젝트 혼동**: 대시보드 로그인 세션이 실제 앱이 쓰는 프로젝트(`kaahuoqzkgshihypzzyh`)가 아니라 다른 빈 프로젝트(`stdmbtyppkyncasplmae`)에 접속돼 있었다. 노션의 "visit holy _Logo/아이디관리" 페이지에서 실제 DB 비밀번호(`데이터베이스패스워드`)를 찾아, 대시보드 UI 없이 직접 Postgres 커넥션(`aws-1-ap-northeast-1.pooler.supabase.com:6543`)으로 접속해 문제를 우회했다.
2. **본당 카테고리 파싱 오류**: 본당·수도회 항목에는 "설립일:YYYY.MM.DD." 줄이 끼어 있어서, 이걸 교구명으로 잘못 파싱하는 버그가 있었다. 전화번호 패턴이 있는 줄을 우선 채택하도록 고쳤다.
3. **지오코딩 대량 실패**: 카카오 로컬 API로 5,918건을 지오코딩했는데 처음엔 5건만 성공했다. 원인은 CBCK 주소가 전부 "28398 충청북도 청주시..." 처럼 **5자리 우편번호가 주소 맨 앞에 붙어 있어서** 카카오 주소 검색이 이를 인식하지 못한 것. 우편번호를 정규식으로 제거하니 100% 성공률로 올라갔다.

## 2차 작업(같은 날 밤): 피정의집·성지사적지 386건에 설명·사진 채우기

노희선이 "질문지 결과가 뻔하다"고 지적한 부분을 보완하기 위해, 실제 추천에 노출되는 두 카테고리(피정의집 194 + 성지사적지 192 = 386건)에 한해 배경 조사 에이전트 4팀(카테고리별 2팀씩)을 병렬로 돌려 설명·사진을 채웠다.

**작업 방식**: 각 에이전트가 담당 배치(약 96~97건)를 웹 검색해서 (1) 2~4문장 한국어 설명, (2) 위키미디어 커먼즈 또는 TourAPI(`firstimage`)에서 라이선스가 확인되는 사진만 — 찾지 못하면 정직하게 null로 남기고 사진을 지어내지 않는다는 원칙으로 진행했다.

**결과**:

| 배치 | 설명 확보 | 사진 확보(라이선스 확인) |
|---|---|---|
| 피정의집 1 | 96/97 | 4/97 |
| 피정의집 2 | 57/97 | 4/97 |
| 성지사적지 1 | 95/96 | 37/96 |
| 성지사적지 2 | 92/96 | 36/96 |
| **합계** | **340/386 (88%)** | **81/386 (21%)** |

성지사적지(역사가 명확한 순교 성지 등)는 설명·사진 모두 확보율이 높았고, 피정의집(특히 배치2 — 작고 잘 알려지지 않은 개인 기도의 집이 많은 구간)은 설명 확보율이 낮고 사진은 거의 못 찾았다 — 애초에 예상했던 대로다. 사진 출처는 `tong.visitkorea.or.kr`(TourAPI, 44건, 공공누리 제1유형) / `upload.wikimedia.org`(위키미디어 커먼즈, 37건, CC BY-SA) 두 곳뿐이며, 실제 라이선스가 확인되지 않은 이미지는 하나도 넣지 않았다.

**겪었던 문제**: 에이전트 하나(피정의집 배치1)가 중간에 API 오류로 끊겨서 재실행했고, 재실행 중에도 스크래치패드 임시 파일명이 동시에 돌던 다른 배치(성지사적지)와 겹쳐서 결과가 뒤섞이는 사고가 있었다 — 해당 에이전트가 ID 대조로 스스로 발견해서 파일명을 바꿔 재작업했다. 다음에 여러 에이전트를 병렬로 돌릴 때는 처음부터 배치별로 겹치지 않는 임시 파일명을 지정해줄 것.

DB 컬럼(`description`, `image_url`, `image_source`, `image_license`)은 `catholic_directory` 테이블에 추가했고, GitHub의 `supabase/catholic_directory_migration.sql`에도 반영해뒀다.

## 3차 작업(재부팅 후 이어서): 노션 교구 자료를 holy_sites에 반영

노션 "대한민국 성지 자료" 데이터베이스의 교구별 종합자료집 15개(서울대·부산·광주대·대구대·안동·제주·청주·인천·수원·원주·전주·춘천·의정부·마산·대전, 북한3교구 제외)를 훑어서 `holy_sites`(195곳)에 없는 새 성지를 찾아 추가했다.

**중요한 발견**: 서울대교구·대전교구는 확인해보니 이미 기존 195곳에 노션 자료 대부분이 반영되어 있었다 — 이 195곳 자체가 애초에 이 노션 데이터베이스에서 만들어진 것으로 보인다. 그래서 "노션 자료를 통째로 옮기면 확 늘어날 것"이라는 기대와 달리, 실제로 겹치지 않는 새 성지는 교구당 0~5곳 정도로 적었다.

**결과**: 4개 에이전트(교구별 그룹)로 나머지 13개 교구를 조사해서 최종 **13곳**을 새로 추가했다(195 → 208곳).

| 교구 | 새로 추가된 곳 |
|---|---|
| 대구대교구 | 범어 주교좌대성당, 비산동 날뫼 순교지, 장대벌 순교지 |
| 안동교구 | 퇴강 성당 |
| 제주교구 | 산토비아조(Santo Viaggio) 순례길 |
| 인천교구 | 김포 성체성지, 백령도 성지 |
| 수원교구 | 한덕골 성지, 던지실 성지, 천호성지 |
| 춘천교구 | 인제 소양로 성당(내면), 거두리 성당, 죽림동 주교좌 성당 |
| 부산·광주대·전주·청주·마산·의정부·원주 | 0곳(전부 기존과 중복이거나, 주소·역사 정보가 너무 부실해서 정직하게 스킵) |

주소가 면/구 단위까지만 있는 항목(한덕골·던지실·천호성지 등)은 좌표가 정확한 지번이 아니라 근사치라는 점을 각 레코드의 history에 남겨뒀다. 원주교구 페이지는 내용이 아예 비어 있었다 — 나중에 확인 필요.

## 아직 안 된 것 / 다음에 할 일

- `target_gender` 컬럼은 만들어뒀지만 CBCK 주소록 자체에는 이 정보가 없어서 전부 비어 있다. 실제로 성별 특정 프로그램(예: 성령선교수녀회 '쉼' 피정 — 만 40세 이하 미혼 여성)을 앱에서 안내하려면, 개별 시설에 직접 확인하거나 언론·주보에서 찾은 정보로 하나씩 수동 채워야 한다.
- ~~노션 "대한민국 성지 자료" 데이터베이스를 holy_sites로 옮기기~~ → **완료(위 3차 작업 참고)**. 다만 원주교구 노션 페이지가 비어 있었던 것, 그리고 부산·광주대·전주·청주·마산·의정부 쪽에서 "이름만 있고 주소·역사 정보가 없어서 스킵한" 후보들(전주옥 순교지, 신시도 최양업 공원, 피아골 피정집, 서홍동 성지 등)은 diocese 홈페이지나 가톨릭굿뉴스에서 직접 정보를 보강하면 추가로 채울 수 있다.
