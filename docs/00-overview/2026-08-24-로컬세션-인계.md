**쉼자리 3단 구조를 헷갈리지 말 것.** 이름이 비슷해서 중복으로 오해하기 쉬운데
의도된 분리다 (`docs/10-product/2026-08-쉼자리-컨셉.md` 참고):

```
catholic_directory → rest_places → rest_spots → rest_spot_reports
   어디에 무엇이      쉼자리를 품은   자리 하나하나   사용자 제보
      있는가            시설         (진짜 자산)
```

한 시설에 자리가 여러 개일 수 있어서 1:N 이다. 합치면 시설 정보가 자리 수만큼 중복된다.
0행인 건 잘못이 아니라 **아직 안 채운 것**이다. 발로 뛰거나 제보로 모아야 하는 데이터라
자동 수집 대상이 아니다.

### DB 접속이 안 될 때

`SUPABASE_DB_URL` 은 `.env.local` 에 있다 (git 추적 안 됨).
비밀번호를 재설정하면 **커넥션 풀러 반영이 몇 분 늦는다.** 그 사이에는 올바른
비밀번호인데도 `password authentication failed for user "postgres"` 가 계속 뜬다.
**값을 의심해서 다른 비밀번호를 연달아 넣지 말 것** — 원인만 꼬인다. 기다렸다 다시 한다.

> **함정** — `select('*', { head: true })` 는 테이블이 없어도 통과한다.
> 테이블 존재 확인은 반드시 컬럼을 지정해서 조회해야 한다.
