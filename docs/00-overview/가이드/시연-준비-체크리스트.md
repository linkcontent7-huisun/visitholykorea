# 시연 준비 체크리스트 — 순례지원팀 방문

## 전날 (로컬 세션에서, 30분)

- [ ] `git pull` 후 `claude/status-check-0ptb3t` 브랜치를 main 에 머지
- [ ] `npm ci && npm run verify` — 전부 통과 확인
- [ ] `npm run db:migrate` — 스탬프 한 줄·즐겨찾기 테이블 반영
- [ ] `npm run translate:import -- data/translations/en-서울.todo.json` 등
      13개 파일 import (영어 시연을 안 할 거면 생략 가능)
- [ ] `npm run dev` 로 열어서 **시연 순서대로 한 번 리허설**
- [ ] 인터넷 안 될 때를 대비해 주요 화면 **스크린샷 저장**

## 당일 주의

- **TourAPI 개발계정은 하루 1,000건.** 홈 화면 1회 로드 = 21건.
  시연 전에 홈을 반복해서 열지 말 것 (45회면 그날 끝). 리허설은 전날에.
- 배포 사이트(visitholykorea-app.vercel.app)를 예비로 — 로컬이 말썽이면
  바로 전환. 노트북 + 핸드폰(배포 사이트) 두 개를 준비하면 안전.

## 시연 순서 (10~15분)

1. **홈 — 오늘의 쉼표** (2분): "지금 이 순간 전국에서 조용한 성지 세 곳"
   이 실시간 계산임을 강조. 새로고침하면 값이 그날 데이터로 나온다
2. **성지 상세** (3분): 소개글 → **음성 안내(TTS) 재생** → 미사·연락처 →
   스탬프 찍기 → "오늘 그곳은 어땠나요?" 한 줄 남기기 → 다녀온 사람의 한 줄
3. **붐빔 피하기** (2분): "해미읍성" 검색 → 붐빔 + 근처 조용한 성지 추천
4. **순례 코스** (2분): 박해 사건·인물 축으로 성지를 잇는 길
5. **AI 미카엘** (2분): 성지 질문 하나 + **일부러 자료 밖 질문** →
   "모른다"고 답하는 것을 보여주며 정직성 원칙 설명
6. **기록 탭** (1분): 순례 여권·교구별 진행률·인증서
7. **마무리**: 도슨트 비전 (기획서 3장) + 협조 요청 (기획서 6장)

## 예상 질문 대비

- "누가 만들었나" → 개인 프로젝트, 공모전 출품 겸함. 교회 공식 아님을 명확히
- "AI 가 틀린 말 하면" → 자료 안으로 제한 + 모르면 모른다 (시연 5번)
- "개인정보는" → 로그인 선택제, 기록은 본인만 조회(DB 정책 강제),
  한 줄 기록만 익명 공개
- "비용은" → 현재 무료 범위 운영, 공사 API 는 운영계정 전환 예정
