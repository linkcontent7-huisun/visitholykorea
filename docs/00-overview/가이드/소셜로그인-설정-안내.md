# 소셜 로그인 설정 안내 (2026-08-18)

로그인 화면에 네이버·카카오·구글·페이스북 버튼이 붙어 있다 (투어원패스 형식).
코드는 완성됐지만, **각 제공자의 개발자 콘솔에 앱을 등록하고 키를 넣어야 실제로 작동한다.**
이 문서는 그 등록 절차를 정리한 것이다. 모두 사용자(계정 소유자)가 직접 해야 하는 일이다.

## 1. 카카오 (Supabase 공식 지원)

1. [Kakao Developers](https://developers.kakao.com/) → 애플리케이션 추가
2. 제품 설정 → 카카오 로그인 활성화, Redirect URI에 위 콜백 주소 등록
3. 동의 항목: 닉네임·이메일(선택)
4. REST API 키·Client Secret 복사
5. Supabase 대시보드 → Authentication → Providers → Kakao 켜고 키 입력

## 2. 구글 (Supabase 공식 지원)

1. [Google Cloud Console](https://console.cloud.google.com/) → 프로젝트 생성 → OAuth 동의 화면 구성
2. 사용자 인증 정보 → OAuth 클라이언트 ID (웹) 생성, 승인된 리디렉션 URI에 위 콜백 주소
3. 클라이언트 ID·Secret 복사 → Supabase Providers → Google 켜고 입력

## 3. 페이스북 (Supabase 공식 지원)

1. [Meta for Developers](https://developers.facebook.com/) → 앱 만들기 (소비자 유형)
2. Facebook 로그인 제품 추가 → 유효한 OAuth 리디렉션 URI에 위 콜백 주소
3. 앱 ID·Secret 복사 → Supabase Providers → Facebook 켜고 입력
4. ⚠️ 앱을 "라이브 모드"로 전환해야 일반 사용자가 로그인할 수 있다

## 4. 네이버 (직접 구현 — Edge Function)

네이버는 Supabase가 공식 지원하지 않아 `supabase/functions/naver-auth` 함수가 OAuth를 대신 처리한다.

1. [네이버 개발자센터](https://developers.naver.com/) → 애플리케이션 등록 (네이버 로그인)
2. 제공 정보: **이메일 주소(필수)**, 이름 — 이메일을 필수로 켜야 한다 (없으면 로그인 실패 처리됨)
3. 서비스 URL: `https://visitholykorea-app.vercel.app`
4. Callback URL: 위 네이버 콜백 주소
5. 발급받은 Client ID·Secret을 Supabase 시크릿으로 등록 후 함수 배포:

```bash
supabase secrets set NAVER_CLIENT_ID=발급받은ID NAVER_CLIENT_SECRET=발급받은시크릿 APP_URL=https://visitholykorea-app.vercel.app
```

```bash
supabase functions deploy naver-auth --no-verify-jwt
```
