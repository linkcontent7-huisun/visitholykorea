### Claude Fable 5.1 가이드 반영 내역
`.claude/agents/*.md`, `.claude/rules/orchestrator.md`,
`docs/70-agent-workspace/규칙.md` 에 반영:
- 자율 실행("묻지 말고 되돌릴 수 있는 일은 진행")
- 변경 범위 규율(지시서 밖 버그는 기록만, 확인용 스크립트는 테스트로 안 남김)
- 파일 전체 재작성보다 대상 지정 편집
- 지시자는 서브에이전트 도는 동안 유휴 대기 안 함
- 외부 자료(신문 등) 인용 시 사실만 뽑아 새로 쓰기 원칙
- **의도적으로 안 바꾼 것도 있다**: "서식 줄이기" 항목은 사용자 CLAUDE.md 가
  이미 조건부 규칙("선택지 2개 이상이면 표로")으로 같은 원칙을 지키고 있어
  그대로 뒀다 — 매뉴얼 문장을 그대로 베끼는 게 항상 정답은 아니다.

### 🔴 정정 — subagent_type 직접 호출 불가
`subagent_type: "developer"` 로 부르면 **"Agent type not found"** 로 실패한다.
이 환경은 정해진 종류(`general-purpose` 등)만 받는다. 우회법:
`general-purpose` 를 부르면서 프롬프트 맨 앞에 "`.claude/agents/<role>.md`
를 읽고 그 역할을 따르라"고 명시한다. `orchestrator.md` 에 반영됨.
