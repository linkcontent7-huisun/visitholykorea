## 1. 오늘 끝난 것

### DB — 막혀 있던 것이 풀렸다

`.env.local` 에 `SUPABASE_DB_URL`(Session pooler URI)을 넣자 마이그레이션이 돌았다.

- **8개 전부 적용.** 적용 이력 테이블이 그때 처음 생겨 기존 5개까지 함께 기록됐다.
  SQL 이 모두 `if not exists` 형태라 데이터는 그대로다 (208행 · 5,918행 유지).
- `pilgrimage_logs` · `rest_spots` · `holy_site_translations` 새로 생성
- **대전 27곳 영어 번역 DB 반영 완료** — 새로 27행, 상태 `machine`(기계 초벌)
- **여행기 화면(`/records`) 정상 동작 확인**

### TourAPI — 초당 한도(코드 23) 대비

홈 1회 로드가 **21회**를 부르는 것을 호출부에서 실측했다
(축제 1 + 붐빔 후보 12 + 코스 8). 셋 다 `Promise.all` 이라 거의 동시에 나간다.

- `src/shared/api/tour-api.ts` 에 **동시 실행 4개 제한** 적용
- 게이트를 `src/shared/lib/concurrency-gate.ts` 로 분리하고 테스트 5개 추가
  (슬롯 인계 경계에서 한도를 넘지 않는지 고정)
- 총 호출량·응답은 그대로. 응답을 저장하지 않으므로 ADR 0002 에 저촉 없음
- `npm run verify` 통과 — 테스트 153개

### 왜 이 순서인가

- **거룩한말씀의수녀회 성당**(대전 중구 목동 96-27, 시 문화유산자료 45호):
  대전에서 가장 오래된 성당(1921). 6·25 때 인민군 치안본부로 쓰였고
  양민 학살과 **아일랜드 선교사 2명 순교**가 있었던 자리. 이야기가 가장 세다.
- **대흥동 주교좌성당**(국가등록문화재 43호): 1962년 완공 당시 대전 최고층.
  49.8m 종탑 · 12사도 부조 · 이남규 스테인드글라스 · 피에타. 그림이 가장 잘 나온다.
- **법동성당**: 역사 소재는 없다. 대신 **성당 결혼식**(수용·피로연·주차)으로 가면
  수요가 확실한데 대전 정보가 비어 있다. 2일차로 따로.

### 현장에서 반드시 채워 올 것

- [ ] **대흥동성당 전화번호** — 우리 DB 에 비어 있다
- [ ] **대흥동 GPS 좌표** — DB `36.3228, 127.4254` vs 주소록 `36.3270, 127.4263`,
      약 **470m 차이**. 정문 앞에서 위치태그 켜고 사진 한 장 찍으면 판정된다
- [ ] **거룩한말씀 건축 연도** — 국가유산포털 1921년 vs 중도일보 1927년 완공. 한쪽으로 확정
- [ ] 법동 — 하객 수용 인원 · 식당 좌석 · 주차 대수 · 비신자 가능 여부
- [ ] 각 성당 미사 시간 · 주차 · 화장실 · 경사도

Expert RAW 설치 · **위치 태그 켜기** · 격자 켜기 · 메인 50MP · 렌즈 닦기.
