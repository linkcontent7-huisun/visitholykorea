# 프로젝트 개요

## 무엇을 만드는가

한국 가톨릭 성지 208곳을 다루는 순례 안내 웹앱. 세 가지를 동시에 한다.
(오래된 문서에 "195곳"으로 남아 있는 것은 초기 수집분 기준이다. 2026-08-11 DB 실측은 208곳.)

1. **찾게 한다** — 교구·분류·검색으로 성지를 찾고, 감정 태그로 코스를 추천받는다.
2. **가게 한다** — 성지 옆 도보권 관광지를 TourAPI 실시간 데이터로 엮어 "하루 코스"로 만든다.
3. **남게 한다** — 다녀온 성지에 스탬프를 찍고 여행기를 남긴다(디지털 순례 여권).

## 왜 만드는가

- 종교관광 시장은 연 7~10%대로 성장 중인데, 순례에 특화된 완성도 높은 디지털 도구는
  산티아고 정도를 빼면 세계적으로도 드물다. 한국 가톨릭 성지 특화라는 포지션 자체가 비어 있다.
- 성지 정보는 교구·성지별로 흩어져 있고, 한곳에서 통합 검색·관리되는 서비스가 없다.
- 근거와 시장 조사는 [`docs/40-knowledge/05-비즈니스기획/여행업계동향과_기능제안서.md`](../40-knowledge/05-비즈니스기획/여행업계동향과_기능제안서.md) 참고.

## 세 갈래 콘텐츠 전략

앱은 삼각형의 한 꼭짓점일 뿐이다. 성지 한 곳을 취재하면 세 방향 결과물이 동시에 나온다.

| 채널   | 성격                            | 역할               |
| ------ | ------------------------------- | ------------------ |
| 유튜브 | 성상·석상 야간 장시간 감상 영상 | 사람을 머물게 한다 |
| 블로그 | 역사·건축·성물·인터뷰 아카이빙  | 장소를 기록한다    |
| 앱     | 가족·목적별 맞춤 추천           | 길을 제안한다      |

운영 방식은 [`docs/30-content-ops/취재-촬영-아카이빙-운영매뉴얼.md`](../30-content-ops/취재-촬영-아카이빙-운영매뉴얼.md) 에 정리되어 있다.
