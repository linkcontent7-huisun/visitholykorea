# 웹 세션에서 일하기

> claude.ai/code 웹 브라우저로 이 프로젝트를 이어서 작업할 때 읽는다.
> **날짜가 없는 문서다.** 상황이 바뀌면 이 문서를 고친다.
> 지금 무엇이 끝났고 무엇이 남았는지는 언제나 `docs/이어서-할-일.md` 가 최신이다.

---

## 0. 세 줄 요약

1. 웹 세션은 **DB 를 못 본다.** 노트북 파일도 못 본다. 이건 설정 문제가 아니라 구조다.
2. 그래도 **저장소 안에서 끝나는 일은 전부 된다** — 코드·문서·기획·PR·번역 감수.
3. 세션끼리 대화가 안 통한다. **연락 수단은 GitHub 저장소뿐이다.**

---

## 1. 시작할 때 순서

```bash
git pull          # 제일 먼저. 로컬 창이 밀어둔 게 있을 수 있다
npm ci            # 컨테이너가 새로 뜨면 node_modules 가 없다
```

그다음 `docs/이어서-할-일.md` 를 읽는다. 그게 현재 상태의 유일한 기준이다.

작업이 끝나면 **그 자리에서** `docs/이어서-할-일.md` 를 고치고 **푸시한다.**
푸시하지 않으면 다음 세션은 그 일이 있었는지도 모른다.

---

## 2. 웹에서 되는 일 / 안 되는 일

| 하려는 일                          | 웹 | 이유 |
| ---------------------------------- | -- | ---- |
| 코드 수정 · 리팩터링 · 테스트      | ✅ | 저장소 안에서 끝난다 |
| `npm run verify`                   | ✅ | 〃 |
| 문서 · 기획서 작성                 | ✅ | 〃 |
| GitHub PR · 이슈                   | ✅ | github.com 은 허용 도메인 |
| 번역 파일 감수 (`data/translations/`) | ✅ | 파일 안에서 끝난다 |
| **DB 조회 · 마이그레이션**         | ❌ | `.env.local` 을 못 본다 |
| **번역 import / export**           | ❌ | DB 가 필요하다 |
| **사진을 DB 에 넣기**              | ❌ | 〃 |
| **실사용자 수 재기**               | ❌ | 〃 |
| **배포 사이트 열어보기**           | ❌ | vercel.app 차단 |
| **TourAPI 호출**                   | ❌ | data.go.kr 차단 |
| OneDrive · 학습자료 열람           | ❌ | 노트북 파일 |

차단 목록은 2026-08-19 실측이고 8/27 에도 같았다.

**"오늘 로컬에서 한 일 중 웹에서 가능했던 것은 하나도 없었다"** (2026-08-27).
번역 208곳도, 마이그레이션도, 사진 검증도 전부 DB 나 노트북 파일이 필요했다.
그러니 웹을 기본으로 쓰되, **DB 에 반영하는 순간에만 로컬 창을 잠깐 연다.**
한 번에 몇 분이면 끝난다.

## 3. 창을 오갈 때 지킬 세 줄

세션끼리는 서로의 대화를 모른다. `ListAgents` 는 "No reachable agents" 를 준다
(2026-08-27 실측). 자동 전달 통로가 없다.

1. 창을 옮기기 **전에** → 쓰던 쪽에서 **푸시**
2. 창을 열자마자 → **`git pull`**
3. **같은 파일을 양쪽에서 동시에 고치지 않는다**
   — 2026-08-27 에 `이어서-할-일.md` 에서 실제로 충돌했다

로컬 창에 시킬 일이 있으면 **붙여넣기용 지시문**으로 남긴다.
말로 "로컬에서 해주세요"라고 적어두면 다음 세션이 무엇을 할지 모른다.

## 7. 절대 하지 않는 것

- **TourAPI 응답을 저장하지 않는다** (실격 위험 · ADR 0002)
- **비밀 키를 `VITE_` 로 클라이언트에 두지 않는다**
- **AI 가 그린 성지 사진을 넣지 않는다** — AI 가 그린 배티 순교성지는
  배티 순교성지가 아니다. 사진이 없는 편이 가짜 사진보다 낫다 (2026-08-27 결정)
