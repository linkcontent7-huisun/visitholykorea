**0. 서비스 롤 키가 상해 있다 — 다만 번역 작업은 이제 이것과 무관하다.**

`SUPABASE_SERVICE_ROLE_KEY` 가 `JWT issued at future` 로 거부된다.
노트북 시계는 정상이고(2026-08-26 08:40 UTC, 구글 서버와 초 단위까지 일치),
앱이 쓰는 anon 키도 멀쩡하다(REST 조회 HTTP 200 — **배포 사이트는 문제 없다**).
상한 건 그 키 하나뿐이다.

**번역 스크립트 3개는 `SUPABASE_DB_URL` 직결로 바꿨다** (`scripts/lib/db.ts`).
JWT 를 안 거치므로 키가 상해도 돈다 — 마이그레이션이 같은 사고에도 멀쩡히
돌았던 것과 같은 이유다. 그래서 아래 1·2번은 키 없이 이미 끝났다.
