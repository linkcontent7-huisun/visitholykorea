## 2. 정한 방향 — UI 디자인부터

사용자가 고른 순서다.

> **공모전 출품컨셉을 먼저 읽고 → 심사에서 실제로 보여줄 핵심 화면 3~4개만 골라 시안을 만든다.**

전체 13개 라우트를 다 그리지 않는다. 남은 기간이 6주라 **구현까지 가려면 범위를 좁혀야** 한다.

기준 문서: [`docs/10-product/2026-08-공모전-출품컨셉.md`](../10-product/2026-08-공모전-출품컨셉.md)

### 왜 UI 가 먼저인가 — 기능이 디자인에 막혀 있다

`docs/이어서-할-일.md` 3번 항목이 근거다.

> "`AlternativesList.tsx` 는 정의만 있고 어디서도 import 하지 않는다.
> **UI 디자인이 정해지면** 스타일을 입히고 `src/app/routes/paths.ts` 에 경로를 추가한다."

대체 추천 기능은 로직·훅·컴포넌트까지 끝났는데 **디자인이 없어 화면에 못 붙었다.**
디자인이 나오면 바로 붙는 기능이 이미 있다는 뜻이다.

### 시안 도구

Claude Design 캔버스(`design` 스킬)를 쓸 수 있다. 여러 화면을 한 캔버스에 아트보드로 깔면
사용자가 직접 클릭해서 색·글자·간격을 고칠 수 있다. 확정된 것만 구현으로 넘긴다.

### 이미 시작된 디자인 조사 — 중복하지 말 것

**같은 날(2026-08-20) 다른 세션이 이미 실측 조사를 해 뒀다.**
[`docs/50-research/디자인-레퍼런스_2026-08-20.md`](../50-research/디자인-레퍼런스_2026-08-20.md) (아직 커밋 안 됨)
