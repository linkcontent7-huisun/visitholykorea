이 판을 다시 부르는 말

"기술 설계도·CR·구조도" 같은 말은 서로 다른 문서를 가리킨다. 이 현황판이 원하는 것이면 첫 줄만 말하면 된다.

"현황판 갱신해줘"이 페이지를 지금 코드·DB 기준으로 다시 잰다 (숫자·상태·남은 일)
"화면 흐름도 보여줘"위의 "화면이 움직이는 순서"만 — 새 화면을 넣기 전에 볼 때
"기술 구조도 보여줘"브라우저·서버·외부 API 연결 그림 — 심사위원·개발자에게 설명할 때
"기능 현황표 보여줘"기능별 완료·진행·미착수 표만 — 무엇을 시킬지 고를 때
"이어서 할 일 알려줘"docs/이어서-할-일.md 맨 위 항목 — 매 세션 시작 때
"보고서 써줘"끝난 것·진행 중·판단 필요·못 한 것 — 정해진 날 보고 형식

CR(Change Request)은 "고쳐 달라는 요청서"라 현황을 보는 문서가 아니다. 설계 이유가 궁금하면 "왜 이렇게 만들었어" — 그건 docs/20-architecture/adr/에 있다.
