- `fixed` 는 스크롤해도 안 사라지므로, 히어로가 지나 흰 「성지 찾기」 카드까지 오면 투명 유리 위 흰 로고 글자가 흰 배경과 겹쳐 안 보이는 사고가 났다(헤드리스 Chrome 으로 실측 발견). 그래서 히어로(`#home-hero`)의 아래쪽 끝이 헤더 높이(모바일 60·PC 72) 아래로 완전히 내려가면 다른 화면과 같은 불투명 흰 헤더로 되돌아간다 — 위치는 계속 `fixed`(자리를 다시 차지하면 본문이 훌쩍 밀려 내려가 버벅여 보인다), 색만 바뀐다.
- 🔑 **두 번째 사고 — 첫 로딩에 헤더가 계속 불투명했다(1440px 새로고침 실측).** `HomePage` 는 `React.lazy`(`router.tsx`)라 처음 그릴 때 `#home-hero` 가 아직 없다. 없으면 "이미 지나갔다"(0 으로 대체)로 잘못 읽었다 — 없을 땐 아예 판단을 보류하고 초기값(투명)을 그대로 두게 고쳤다.
- `TextSizePicker`·`LanguagePicker` 에 `variant="onDark"` 추가(기존 `CrowdingLabel` 의 `default`/`onDark` 패턴을 그대로 따랐다) — 평소 흰 배경 대신 반투명 검정 칩 + 흰 글자. 로그인 버튼은 원래도 불투명한 남색이라 그대로 두고 그림자만 더함. 로고 글자는 흰색 + 그림자, 마크에는 옅은 그림자.
