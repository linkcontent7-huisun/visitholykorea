## 작업 환경 — 어디서 무엇을 하는가

세션이 두 종류라 헷갈리기 쉽다. **할 수 있는 일이 다르다.**

|                        | 노트북 파일 | 외부 인터넷   | 쓰는 곳                             |
| ---------------------- | ----------- | ------------- | ----------------------------------- |
| 로컬 CLI · 데스크톱 앱 | 볼 수 있음  | 전부 됨       | DB 작업, OneDrive 정리, 배포 확인   |
| 웹 (claude.ai/code)    | **못 봄**   | 허용 도메인만 | 저장소 안에서 끝나는 코드·문서 작업 |

웹 세션은 GitHub 저장소만 복제해온 클라우드 컨테이너에서 돈다.
OneDrive 든 `.env.local` 이든 노트북 안의 것은 구조적으로 접근이 안 된다.
인터넷은 허용 목록에 있는 도메인만 나간다 — 2026-08-19 실측으로
supabase.com·vercel.app·TourAPI(data.go.kr) 는 차단, 문서 사이트류는 일부 열림.
환경 설정(claude.ai/code 의 환경 선택기)에서 허용 도메인을 늘릴 수는 있지만,
비밀값 저장소가 없어 DB 비밀번호를 웹 환경에 넣는 것은 권장되지 않는다.
