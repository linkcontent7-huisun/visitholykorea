## 작업 환경 — 어디서 무엇을 하는가

세션이 두 종류고 **할 수 있는 일이 다르다.** 자세한 것은 `00-overview/가이드/웹세션-시작하기.md`.

| | 노트북 파일 | 외부 인터넷 | 쓰는 곳 |
| --- | --- | --- | --- |
| 로컬 CLI · 데스크톱 앱 | 볼 수 있음 | 전부 됨 | DB 작업, OneDrive 정리, 배포 확인 |
| 웹 (claude.ai/code) | **못 봄** | 허용 도메인만 | 저장소 안에서 끝나는 코드·문서 작업 |

웹 세션은 저장소만 복제해온 클라우드 컨테이너에서 돈다 — OneDrive 도 `.env.local` 도 구조적으로 못 본다.
supabase·vercel·TourAPI 는 차단돼 있다 (2026-08-19 실측).

⚠️ **로컬 세션이어도 `.env.local` 이 없으면 DB 를 못 본다.** 포크를 새로 복제한 폴더가 그렇다
(2026-09-14 이 세션이 그 경우였다). 클론했다고 DB 가 따라오지 않는다.

**세션끼리는 서로의 대화를 모른다. 연락 수단은 GitHub 저장소뿐이다** — 창을 옮기기 전에 푸시하고,
열자마자 `git pull` 한다.
