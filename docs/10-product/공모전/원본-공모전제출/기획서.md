# 서비스 기획서

## 쉼표 순례길 — 오버투어리즘 대응 감정 기반 성지순례 코스 추천

> 2026 관광데이터 활용 공모전 ②-2 웹·앱 구현 부문 — 지정과제 2번
> (유명 관광지 쏠림/오버투어리즘 문제 해결)
> 주최기관: 한국관광공사 — **"대한민국 구석구석"** 앱 스타일 벤치마킹

---

## 0. 기획 전환점

v1(감정 필터 검색 도구)은 기능은 있지만 밋밋했다. 처음엔 서울시 "비지트서울" 앱의 개인 에디터 감성 문체를 참고했으나, **이 공모전의 실제 주최기관인 한국관광공사가 운영하는 "대한민국 구석구석"**을 다시 살펴보니 톤이 다르다.

**대한민국 구석구석의 실제 콘텐츠 문법**:

- 개인 에디터의 문학적 문장이 아니라, **"여행코스"** 단위의 캠페인형 콘텐츠 (예: _"한국관광공사 추천 3월 걷기여행길, 음악이 흐르는 걷기여행길"_)
- **캠페인 브랜딩**을 걸고 시리즈를 운영 (예: "여행가는 달", "한국관광의 별")
- 제목 패턴: **[테마/시기] + [지역·코스 유형] + [여행길/코스]** 구조로 실용적이면서 캐치프레이즈화
- **AI를 활용해 여행기사 요약 정보를 자동 제공**한다고 스스로 명시 — AI 큐레이션을 이미 공식적으로 채택 중

**v2의 전환**: 우리 서비스도 "여행코스" 포맷과 캠페인 브랜딩을 채택해서, 주최기관 앱과 톤이 자연스럽게 맞물리는 서비스로 설계한다. (심사위원이 "우리 플랫폼 철학과 잘 맞는다"고 느끼게 되는 효과도 있음)

---

## 1. 배경 및 문제 정의

### 1-1. 지정과제와의 연결 — "코스 단위 분산"

기존 오버투어리즘 대응은 대개 "단일 명소 A 대신 단일 명소 B"식 1:1 대체 추천에 그친다. 본 서비스는 한 걸음 더 나아가 **"혼잡 명소를 경유하되, 그 옆에 숨은 성지를 엮은 완결된 코스"**를 제공한다 — 대한민국 구석구석의 "여행코스" 콘텐츠 문법과 동일한 접근.

예: **"수원, 마음을 내려놓는 성지 걷기 코스"**
= 화성행궁(TourAPI 인기 관광지, 혼잡) → 도보 20분 → 수원 화성 순교성지(한적, 감정 케어) → 인근 산책로

### 1-2. 왜 성지(순례지)인가

- 전국 각지에 분포 — 특정 대도시에 쏠리지 않음, 대한민국 구석구석의 "구석구석"이라는 정체성과 정확히 부합
- 대부분 한적하고 사색에 적합한 공간 (오버투어리즘의 정반대 특성)
- 종교 여부와 무관하게 "걷기·사색·치유" 콘텐츠로 소구 가능
- TourAPI 등 공공 데이터에는 없는 세분화된 틈새 데이터 — 데이터 차별화
- **지수님의 지역 저널리즘 경력(마을기자·라디오 제작단)** — 코스 소개 문구를 실제 취재하듯 신뢰감 있게 쓸 수 있는 역량. AI 자동 생성이 흔해진 시대에, "직접 취재한 코스 가이드"는 경쟁 서비스가 흉내내기 어려운 신뢰 자산.

## 2. 타깃 사용자

- 번잡한 명소 대신 여유로운 여행을 원하는 자유여행객
- 여행을 통해 심리적 위안·재충전을 원하는 사람 (번아웃, 이별, 새출발 등 생애 전환점)
- 종교와 무관하게 "걷기 명상/사색 여행"에 관심 있는 2030~4050 세대
- 대한민국 구석구석의 "여행코스" 콘텐츠를 즐겨보는 기존 이용자층과 자연스럽게 겹침
- (부가) 실제 성지순례객, 외국인 관광객(다국어 지원)

## 3. 핵심 가치 제안

> "붐비는 그 코스 말고, 지금 당신 마음에 필요한 쉼표 하나"

기존 여행 추천 서비스가 "인기순/평점순 리스트"라면, 본 서비스는 **완결된 도보 코스 + 감정 매칭**을 제공한다. 혼잡 관광지 데이터(TourAPI)와 자체 구축한 성지 콘텐츠 DB를 결합해, "대한민국 구석구석"의 여행코스 콘텐츠 생태계에 자연스럽게 들어갈 수 있는 새로운 코스 카테고리를 만든다.

## 4. 콘텐츠 포맷 — "쉼표 순례길" 캠페인 & 코스 설계

### 4-1. 캠페인 브랜딩 체계 (대한민국 구석구석 "여행가는 달" 벤치마킹)

| 구성요소       | 예시                                                                                  |
| -------------- | ------------------------------------------------------------------------------------- |
| 캠페인명(고정) | **쉼표 순례길**                                                                       |
| 코스 제목 패턴 | [감정 테마] + [지역] + [코스 유형]                                                    |
| 코스 제목 예시 | "위로가 필요한 날, 수원 성지 걷기 코스" / "새출발을 다짐하는 이, 000성지 일출 순례길" |
| 코스 부제      | "화성행궁 인파를 뒤로하고, 도보 20분 한적한 기도의 자리로"                            |
| 해시태그       | #쉼표순례길 #성지순례 #걷기여행길 #수원가볼만한곳 #감정여행                           |

### 4-2. 감정 태그 체계 (콘텐츠 톤·코스 성격의 기준)

| 감정 태그 | 의미              | 코스 성격                           |
| --------- | ----------------- | ----------------------------------- |
| 위로      | 지치고 힘들 때    | 짧고 아늑한 도보 코스, 소규모 성지  |
| 새출발    | 인생의 전환점     | 전망 좋은 곳, 일출 코스             |
| 평온      | 그냥 쉬고 싶을 때 | 자연·숲길 동반 코스                 |
| 치유      | 마음의 상처 회복  | 역사적 의미 깊은 성지 중심 코스     |
| 감사      | 좋은 일이 있을 때 | 아름다운 건축·풍경의 대표 성지 코스 |

→ Notion DB에 `감정 태그`(Multi-select) + `짝지은 관광지`(Text, TourAPI 인기 관광지명) + `코스 제목`(Text) + `코스 부제`(Text) + `도보 소요시간`(Number) 속성 신규 추가.

## 5. 핵심 기능 정의

| 기능                  | 설명                                                                                                      | 우선순위               |
| --------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------- |
| 쉼표 순례길 코스 피드 | 캠페인 코스 카드 목록 (홈 화면, "대한민국 구석구석" 여행코스 탭과 유사한 UX)                              | P0                     |
| 감정 선택 진입        | 감정 카드로 필터링해 관련 코스만 보기                                                                     | P0                     |
| 관광지-성지 짝 매칭   | TourAPI 인기 관광지 + 도보권 성지 자동/수동 매칭                                                          | P0 (OpenAPI 필수 요건) |
| 코스 상세 페이지      | 코스 설명 + 스탑별 정보(혼잡 관광지→성지) + 실용정보(소재지/미사시간)                                     | P0                     |
| AI 코스 요약          | 성지 원본 자료를 AI로 코스 소개문 자동 초안 생성 (사람이 검수) — 대한민국구석구석의 "AI 요약" 철학과 동일 | P1                     |
| 주변 정보 연계        | 주변 관광지/숙박시설 (TourAPI 보완)                                                                       | P1                     |
| 다국어 지원           | 한/영 우선, 추후 확장                                                                                     | P1                     |
| 도보 동선/소요시간    | 코스 내 이동 정보                                                                                         | P1                     |
| 나만의 순례 기록      | 저장/기록 (구석구석의 "배지랜드"류 기능처럼 확장 가능)                                                    | P2                     |

> P0 = MVP 필수, P1 = 심사 시연에 있으면 좋음, P2 = 여유 있을 때

## 6. 사용자 시나리오 (예시)

1. 앱 접속 → 홈 화면에 "쉼표 순례길" 코스 카드 피드: "위로가 필요한 날, 수원 성지 걷기 코스" 등
2. 감정 카드("위로")로 필터링 가능
3. 코스 클릭 → 상세 페이지: 코스 개요("화성행궁 인파를 뒤로하고, 도보 20분") + 스탑 1(화성행궁, TourAPI 혼잡 정보) → 스탑 2(수원 화성 순교성지, 실용정보+짧은 소개글) + 예상 소요시간
4. 하단에 "이 마음이라면, 이 코스도" 관련 감정 코스 추천

## 7. 심사기준 대응 전략

| 심사항목(배점)         | 대응 전략                                                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 서비스 구현성(30)      | P0 기능(코스 피드+상세페이지+짝매칭)을 실제 작동하는 웹앱으로 완성                                                              |
| 서비스 기획력(30)      | 주최기관 앱의 "여행코스" 문법을 계승하면서 "오버투어리즘 분산 코스"라는 새 카테고리로 독창성 확보                               |
| 데이터 활용 적절성(20) | TourAPI(인기 관광지 데이터로 코스 스탑1 선정) + 자체 DB(성지 콘텐츠, 코스 스탑2) 결합을 코스 단위로 명확히 증빙                 |
| 서비스 발전성(20)      | 코스 시리즈 확장(지역별/계절별), 저널리즘 경력 활용한 콘텐츠 지속 생산, 대한민국구석구석 여행코스 카테고리 입점 가능성까지 시사 |
