## 3. 미확인 사항과 운영자 확인 항목

1. **Vercel 환경 변수** — `TOUR_API_SERVICE_KEY` 추가(서버용). `VITE_TOUR_API_SERVICE_KEY` 는 **삭제**하고, 번들에 노출됐던 키는 공공데이터포털에서 **재발급** 권장. `VITE_SUBMISSION_MODE` 여부 결정.
2. **운영 DB** — 9/5 이후 마이그레이션 적용 여부(`npm run db:status`), `20260914130000` 적용 승인. 적용 전에도 앱은 정상(hidden·photo_featured 를 보내지 않음).
3. **Supabase Auth** — 이메일 확인 켜짐 여부·Site URL·Redirect URL 운영값. 가입 흐름 실제 테스트 계정.
4. **개인정보 안내** — 보유기간·삭제 방법(계정 삭제)·담당자 연락처 확정(`PrivacyPage.tsx` 의 `needsOperator` 항목).
5. **WYD 2027·DID 공식 링크** — `src/shared/config/official-links.ts` 의 `url: null` 채우기. 추측 URL 은 넣지 않았다.
6. **TourAPI** — 키 등급(개발/운영)·`EngService2` 활용신청 여부.
7. **문의 연락처** — 홈 7번 절·FAQ 에 넣을 실제 연락 방법.
8. **공고문·OT·OpenAPI 설명회 원문** — 저장소에 없음. 원문을 받으면 요건을 대조한다.
9. 실기기(삼성인터넷·사파리) 확인 — 하단 탭·큰 글자·현재 위치.

## 4. 공모전 제출용 기능 설명 (초안)

**서비스 한 줄** — 붐비는 유명 관광지 대신 조용히 머물 수 있는 한국 가톨릭 성지와 주변 지역을 발견하고 실제 방문을 준비하도록 돕는 전국 성지순례 안내 서비스.

**지정과제(관광객 쏠림·오버투어리즘 완화)에 답하는 기능 — 고요 속으로**
- 입력: 방문 예정 관광지·지역 이름 → 한국관광공사 TourAPI `searchKeyword2`(실시간 호출)로 후보 검색.
- 예상 붐빔 정도: `searchFestival2`(오늘 열리는 축제·행사, 15km) + `locationBasedList2`(주변 관광시설 3km) + 있으면 `TatsCnctrRateService`(관광지 집중률, 최신일·5km). 현장 인원·대기 시간 측정값이 아님을 화면에 명시. 저장하지 않음.
- 대안: 직선 20km 안 성지 중 등급이 실제로 내려가는 곳, 가까운 순 3곳. 근거(등급 비교·직선거리 참고값)와 한계(예상값·확인 부족)를 카드 안에 표시.
- 정직한 분기: 원래 장소가 이미 「조용」 이하면 이동을 권하지 않음 / 출발지 정보 부족·대안 없음이면 추천하지 않음 / 조회 실패 후보는 「확인 부족」으로 분리.
- 이어지는 행동: 성지 상세 → 방문 정보·연락처·주소 → 외부 지도(Google·Apple·카카오·T맵·네이버).

**OpenAPI 활용 재현 방법** — 브라우저 개발자 도구 Network 탭에서 `/api/tour?service=KorService2&op=searchKeyword2…`, `op=searchFestival2`, `op=locationBasedList2`, `service=TatsCnctrRateService` 요청을 확인. 서버(`api/tour.ts`)가 서비스키를 붙여 `apis.data.go.kr` 로 전달하며 `Cache-Control: no-store`.

**자체 데이터** — 성지 208곳(이름·교구·주소·좌표·역사·연락처·사진 출처·번역), 본당·공소 주소록(공개 뷰), 출처 표.
