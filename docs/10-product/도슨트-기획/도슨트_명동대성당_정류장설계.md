## 조사로 확정된 사실

출처: [한국민족문화대백과사전 「서울 명동성당」](https://encykorea.aks.ac.kr/Article/E0018240) (공공누리, 최종수정 2026-07-02)

| 항목 | 값 |
|---|---|
| 지정 | **사적** (1977. 11. 22.) |
| 착공 | 1892. 5. 8. 정초식 |
| 축성 | **1898. 5. 29.** |
| 설계·감독 | **코스트** 신부(E. J. G. Coste, 한국명 고의선) → 1896년 선종 → **프와넬** 신부(V. L. Poisnel)가 내부공사 완성 |
| 부지 매수 | **블랑** 주교(M. J. G. Blanc), 1882년 한미수호조약 이후 |
| 규모 | 길이 68m · 너비 29m · 높이 23m · **종탑 47m** · 1,668㎡(427평) |
| 평면 | **라틴 십자형 삼랑식(三廊式)** |
| 구조 | **우리나라 유일의 순수 고딕 양식 연와조(벽돌)** |
| 벽돌 | 적색·회색 **20여 종의 이형(異形) 벽돌** |
| 복원 | 1981~1984 (스테인드글라스·지붕 동판) / 2002~2009 (종탑·외벽·스테인드글라스) |

**이야깃거리로 쓸 만한 것**
- 부지가 조선 역대 왕의 어진을 모신 **영희전(永禧殿)과 가까워, 풍수를 해친다는 이유로 조정이 소유권을 억류**해 착공이 지연됐다
- 당시 조선에 양옥 기술자가 없어 **벽돌공·미장이·목수를 중국에서 데려왔다**
- 완공 후 **'뾰죽집'** 이라 불리며 구경꾼이 몰렸다
- 고딕의 정수는 석조인데 이 성당은 벽돌이다. **"돌로 못 한 고딕을 벽돌로 해낸 건물"**

**⚠️ 출처가 엇갈리는 것 — 반드시 성당 자료로 확인**
- 스테인드글라스 제작처: 백과사전은 *"프랑스에 있는 한 수도원"*, 가톨릭 언론은 *"프랑스 툴루즈 제스타 공방"* 으로 적는다. **둘 중 하나로 확정해야 한다.**
- 1981년 보수 주체를 백과사전은 *"우리나라 사람"* 으로만 적는다. 이름 확인 필요.

## 정류장 8곳 (안)

### ① 언덕 아래 — 왜 하필 이 자리인가
```
위치      명동길 정문 아래, 성당을 올려다보는 지점        실외
소요      3분
```
**볼 것** 언덕 위로 솟은 성당 전체. 명동 한복판의 상업지구와의 대비.

**다룰 내용**
- 이곳의 옛 이름 **종현(鐘峴)**
- 1882년 한미수호조약으로 신앙의 자유가 열리자 블랑 주교가 이 땅을 샀다
- 그런데 **영희전 풍수 문제로 조정이 소유권을 묶어 착공이 지연**됐다
- 성당 하나 세우는 데 왕조와 협상이 필요했던 시대

`현장 확인` 정문 앞에 사람이 서 있을 만한 안전한 지점이 있는가. 계단 위치.
`확인 필요` 이 터가 **김범우의 집터(명례방 공동체)** 와 어떤 관계인지 — 성당 공식 자료로 확인할 것. 흔히 언급되나 정확한 서술이 필요하다.

### ② 정면 파사드 — 47m와 세 개의 탑
```
위치      정문 정면, 성당을 올려다보는 자리              실외
소요      3분
```
**볼 것** 중앙 종탑과 좌우 팔각 소탑, 세 개의 정문, 중앙 정문 위 장미창.

**다룰 내용**
- 종탑 **47m**. 1898년 서울에서 이보다 높은 건물은 없었다
- 종탑 좌우 팔각 소탑은 장식이 아니라 **2층 회랑으로 이어지는 계단실**
- 설계자 **코스트 신부**는 완공을 못 보고 1896년 선종했다. **프와넬 신부**가 이어받아 마무리했다
- 6년이 걸렸고, 재정난과 청일전쟁으로 중단되기도 했다

`현장 확인` 장미창이 밖에서 보이는가, 잘 보이는 각도는 어디인가.
`현장 확인` 정문 셋 중 평소 열리는 문은 어느 것인가.

---

### ③ 벽돌 — 돌이 아닌 고딕
```
위치      성당 측면, 부축벽이 보이는 자리                실외
소요      3분
```
**볼 것** 일정한 간격의 부축벽, 모서리 소첨탑, 벽돌의 색과 모양 차이.

**다룰 내용**
- **고딕의 정수는 석조인데 이 성당은 벽돌이다.** 조선에 석조 고딕을 지을 기술과 돈이 없었다
- 대신 **20여 종의 이형 벽돌**을 구워 부위마다 다른 모양을 만들었다. 벽돌로 조각을 한 셈이다
- 열주(줄지어 선 기둥)도 벽돌인데 석재를 깎은 것처럼 보이게 쌓았다
- **없는 조건에서 만들어낸 고딕** — 이 건물의 성격이 여기 있다

`현장 확인` **벽돌 종류 차이가 실제로 눈에 보이는 지점**을 찾아야 한다. 이 정류장의 성패가 여기 달렸다.
`현장 확인` 측면에 접근 가능한가, 통제되는 구역인가.

### ④ 안으로 — 라틴 십자와 세 개의 복도
```
위치      성당 내부 입구(나르텍스), 중앙 통로를 바라보는 자리   실내
소요      3분
```
**볼 것** 기둥 열이 만드는 가운데 통로(중랑)와 양옆 통로(측랑), 아치, 천장 높이 23m.

**다룰 내용**
- 평면이 **라틴 십자형**이다. 위에서 보면 십자가 모양
- **삼랑식** — 기둥 열이 공간을 셋으로 나눈다. 가운데가 중랑, 양옆이 측랑
- 모든 창이 아치형인 이유 — 고딕은 **위로 끌어올리는 건축**이다
- ⚠️ 여기서 **순례 에티켓**을 안내한다. 기도하는 분이 계실 수 있음, 정숙, 촬영 자제

`현장 확인` 입구에서 잠시 서 있어도 통행에 방해되지 않는 자리.
`현장 확인` 내부 촬영이 허용되는가.

---

### ⑤ 스테인드글라스 — 두 번 깨지고 두 번 되살아난 빛
```
위치      스테인드글라스가 가장 잘 보이는 자리            실내
소요      4분
```
**볼 것** 창을 통과한 빛의 색, 시간대에 따른 변화.

**다룰 내용**
- 1898년 축성 때 **프랑스에서 제작해 들여온 것**
- **6·25 전쟁으로 크게 파손**됐다
- **1981~1984년 복원.** 1984년은 교황 요한 바오로 2세가 한국에 온 해이자 한국 천주교 200주년이었다
- 2002~2009년 다시 보수했다
- **지금 보는 빛은 세 번째 빛이다**

`현장 확인` ★ **어느 창에 무엇이 그려져 있는지 반드시 현장에서 확인**한다. 도상을 틀리면 안 된다.
`확인 필요` 제작처를 성당 공식 자료로 확정 (수도원인가 툴루즈 제스타 공방인가).
`확인 필요` 창의 저작권 — 근현대 작품이면 사진 사용에 제약이 있을 수 있다.

### ⑥ 제대 앞 — 주교좌라는 자리
```
위치      제대가 보이는 신자석 앞쪽                      실내
소요      3분
```
**볼 것** 제대, 트랜셉트(십자의 가로축)가 만드는 넓어진 공간.

**다룰 내용**
- 여기는 **주교좌성당**이다. 교구장 주교의 자리(cathedra)가 있는 성당이라는 뜻
- 한국 천주교에서 이 성당이 갖는 상징적 위치
- 1898년 축성 이후 지금까지 **하루도 미사가 끊긴 적이 없다** ← ⚠️ 확인 필요

`현장 확인` 미사·성체조배 시간을 피해야 하는 정류장이다. **가능 시간대를 반드시 확인**할 것.
`현장 확인` 제대 앞까지 접근 가능한가, 어디까지 허용되는가.

---

### ⑦ 지하 묘역 — 이 성당이 서 있는 이유
```
위치      지하 성당(순교자 묘역)                        실내
소요      4분
```
**볼 것** 순교자들의 유해가 모셔진 자리.

**다룰 내용**
- **1901년**, 기해박해 순교자들의 유해가 **삼성산에서 이곳으로 옮겨졌다**
- **앵베르 주교**를 비롯한 유해가 안장돼 있다
- 병인박해 때 순교한 **푸르티에 신부**, **프티니콜라 신부**, 그리고 **이름이 남지 않은 순교자들**도 함께 계시다
- **위층의 아름다운 건물은 이분들 위에 서 있다.** 이 성당은 기념물이기 전에 무덤이다
- 이 정류장이 투어 전체의 무게중심이다

`현장 확인` ★ **누가 모셔져 있는지 현장 안내판으로 정확히 확인.** 이름과 수를 틀리면 안 된다.
`현장 확인` 지하 성당 개방 시간, 사진 촬영 가부.

---

### ⑧ 마당에서 — 1898년에서 1987년으로
```
위치      성당 마당 또는 성모동산                       실외
소요      3분
```
**볼 것** 성당 전체를 다시 한번. 그리고 명동 거리.

**다룰 내용**
- 이 성당은 **박해 시대의 끝에서 지어졌다**
- 그리고 **1987년 6월, 다시 사람들이 이곳으로 왔다.** 민주화 운동의 성지가 됐다
- 순교자를 품은 성당이 100년 뒤 다시 피난처가 된 것은 우연이 아니다
- **2018년, 이 성당을 포함한 서울 순례길이 교황청으로부터 아시아 최초 국제 공식 순례지로 승인**됐다
- 마무리: 순례 여권 스탬프 안내, 인근 성지(절두산·서소문) 안내

`현장 확인` 마무리하기 좋은 자리(앉을 곳, 성당이 잘 보이는 곳).
`확인 필요` 1987년 관련 서술은 **정치적으로 민감**할 수 있다. 사실만 담백하게, 해석은 넣지 않는다.
