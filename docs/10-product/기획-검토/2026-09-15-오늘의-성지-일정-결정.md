# 「마음 나침반」 → 「오늘의 성지 일정」 결정 사항

(개발자용 세부 지시는 `docs/70-agent-workspace/tasks/T-022-오늘의-성지-일정/지시서.md`)

---

## 한 줄 요약

질문 6개에 답하면 **성지 한 곳을 중심으로 한 하루 일정(오전 성지 → 점심 → 오후 관광지)** 을 보여 주고,
마음에 안 들면 답을 다시 하지 않고 **다른 성지로 바로 갈아탈 수 있게** 한다.

---

## 무엇이 문제였나

| 문제 | 확인한 사실 (9/15 코드 실측) |
| --- | --- |
| 「마음 나침반」이 무슨 기능인지 첫눈에 안 읽힌다 | 나침반→방향→추천 이라는 비유를 사용자가 스스로 풀어야 한다. 이용자 85%가 50대 이상, 외국어 6개 |
| 질문 8개 중 2개는 답을 받아놓고 안 쓴다 | 「혼자/함께」(참여 방식) 답은 추천 어디에도 안 쓰임. 「성별」은 성지 데이터에 성별 정보가 없어 쓸 데가 없음 |
| 시간 답이 성지 선택을 안 바꾼다 | 「반나절」이라 답해도 80km 떨어진 성지가 나올 수 있음. 답은 결과 카드 문장 한 줄에만 쓰임 |
| 결과가 「일정」이 아니라 성지 카드 한 장 | 성지 + 근처 관광지 1곳은 이미 있으나 시간 순서로 안 보임 |
| 「다시 골라볼게요」가 질문 1번으로 돌아간다 | 성지만 바꾸고 싶은 사람도 8개를 다시 답해야 함 |

## 결정 1 — 이름

| 자리 | 지금 | 바꿀 값 |
| --- | --- | --- |
| 홈 큰 카드 제목 | 마음 나침반 | **마음 상태로 고르는 오늘의 성지 일정** |
| 홈 상단 버튼 (짧게) | 마음 나침반 | **오늘의 성지 일정** |

- 첫 화면 인사말 「지금, 어떤 마음으로 여기 오셨나요? 몇 가지만 여쭤볼게요…」 는 **그대로 둔다.**
- 5개 마음 이모지(위로·새 시작·평온·어루만짐·감사)도 그대로.

---

## 결정 2 — 질문 8개 → 6개

| 순번 | 질문 | 이 답이 하는 일 |
| --- | --- | --- |
| 1 | 지금 마음에 가장 가까운 색 | **어느 성지가 나올지** 정한다 |
| 2 | 요즘 어떤 것에 마음을 많이 쓰고 계세요? | 성지는 안 바꾸고 결과 첫 문장만 바꾼다. "내 얘기를 들었구나" 느낌을 주므로 **남긴다** |
| 3 | 어디서 출발하세요? | 가까운 순 정렬, 반경의 기준점 |
| 4 | 오늘 얼마나 시간을 낼 수 있으세요? (반나절 · 하루 · 1박2일 이상) | **반경**과 일정 줄 수 (결정 3) |
| 5 | 이번 길은 몇 분이 함께하세요? | 결과 문장. 옛 「혼자/함께」의 뜻을 여기로 흡수 |
| 6 | 마음에 담아두고 싶은 말 (건너뛰기 가능) | 저장만 |

**뺀 질문**
- **성별** — 묻지 않는다. "결과에 여성 피정 같은 표시만 붙이자" 했으나, 성별 정보는 피정의집·수도회 주소록에만 있고 성지 일정에는 붙을 자리가 없다. 나중에 「근처 피정의집」 줄이 생기면 그때 표시.
- **참여 방식(혼자 조용히 / 누군가와 이야기)** — 1번과 같은 걸 두 번 묻는 셈이고, 답을 어디서도 안 썼다.

---

## 결정 3 — 시간 답을 반경으로 쓴다

| 답 | 반경 (출발지 기준) | 결과 일정 |
| --- | --- | --- |
| 반나절 | 약 30km | 오전 성지 → 오후 근처 관광지 (2줄) |
| 하루 | 약 80km | 오전 성지 → 점심 근처 식당 → 오후 근처 관광지 (3줄) |
| 1박2일 이상 | 제한 없음(전국) | 1일차 3줄 + **「2일차 일정은 준비 중이에요」** 한 줄 |

- 반경 숫자는 "이동 시간이 머무는 시간보다 길면 안 된다"는 원칙으로 잡은 **임시값**. 써 보고 조정한다.
- 반경 안에 갈 곳이 없으면 몰래 반경을 넓히지 않고 **"이 시간으로 갈 수 있는 곳이 없어요 — 시간을 늘려 보시겠어요?"** 라고 알린다.
- 2일차는 지금 만들지 않는다. 「1박2일 이상」을 실제로 몇 %가 고르는지 본 뒤에 결정한다.

---

## 결정 4 — 결과는 「성지 1곳 중심 하루 일정」

세 가지 안 중 (가) 를 골랐다.

| 안 | 내용 | |
| --- | --- | --- |
| **(가)** | **성지 1곳 중심** — 오전 성지, 점심 근처 식당, 오후 근처 관광지 | ✅ 선택 |
| (나) | 성지 2곳 순례 — 성지 A, 점심, 성지 B, 사이 관광지 | |
| (다) | 그 성지의 미사 시간을 축으로 앞뒤 배치 | |

화면 모양:

```
[오늘의 성지 일정]
  요즘 일로 마음이 많이 쓰이셨죠 …        ← 2번 답에 따른 첫 문장
  오전  ○○성지          (출발지에서 N km)
  점심  △△식당           (성지에서 도보 N분)   ← 「하루」 이상만
  오후  □□관광지         (성지에서 도보 N분)
  2일차 일정은 준비 중이에요              ← 「1박2일 이상」만

  [ 다른 성지로 추천해 주세요 ]

  앞서 본 성지
  · △△성지  · □□성당                     ← 누르면 그때 본 일정으로 돌아감
  처음부터 다시                            ← 작은 글씨
```

- 점심 식당은 한국관광공사 TourAPI 에서 그때그때 받는다 (저장하지 않는다 — 공모전 규칙).
  근처에 식당 정보가 없으면 "근처 식당 정보 없음" 으로 정직하게 비운다.

---

## 결정 5 — 「다른 성지로 추천해 주세요」 버튼

- 답은 그대로 두고 **성지만 바꾼다.** (기존 「다시 골라볼게요」는 질문 1번으로 돌아가는 버튼이라 역할이 다르다 → 「처음부터 다시」 작은 링크로 남긴다)
- 처음에 후보 성지를 넉넉히(10곳) 받아 두고, 반경 안 · 가까운 순으로 줄 세워 **누를 때마다 다음 순번**을 보인다. 무작위로 다시 뽑으면 방금 본 성지가 또 나올 수 있어서 순번 방식.
- 이미 본 성지는 다시 안 나온다.
- 후보가 바닥나면 버튼 대신 **"이 조건으로는 여기까지예요 — 시간을 늘리거나 마음을 바꿔 보시겠어요?"**
- **앞서 본 성지 목록**을 결과 아래에 쌓는다 (「이전」 버튼 대신 — 50대 이상 이용자에게 덜 헷갈림). 누르면 **그때 본 일정 그대로**(점심·관광지 포함) 돌아간다.

## 결정하지 않은 것 (열려 있음)

- 성지 저장 컬럼 중 성별·참여방식 칸을 비워 둘지 지울지 (개발자 판단)
