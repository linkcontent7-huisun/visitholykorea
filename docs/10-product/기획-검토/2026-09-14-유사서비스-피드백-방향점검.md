## 1. 피드백이 말한 것 (요약)

팀원이 국내 5 · 해외 5 · 인접 5개 서비스를 비교해 내린 결론:

- **따라 하면 안 되는 것** — 공식 순례 인증(서울순례길), 대규모 가톨릭 생활정보(굿뉴스), 장거리 순례길 운영(카미노 앱). 이미 강자가 있다.
- **차별화 조합** — 전국 통합 검색 + 감정 기반 발견 + 관광공사 관광정보 연결 + 다국어 + GPS·오프라인·기록 확장.
- **가장 직접적인 경쟁자** — 가톨릭 길동무(현재 위치·길찾기·GPS 순례 기록).
- **장기 보완 구조** — TripCatholic 의 "여행 전 계획 → 현장 방문 → 방문 후 기록" 한 흐름.

## 2. 방향 점검 — 결론: 방향은 맞다, 부족한 건 "깊이"와 "돈이 도는 그림"

피드백의 차별화 조합 다섯 가지를 우리 앱은 이미 다 갖고 있다(9/14 기준):

| 차별화 요소    | 우리 앱 현재                                            | 비고                                   |
| -------------- | ------------------------------------------------------- | -------------------------------------- |
| 전국 통합 검색 | 성지 208곳 + 본당·공소 5,918곳 검색                     | 유일하게 성지·본당을 한 화면에서       |
| 감정 기반 발견 | 마음 나침반 → 코스                                      | 경쟁 서비스 어디에도 없음              |
| 관광정보 연결  | 붐빔 지수·축제·주변 관광(TourAPI 실시간)                | 공모전 핵심, 13개 API 연결 중(T-020)   |
| 다국어         | 6개 언어 화면 + 208곳 영어 번역 + 도슨트 13곳(한·영·스) | WYD 2027 공식 언어와 일치              |
| 기록           | 스탬프·여권·여행기(사진 여러 장, 9/14)                  | 길동무와 같은 급, GPS 자동 기록은 없음 |

그래서 **방향을 바꿀 이유는 없다.** 대신 두 가지가 비어 있다.

1. **깊이** — 기능은 다 있는데 각각이 얕다. 도슨트 13/208, 사진 53/208, 미사 시간은 서울만. 심사위원이 아무 성지나 눌렀을 때 "준비 중"이 나오면 차별화가 안 보인다.
2. **사업성** — 8/26 검토 결론대로 이 사업의 형태는 B2C 앱이 아니라 **B2B(교구·성지·지자체에 콘텐츠와 데이터를 파는 것)** 다. 공모전 심사의 "사업성" 항목도 이 그림으로 답해야 한다. 앱은 무료이고 신뢰와 유입의 문이다.
