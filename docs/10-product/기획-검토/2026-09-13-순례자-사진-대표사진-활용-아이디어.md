# 순례자 사진을 대표 사진으로 — 보상·동의 아이디어 (사장님, 2026-09-13)

**상태: 아이디어 보관. 사장님이 "다음에 다시 알려 달라"고 함. T-017 끝난 뒤 보고할 것.**

## 사장님 말

> 관리자 콘솔에서 순례자가 올린 사진을 대표 사진으로 올릴 수 있게 하고, 향후 올린 분에게
> 포인트를 지급하거나 메일로 허락을 받아 공개 대표 사진으로 쓰는 것도 생각 중.

## 지금 되는 것

- 관리자 콘솔 「사진 승인함」에서 순례자 사진을 대표 사진으로 승인 (`admin_set_photo_featured`)
- T-017 부터 스탬프당 사진 여러 장, 사진 단위로 승인

## 정리해 둔 선택지

| 방식                                                   | 장점                      | 단점                               | 필요한 것                                                                         |
| ------------------------------------------------------ | ------------------------- | ---------------------------------- | --------------------------------------------------------------------------------- |
| A. 업로드 때 동의 체크 「대표 사진으로 쓰여도 좋아요」 | 메일 왕래 없음, 즉시 사용 | 동의 안 한 사진은 못 씀            | `stamp_photos.allow_featured boolean`, 업로드 UI 체크박스, 약관 문구              |
| B. 승인 때 메일로 허락 요청                            | 정중, 관계 형성           | 회신 기다림, 메일 발송 기능 필요   | `profiles.email` 접근 RPC, 메일 발송(Resend 등), 상태 열(pending/agreed/declined) |
| C. 포인트 지급                                         | 참여 유도                 | 포인트 표·화면·정산 규칙 전부 새로 | `point_ledger` 표, 적립 규칙, 기록 탭 표시                                        |

**권장 순서** — A 를 먼저(작고 법적으로 깔끔), 사진이 쌓이면 C(포인트)를 스탬프 넛지와 묶어 설계.
B 는 A 로 동의를 못 받은 특별히 좋은 사진에만.

## 같이 생각할 것

- 사진 저작권은 올린 사람에게 있음 — 동의 없이 대표 사진으로 쓰면 안 됨(A 또는 B 필수)
- 대표 사진으로 쓸 때 출처 표기: 「순례자 ○○○ 제공」(이름 공개 동의도 같이 받기)
- `site_sources` 에 kind `user` 로 기록하면 출처 추적이 됨
