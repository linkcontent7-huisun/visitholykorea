## 1. 문제 인식

### 1-1. 여행의 목적이 '이동'에서 '회복'으로 옮겨갔다

한국관광공사 2026 관광 트렌드는 'D.U.A.L.I.S.M.'이고, 여러 매체가 "많이 보는 여행"에서
"잘 쉬는 여행"으로의 전환을 보도한다.

한국관광공사 「추천 웰니스 관광지 이용자 만족도 조사」 — **개별 면접, 표본 2,149명**

| 지표 | 값 |
| --- | --- |
| 웰니스 시설 이용 **1인 지출** | **약 89,000원** (내국인 88,000 / 외국인 107,000) |
| **당일 체류 비율** | **73.7%** (외국인 **80.2%**) |
| **테마별 만족도 1위** | **「자연/숲 치유」** — 만족 4.4 · 재방문 4.5 · 추천 4.5 |
| 동반자 있음 | 95.5% (친구·동료 44.9 / 배우자 27.1 / 자녀 18.3) |

> **문제** — 만족도 1위가 "자연 속 치유"인데 **73.7%가 당일에 돌아간다.**
> 지역에 남는 소비가 얇다.

### 1-2. 2026 관광 트렌드 「D.U.A.L.I.S.M.」과 정면으로 맞는다

한국관광공사가 2025년 12월 발표한 2026년 관광 키워드는 **「D.U.A.L.I.S.M.」**
— 기술과 감성, 위기와 적응, 럭셔리와 실속처럼 **상반된 가치가 공존하는 이원적 관광**이다.
일곱 개 키워드에 이 서비스를 하나씩 대보면 이렇다.

| 키워드 | 대응 (✅ 구현·검증 / ○ 설계) |
| --- | --- |
| **D**igital Humanity<br>디지털 휴머니티 | ✅ AI 가이드 「미카엘」이 **성지 DB 밖은 "모른다"고 답하도록 제한**돼 있다. ○ 프로그램의 중심은 사람과의 **차담** |
| **U**nity of Culture<br>문화의 일치 | ✅ 순교사에 지역 생활문화를 함께 담았다 — 강경은 **금강 포구**, 공세리는 **세곡 창고(貢稅倉)**, 해미는 **읍성**이었다 |
| **A**daptive Resilience<br>적응형 회복탄력성 | ✅ **붐빔 지수**로 오늘 붐비는 곳을 피한다. ○ 평일 분산은 프로그램 설계 단계 |
| **L**ocal Re-creation<br>**로컬의 재창조** | ○ 대전 도심의 평범한 성당·문화회관·공방을 관광 자원으로 다시 읽는다. 트렌드 정의가 "지역의 평범한 일상 요소가 독창적 관광 자원으로 재해석되는 것"이라 **이 사업의 성격 자체가 여기 해당한다** |
| **I**ndividual Value Spectrum<br>개인 가치 스펙트럼 | ○ **혼자도 여럿이도**, 신자도 비신자도. 미사·기도는 "원하는 분만" — **모드를 강요하지 않는 병행 옵션** |
| **S**patial Experience<br>공간적 경험 | 근대 성당 건축 · 스테인드글라스 (○ **「밤의 대흥동」 야간 코스는 설계안이며 아직 운영 전**) |
| **M**ulti-Generation Flow<br>세대 간 흐름 | ○ 실측 동반자 구성이 이미 섞여 있다 — 친구·동료 44.9%, **배우자 27.1%, 자녀 18.3%**. 프로그램을 세대로 나누지 않는 근거 |

> **트렌드 보고서가 짚은 세대 차이도 그대로 쓸 수 있다** — 웰니스가
> **MZ세대에게는 "감정 회복과 자기 위로"**, **40대 이상에게는 "일상의 리듬을 다잡는 자기 관리"**로
> 다르게 읽힌다. 같은 코스를 **채널별로 다르게 소개**하면 되는 일이지,
> 프로그램을 나눌 필요는 없다.

### 1-3. 불교는 이 수요를 받고 있는데, 가톨릭에는 창구가 없다

42%→67.2%로 늘었다. 2004년 한국불교문화사업단이 생기며 표준화된 결과다.

**가톨릭 성지 208곳에는 그런 전국 창구가 없다.** 교구별로는 이미 한다 —
서울 순례길 3코스(2018년 **교황청 승인, 아시아 최초 국제 순례지**), 제주 6코스,
한티가는길 45.6km. 그러나 **교구를 가로질러 한 곳에서 보는 층이 없다.**

### 2-3. 한국관광공사 데이터를 어떻게 쓰는가

**실시간 호출만 하고 저장하지 않는다.** TourAPI 응답(주변 명소·축제)은 매 요청마다
실제 호출하며 DB·캐시에 넣지 않는다. 반면 `holy_sites` 208곳은 **직접 수집·큐레이션한
자체 자산**이라 저장·가공한다. 이 구분을 아키텍처 문서(ADR 0002)에 명문화해 두었다.

### 2-4. 데이터 품질을 관리하는 체계가 있다

콘텐츠가 많아지면 **원문과 번역이 어긋난다.** 실제로 그랬고, 우리는 그것을 찾아냈다.

- 2026-08-18 한국어 소개글을 재작성했는데, 영어는 그 이전(8/11)에 옮긴 것이었다
- **재작성 직전 백업 3개를 현재 DB와 대조**해 어긋난 곳 **25곳을 정확히 특정**
- 그중 **9곳 재번역·감수 완료**(솔뫼·진산·강경·공세리·여사울·합덕·갈매못·수리치골·신리)
- 나아가 **208곳 전수 검사**로 소개글↔역사의 숫자 모순 **2건**을 발견 →
  추측으로 고르지 않고 **교구 자문단 확인 항목**으로 남김

> 종교·순교 기록은 틀리면 신뢰가 즉시 무너진다. **틀릴 수 있다는 전제로 만든 절차가 있다.**

### 3-2. 왜 「초」인가 — 검증된 소재이고, 여기에만 있다

성당 체험의 킬러 소재는 이미 검증돼 있다.

| | 프로그램 | 손작업 |
| --- | --- | --- |
| 왜관 (칠곡군 + 베네딕도회) | 칠곡 홀리데이 · 홀리페스티벌 **3일 1만 2천 명** | 색유리화 |
| 공세리 (민간 + 대전교구 성당) | 둘러보공 놀아보세 · **문화재청 2022 우수상** | 색유리공방 |
| **대전 도심** | **우리가 만들 자리** | **초 만들기** |

**초가 색유리보다 나은 점** — 반나절에 끝나고, 가져가고, **집에서 다시 켠다.**
그리고 **이중 진입점**이다: 신자에게는 전례의 상징(빛), 비신자에게는 예쁜 공예.
"참여의 조건을 신앙 고백이 아니라 활동으로 재정의한다"가 **재료 자체에 들어 있다.**

베타니아의 대표 작품이 **「김대건 안드레아 신부님 생애」 조각초**다.
우리 앱에는 **김대건길** 코스가 있고, 탄생지 **솔뫼성지는 WYD 2027 공식 일정지**다.
지어낸 연결이 아니라 이미 있는 것들이 겹친다.

### 3-3. 시한이 확정된 기회 — WYD 2027

| 항목 | 확정 사실 |
| --- | --- |
| 교구대회 | **2027.7.29~8.2** — 서울 제외 **15개 교구**(대전교구 포함) |
| 본대회 | 2027.8.3~8.8, 서울 |
| 규모 | 최대 80만 명, **해외 청년 20~30만 명** |
| 수호성인 | 성 김대건 안드레아와 동료 순교자 |
| **공식 일정지** | **솔뫼성지 · 해미읍성 — 둘 다 대전교구** |

수요는 이미 오고 있다 — 서울대교구 외국인 순례자는 2024.10~2025.9 기준 **약 3만 5,200명**,
사전접수는 5,156명으로 전년 대비 **+36%**. (가톨릭신문 2026-01-05)


가격 근거 — 웰니스 시설 1인 지출 실측 **89,000원**, 국내 당일 순례 상품 6.5만~9.8만 원,
템플스테이 1박2일 3만~7만 원, 서울대교구 도보순례 7,000원(사목 가격).

**가격 구간이 위아래로 막혀 있다.**

```
 7,000원 ── 서울대교구 도보순례 (사목 가격, 상업적으로 맞출 수 없음)
    ↓
 [우리 구간]
    ↑
89,000원 ── 웰니스 시설 1인 지출 실측
65,000~98,000원 ── 여행사 국내 당일 순례 상품
```

## 4. 파트너십 후보 — 한 수도회, 세 거점

> ⚠️ **먼저 밝힙니다 — 아직 협의 전입니다.**

> **"협력 중"이 아니라 "협력을 청하려는 곳"으로 읽어 주십시오.**

> "가톨릭 신자 뿐만 아니라 **개신교인, 일반인들도 함께 참여**할 수 있는 풍성한 주제로"

**민간이 국가유산청 트랙을 통과한 선례도 있다.** ㈜문화상상연구소가 **공세리성당(대전교구)**에서

지자체가 아닌 **민간 기업**이 해낸 일이라 1인 창업자인 우리에게 그대로 적용된다.
