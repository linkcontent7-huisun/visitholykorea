## 3. 다음 착수 작업 (우선순위순)

### 1순위 — 성지 콘텐츠 확충 (완료, 2026-07-27)

- 전국 10개 지역 66곳 확보, 감정 태그(위로/새출발/평온/치유/감사) 전 항목 반영 완료
- 남은 소소한 정리: 대전목동성당 미조사 1건, 수원 화성 순교성지 조사중 → 조사완료 전환, 일부 지명 재확인

### 2순위 — 감정 태그 체계 DB 반영

- Notion DB에 `감정 태그` Multi-select 속성 추가
- 기존 1건(수원 화성 순교성지) 및 신규 입력 성지에 태그 부여

### 3순위 — TourAPI 실동작 검증

- `areaBasedList`, `locationBasedList` 등 실제 호출 테스트
- 응답 데이터 구조 확인 후 웹앱에서 활용할 필드 확정

### 4순위 — Supabase 마이그레이션

- 기술아키텍처 문서의 스키마로 테이블 생성
- Notion → Supabase 데이터 이관 (Make 자동화 또는 1회성 스크립트)

### 5순위 — 프론트엔드 MVP

- 화면 4개(감정선택/지역입력/추천결과/상세) 우선 구현
- AI 웹앱 빌더 활용해 개발 속도 확보
