### Phase 1: 공모전 출품 (2026-08-10 ~ 2026-09-30)
**목표**: "오늘의 쉼표" 완성 후 심사 제출

**주요 작업**:
- [x] 붐빔 지수 계산 로직 완성 (1차 실측 완료)
- [x] 성지 18곳 테스트 완료
- [ ] 남은 성지 190곳 실측 검증 (대전 27곳 우선)
- [ ] 홈 화면 UI 재구성
- [ ] 데모 영상 + 발표자료
- [ ] 버그 수정

**공모전 심사 배점**:
- 구현성 30% ← 새 기능 최소, 기존 재활용
- 기획력 30% ← "역발상": 데이터로 분산
- 데이터 활용 20% ← TourAPI 필수 (끄면 화면이 빔)
- 발전성 20% ← 208→5,918으로 확장 가능

### Phase 2: 홍보 콘텐츠 자동화 — ⛔ 보류 (2026-10-01 이후)
**목표**: Claude API로 성지별 홍보 콘텐츠 자동 생성

> 문서 첫머리의 결정에 따라 **공모전 제출 전에는 착수하지 않는다.**
> 아래 내용은 10월에 다시 꺼내 쓰기 위한 설계 기록으로만 남긴다.

**콘텐츠 전략**: "비신자 + 신자" 이중 타겟

| 타겟 | 포지셔닝 | 콘텐츠 |
|------|---------|--------|
| **비신자/관광객** | "건축미, 역사, 휴식" | 블로그: 아름다움 강조 |
| **신자/순례자** | "영적 여정, 순교정신" | 블로그: 신앙 의미 강조 |
| **공통** | SNS 감성 | 해시태그 + 감성 카피 |

**구성**:
1. 블로그 콘텐츠 (250-300자) 자동 생성
2. 인스타 캡션 A (비신자용) 자동 생성
3. 인스타 캡션 B (신자용) 자동 생성
4. 해시태그 (10개) 자동 생성

**기술 스택**:
- Claude API (Anthropic)
- Python 스크립트 (anthropic 라이브러리)
- Supabase 저장 (holy_sites.marketing_content)

## 홍보 콘텐츠 자동화 상세 전략

### 사례 선정 기준
- **다양성**: 지역별(서울, 아산, 안성, 대전 등)
- **대표성**: 성지 + 본당 + 순교지 + 특별 장소
- **검증 가능성**: 기존 로드맵의 1차 실측 완료 18곳 + 새로운 사례

### 선정된 12개 사례

#### 대전 (최우선, 27곳 중 선정)
1. 계산동 대전대교구 성당 (대도시 본당)
2. 청주시 상당산 성지 (자연 + 영적)

#### 서울 (신분당선 지역)
3. 명동성당 (한국 최초 고딕)
4. 약현성당 (역사 + 건축미)

#### 아산 (공모전 주력)
5. 공세리 성당 (순교 성지)

#### 안성 (확장 예시)
6. 미리내 성지 (대순교지)

#### 강원도 (고령 접근성 고려)
7. 인제 소양로 성당 (조용함 극단)

#### 경주 (관광지 대안)
8. 불국사 인근 가톨릭 성지

#### 기타
9-12. (추가 선정)

### 콘텐츠 생성 프롬프트 (Claude API)

```python
def generate_holiness_content(site_name, location, history, category):
    """
    site_name: 성지/성당 이름
    location: 위치
    history: 역사/배경
    category: 대도시본당/성지/순교지/자연성지
    """
    prompt = f"""
너는 가톨릭 성지 홍보 전문가야. 비신자와 신자 모두를 사로잡아야 해.

[성지 정보]
이름: {site_name}
위치: {location}
종류: {category}
역사: {history}

[요구사항]
1. 대상: 비신자(관광객) + 신자(순례자)
2. 톤: 따뜻하고 평화로운 느낌
3. 비신자에게는 "건축미, 휴식, 역사"를 강조
4. 신자에게는 "영적 의미, 순교정신, 기도의 자리"를 강조

[형식]

## 블로그 (250-300자)
(역사, 건축미, 영적 의미를 모두 포함)

## 인스타그램 캡션 A (비신자용, 50자 이내)
(감성적, "지친 일상에서의 위로" 테마)

## 인스타그램 캡션 B (신자용, 50자 이내)
(영적, "기도의 의미" 테마)

## 해시태그
(15개, 성지 + 여행 + 가톨릭 혼합)
"""
```
