## 1단계 — 데이터 채우기 (최우선)

기능보다 데이터가 먼저다. 좌표가 없으면 코스 추천이 동작하지 않고, 사진이 없으면 화면이 비어 보인다.

- [ ] 성지 좌표 확보 — 미확보 다수 (`data/research/location_retry_summary.md`)
- [ ] 대표 사진 확보 — 직접 촬영 우선 (`docs/30-content-ops/` 매뉴얼대로)
- [ ] TourAPI 유래 이미지 정리 — ADR 0002 의 미해결 항목
- [ ] 감정 태그 미부여 성지 채우기 — 태그가 없으면 "쉼표 순례길" 후보에 안 들어간다

## 2단계 — 완결성 (심사 배제 위험 제거)

- [ ] AI 가이드 Edge Function 실배포 + 응답 품질 확인 (코드는 있으나 아직 배포 전)
- [ ] 여행기 작성 화면 구현 (지금은 읽기만 가능)
- [ ] 지도 실연동 (ADR 0003, 좌표 확보 이후)
- [ ] 전례력 시기 판정 검토 — 대림 시작일 등을 근사치로 계산하고 있어,
      스탬프 연출용으로는 충분하지만 전례 안내로 쓰기 전에 사목자 확인이 필요하다

## 3단계 — 차별화

- [ ] AI 하루 코스 자동 생성 (성지 + TourAPI 관광지·맛집·숙박 조합)
- [ ] 마음 나침반 응답을 저장해 추천 개인화에 활용 (지금은 화면 안에서만 쓰이고 사라진다)
- [ ] `catholic_directory` 활용 — 성지 주변 피정의집·본당 미사시간 안내
- [ ] 즐겨찾기(찜하기) 구현 — UI 버튼만 있고 동작하지 않는다

## 4단계 — 이후
