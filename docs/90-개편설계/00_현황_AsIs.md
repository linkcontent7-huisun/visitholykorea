## 1. 검색엔진·AI·인스타가 지금 보는 모습 — 가장 큰 문제

| 항목 | 상태 | 근거 1 | 근거 2 |
|---|---|---|---|
| 모든 주소의 제목이 똑같다 | ✅ | 운영 서버 `/routes`, `/sites/…` 를 받아 보니 `<title>` 이 둘 다 「Visit Holy Korea - 길 위에서 나를 만나는 성지순례」 | 앱이 `index.html` 한 장을 모든 주소에 돌려준다(`vercel.json` rewrites) |
| 성지별 검색용 제목·설명이 **써 있는데 안 쓰인다** | ✅ | DB `holy_sites` 213곳 모두 `seo_title`·`seo_description` 이 비어 있지 않음(10/31 실측) | 코드에서 이 칸을 읽는 곳은 관리자 화면(`admin.repository.ts`)뿐 |
| `robots.txt`·`sitemap.xml` 없음 | ✅ | `public/` 폴더에 파일 없음 | 운영 서버에 요청하면 둘 다 앱 화면 HTML 이 나옴 |
| 구조화 데이터(schema.org) 없음 | ✅ | `index.html`·`src` 에 `ld+json` 없음(검색) | — 근거 1개뿐 |
| 인스타·카톡 링크 미리보기가 성지마다 같다 | ❓ 추측 | `og:title` 이 `index.html` 에 고정 | 확정하려면: 카톡에 성지 링크 하나 붙여 미리보기 확인 |

**뜻:** 구글·AI 검색기는 대부분 첫 HTML 만 읽는다. 지금은 213곳 어느 주소로 와도 "앱 소개 한 장"만 보인다.
이미 써 둔 213곳의 제목·설명을 **첫 HTML 에 실어 보내는 것**이 개편의 1순위다.

## 2. 화면(주소) 목록 — 사장님이 「뺄 것」 표시할 칸

`src/app/routes/router.tsx` 기준. "제 의견"은 인스타 신규 방문자 기준 ❓추측이다.

| 주소 | 화면 | 하는 일 | 제 의견 | 사장님 표시 |

| `/sites/:id` | 성지 상세 (1102줄, 가장 큼) | 소개·역사·오디오 가이드·길찾기 | **핵심. 인스타 링크가 닿는 곳** | |
| `/search` | 성지 찾기 | 검색·목록 | 남김 | |
| `/map` | 지도 | 제출판 모드에서 다른 화면으로 분기 | 확인 필요 | |
| `/records` | 기록(스탬프) | 로그인 사용자 순례 기록 | 신규에겐 뒤로 | |
| `/compass` | 오늘의 일정(마음 나침반) | 질문 → 성지 추천, 붐빔 비교 | 남김 | |
| `/routes`, `/routes/:slug` | 순례 코스 | 사건·인물로 잇는 길 | 인스타 소재로 좋음 | |

| `/menu`, `/account` | 더보기·계정 | 설정·언어·글자 크기 | 남김 | |

**아래 탭(5개):** 홈 · 성지 찾기 · 기록 · 오늘 일정 · 더보기 (`nav-items.ts`).
