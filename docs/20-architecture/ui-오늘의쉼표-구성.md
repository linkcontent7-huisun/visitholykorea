```

│  ├─ 로고: "VISIT HOLY"
```

## 🎯 "오늘의 쉼표" 섹션 상세 구성

### 1️⃣ **헤더 영역** (TodayQuietSection 최상단)

```
오늘 | 8월 5일 화요일  (소문자, 바이올렛색, 자간 넓게)
          ↓
     오늘, 조용한 자리  (극굵음, 2rem)
          ↓
한국관광공사 실시간 축제·관광 정보로 오늘의 붐빔을 계산했어요
                      (회색, 13px, 설명)
```

**디자인 의도:**
- 날짜 표시로 "매일 새로 계산된다"는 점을 강조
- 제목이 명확해서 사용자가 "이것이 무엇인지" 한눈에 파악
- 설명에서 **TourAPI를 사용한다는 사실**을 명시 (심사위원 대상)

---

### 2️⃣ **로딩 상태** (첫 진입 시, ~1-3초)

```
오늘 열리는 행사를 확인하는 중…

┌──────────────────────────────┐
│  [로딩 스켈레톤]  높이 112px   │ ← 3개 줄
├──────────────────────────────┤
│  [로딩 스켈레톤]               │
├──────────────────────────────┤
│  [로딩 스켈레톤]               │
└──────────────────────────────┘
```

**기술 세부:**
- `role="status"` + `aria-live="polite"` (접근성)
- 회색 배경, 둥근 모서리 (20px 라디우스)
- 3개 카드를 미리 그려서 깜빡임 방지
- 로딩 텍스트로 사용자를 안심시킴

---

### 3️⃣ **에러 상태** (API 호출 실패)

```
┌──────────────────────────────┐
│                              │
│   오늘의 붐빔을 계산하지      │
│          못했어요             │
│                              │
│  관광 정보를 불러오는 중     │
│  문제가 생겼습니다.          │
│  잠시 후 다시 열어주세요.    │
│                              │
│  [에러 메시지 - 선택사항]    │
│                              │
└──────────────────────────────┘
```

**특징:**
- 흰색 배경, 테두리 있음
- 센터 정렬 (불행하지만 안정적인 느낌)
- 에러 메시지는 개발자용 (회색, 투명도 60%)
- 사용자가 재시도할 방법을 명확히 함

---

### 4️⃣ **빈 상태** (좌표 데이터 부족)

```
┌──────────────────────────────┐
│                              │
│          〰️  (바람 아이콘)   │
│                              │
│   아직 계산할 성지가 없어요   │
│                              │
│  붐빔을 재려면 성지 좌표가   │
│        필요합니다.           │
│                              │
│   현재 좌표가 확인된 곳은    │
│           42곳입니다.        │
│                              │
└──────────────────────────────┘
```

**설계 의도:**
- 대시드 테두리 (점선) = "아직 준비 중" 느낌
- 바람 아이콘 (Wind) = "조용함"의 메타포
- **숫자를 표시** (42곳) = 진행 상황을 투명하게
- 이 화면이 떴다는 것은 **데이터 채우기 완료가 우선**이라는 신호

---

### 5️⃣ **성지 카드 리스트** (메인 콘텐츠)

#### 개별 카드 구조 (QuietSiteCard)

```
┌─────────────────────────────────────┐
│ 공세리 성지              │ 조용 | 15 │
│ 📍 충청남도 아산시       │             │
│                                     │
│ · 반경 3km에 오늘 열리는 행사 없음  │
│ · 가장 가까운 인파는 12km 밖        │
│ · 주차 가능, 화장실 1개            │
│                                     │
└─────────────────────────────────────┘
```

**구성 요소:**

| 요소 | 역할 | 기술 사항 |
|------|------|---------|
| **성지 이름** | 주제 | `font-bold`, `text-lg`, 한 줄(너무 기면 자르기) |
| **주소** | 위치 정보 | 12px, 회색, MapPin 아이콘 |
| **붐빔 배지** | 지수 표시 | 등급명 + 숫자 (예: "조용 15") |
| **사유 리스트** | 신뢰 근거 | 3-4줄, 불릿 포인트 (·) |

**사진이 없는 이유:**
1. **성지 사진이 아직 없음** (프로젝트 진행 중)
2. **더 중요한 이유**: 이 카드가 파는 것은 **풍경이 아니라 "오늘의 상태"**
   - "조용하다" ← 숫자와 근거가 전부
   - 풍경은 상세 페이지에서 볼 수 있음

**상호작용:**
- 클릭하면 성지 상세 페이지로 이동
- 호버 시 테두리 색 변경 (brand-blue/30)
- 터치 기기: 클릭 피드백만 있음 (호버 없음)

---

### 6️⃣ **붐빔 배지** (CrowdingBadge)

신호등 색상 규칙을 따름:

```
┌──────────────────────────────────┐
│ 등급            | 색상  | 숫자범위 │
├──────────────────────────────────┤
│ 🟢 아주 조용    | 초록  │  0~20  │
│ 🔵 조용        | 청록  │ 20~40  │
│ 🟡 보통        | 주황  │ 40~60  │
│ 🟠 붐빔        | 주황  │ 60~80  │
│ 🔴 매우 붐빔    | 빨강  │ 80~100 │
└──────────────────────────────────┘
```

**설계 선택:**
- **신호등 색**: 나이 많은 사용자를 배려 (새로운 색 체계 학습 불필요)
- **채도 낮춤**: `bg-emerald-50` (진한 초록 ❌ → 밝은 초록 ✅)
  성지의 분위기를 해치지 않으면서도 정보 전달
- **등급명 필수**: 색만으로는 색각 이상 사용자가 이해 불가
  → 텍스트 + 색 함께 사용
- **숫자 표시**: "조용 15" 형태로 지수값도 함께 표시

**추가 속성:**
- `isPartial = true`: "· 일부" 표시
  - 주변 시설 정보가 충분하지 않은 경우
  - 축제 압력만으로 낸 값임을 사용자에게 알림

---

### 7️⃣ **면책 문구** (카드 아래)

```
공사 데이터에는 실시간 혼잡도가 없어, 오늘 열리는 행사와 
주변 관광 시설 밀도로 추정한 값입니다. 실제와 다를 수 있어요.

[12px, 회색, 투명도 70%]
```

**왜 이것이 중요한가:**
- **신뢰 유지**: "정확하다"고 거짓말하지 않음
- **공모전 심사에서 플러스**: 데이터의 한계를 투명하게 인정
  → "우리가 충분히 생각했다"는 인상
- **향후 업데이트**: 사용자 리뷰로 추정값을 보정할 수 있음을 암시

## 🔄 데이터 흐름

```
사용자가 홈 화면 진입
         ↓
TodayQuietSection 마운트
         ↓
useQuietSites() 훅 실행
         ↓
성지 300곳 중 좌표 있는 곳 필터링
         ↓
TourAPI 호출:
  1️⃣ searchFestival2: 오늘 전국 축제 조회 (2회)
  2️⃣ locationBasedList2 × 최대 12회: 후보 성지별 주변 인프라 조회
         ↓
붐빔 지수 계산 (festivalscore × 0.5 + amenityDensity × 0.3 + ...)
         ↓
상위 3곳 선별 (지수 낮은 순)
         ↓
화면 렌더링: QuietSiteCard × 3개
```

**호출량:**
- 홈 1회 진입 시 총 **14회 TourAPI 호출**
- 캐싱 불가 (실시간성 요건 때문에 매일 새로 계산)

| 항목 | 구현 방식 |
|------|---------|

## 핵심 설계 원칙
