# UI 레퍼런스 — 사진 중심 순례 앱을 만들기 위해 본 것들

조사일: 2026-08-08 · 브라우저에서 직접 계측

사진이 많고 소개글이 재미난 순례 앱을 만들기로 했다. 감으로 정하지 않으려고
이미 그 일을 하고 있는 곳들을 열어 봤다.

> **베끼지 않는다.** 레이아웃·색·컴포넌트를 그대로 옮기면 심사에서 문제가 된다.
> 여기 적은 건 "왜 그렇게 했는가"이지 가져다 쓸 소스가 아니다.

| 무엇 | 왜 봤나 |
| --- | --- |
| [Visit Seoul](https://korean.visitseoul.net/) | 사진 중심 관광 콘텐츠의 표준 |
| [Gronze](https://www.gronze.com/) | 산티아고 순례길의 사실상 표준 가이드 |
| Google Maps (저장한 장소) | 지도 위에 내 발자취를 표현하는 법 |
| Buen Camino 앱 | 순례 앱이 실제로 배송하는 기능 |

## 1. Visit Seoul — 사진을 어떻게 배치하는가

### 섹션 순서와 호흡

| 순서 | 섹션 | 이미지 | 높이(PC/모바일) |
| --- | --- | --- | --- |
| 1 | 메인 비주얼 | 0 (배경 처리) | 730 / 518 |
| 2 | 이벤트 | **35** | 673 / 785 |
| 3 | 탐방하기 | 8 | 652 / 557 |
| 4 | **에디터 추천** | 5 | 706 / 480 |
| 5 | 배너 | 4 | 456 / 174 |
| 6 | 여행정보 | 0 | 427 / 315 |
| 7 | SNS | 8 | 599 / 516 |

**이미지가 없는 섹션(1·6)을 사이에 끼워 숨 쉴 곳을 만들었다.**
사진을 많이 쓰겠다고 전부 사진으로 채우면 눈이 지친다.

### 카드 — 가장 많이 쓸 조각

```html
<a href="...">                  <!-- 카드 전체가 하나의 링크 -->
  <div class="thumb-cont"><img></div>     <!-- 사진 먼저 -->
  <div class="text-cont">
    <h3>용마폭포공원</h3>                   <!-- 이름 -->
    <p>가슴속까지 시원한 동양 최대 인공폭포</p>  <!-- 한 줄 후킹 -->
  </div>
</a>
```

- 카드 어디를 눌러도 이동한다. 제목만 링크면 모바일에서 누르기 어렵다
- 사진과 글이 형제 관계다. 겹치지 않아 글자가 사진에 묻히지 않는다

**모바일 카드 폭 = 화면의 0.70** → 다음 카드가 30% 걸쳐 보인다.
화살표나 안내문 없이 "옆으로 넘길 수 있다"를 형태만으로 알린다.

원본 1140px 이미지를 280px 자리에 쓴다(고밀도 화면 대응).

### 타이포·여백

| | PC | 모바일 |
| --- | --- | --- |
| 섹션 제목 | 36px / 600 | 24px / **700** |
| 본문 | 13px | 13px |
| 섹션 여백 | 90~100px | 50~70px (0.55~0.7배) |

**모바일에서 크기는 줄이고 굵기는 올렸다.** 작아진 만큼 획을 굵게 해 존재감을 지킨다.

### 제목 짓는 두 가지 공식 ← "재미난 소개글"의 실제 사례

**① 시리즈 + 장소 + 감성** — 연재물처럼 보여 다음 편을 기다리게 한다
```
[아무도 말해주지 않은 서울]
창신동, 말랑한 동심을 따라 걷는 하루
```

**② 이름 + 한 줄 카피** — 설명이 아니라 카피다
```
용마폭포공원
가슴속까지 시원한 동양 최대 인공폭포
```

우리 성지에 옮기면:
```
[아무도 모르는 서울 성지]
명동 한복판, 골목 하나 올라가면 나오는 120년의 고요

절두산 순교성지
한강 노을이 가장 아름답게 지는 언덕
```

`SNS-레퍼런스-조사.md` 의 인스타 제목과 **같은 공식을 쓰면** 웹과 SNS가 한 목소리를 낸다.

## 2. Gronze — 정반대의 선택

같은 "여행 사이트"인데 Visit Seoul 과 정반대다.

| | Visit Seoul | Gronze |
| --- | --- | --- |
| 이미지 수 | 61장 | **11장** |
| 본문 크기 | 13px | **16px** |
| 폰트 | Noto Sans KR (웹폰트) | **Verdana** (시스템 폰트) |
| 성격 | 감성·발견 | **실용·정보 밀도** |

**Gronze 는 사진으로 유혹하지 않는다.** 순례자는 이미 갈 마음을 먹었고,
필요한 건 거리·고도·숙소·물 있는 곳이기 때문이다.

배울 점:
- **본문 16px** — 오래 읽는 정보에는 이쪽이 맞다
- 루트 목록을 한 화면에 다 펼쳐 **"세상에 이렇게 많구나"** 를 먼저 보여준다
  (스페인·포르투갈 27개, 프랑스·이탈리아 10개)
- 웹폰트를 안 써서 가볍다

## 3. Google Maps — 지도에 발자취를 그리는 법

산티아고 순례자가 구글맵에 저장한 화면을 봤다. **핵심 발견:**

> **경로선이 아니다.** 저장한 장소 핀이 촘촘히 찍혀서 **선처럼 읽히는 것**뿐이다.

폴리라인을 계산해 그리는 것보다 훨씬 간단한데 "잇고 싶다"는 느낌은 똑같이 난다.
핀 종류(하트·별·깃발)와 색으로 목록을 구분한다.

장소 상세 시트는 **경로 · 저장 · 라벨 · 공유** 네 버튼이 최상단이다.
정보보다 행동이 먼저 온다.

## 4. Buen Camino 앱 — 순례 앱이 실제로 배송하는 것

4.8★ / 리뷰 1.69만 / 50만+ 다운로드. 스토어 스크린샷에서 기능이 다 드러난다.

| 화면 | 담긴 것 |
| --- | --- |
| **구간 계획** | 출발지·도착지 선택 → 21.34km, 도보 시간, **고도 프로필**(상승 633.5m / 6.1%) |
| **지역별 탐색** | 사진 + **유튜브 영상**, 대체 경로, **미사 시간**, 숙소(평점·잔여 침대 수), Booking 예약 |
| **설정** | 언어, 다크 모드, 마일 단위, 위치 권한, 오늘 날짜 기준 가격, 알림, **자전거 모드** |
| **문의** | **가이드 저자와 직접 채팅** |
| **지도** | 위성 지도 + 경로선 + 지점 핀 |

### 배울 점 세 가지

**① 신뢰를 사람 이름으로 담보한다**

> 2004년부터 20년 넘게 제작. 순례자이자 기자인 Carlos Mencos(Aymeric Picaud 수상)가
> 직접 작성하고 **매일 업데이트**하며, 전문 팀이 함께 작업합니다.

실명·경력·수상·갱신 주기를 앱 소개 첫머리에 박아 뒀다.
`CLAUDE.md` 에도 "종교 정보는 틀리면 신뢰가 바로 무너진다"고 적혀 있다.
우리는 AI 가이드로 가되, **출처를 화면에 드러내는 방식**으로 같은 문제에 답해야 한다.

**② 미사 시간이 1급 정보다**

관광 정보가 아니라 **순례 정보**의 핵심이다. 구간 상세 안에 미사 시간이 들어 있다.
우리도 `missa.cbck.or.kr` 연동 계획이 있고, 인스타 월요일 코너도 미사 시간이다.

**③ 이동 수단에 따라 정보가 달라진다**

도보냐 자전거냐로 거리·시간·경로가 바뀐다. 우리는 **차량 순례**가 많으니
"도보 / 대중교통·차" 구분이 그 역할을 한다 (`alternatives.ts` 에 이미 있다).

## 5. 지도 넛지 설계 — "채워보고 싶은 느낌"

### 먼저 짚을 차이

**Camino 는 선형이다.** A→B→C 로 걷고, 끊긴 구간이 보이니 잇고 싶어진다.
**우리 208곳은 흩어져 있다.** 차로 다니고 순서도 없다.
Gronze 의 선을 그대로 가져오면 억지가 된다.

그래서 **두 층으로 겹친다.**

- **선형 루트는 선으로** — 서울 순례길 3코스(말씀의 길·생명의 길·일치의 길, 교황청 공인 2018), 버그내순례길
- **흩어진 208곳은 핀으로** — 구글맵 방식

### 넛지가 센 순서

**① 핀을 3단계로** (가장 먼저, 가장 효과적)

```
● 방문함       채워진 핀 + 스탬프 표시
○ 안 감        빈 윤곽선, 흐리게
◉ 지금 갈 만함  강조 — 가깝고 + 아직 안 갔고 + 지금 한적함
```

빈 핀이 채워진 핀 사이에 끼어 있으면 **그것만 눈에 띈다.**
문구 없이 형태만으로 넛지가 된다.

**② 마지막 한 곳을 집요하게**

```
대전교구  3/27   ▓░░░░░░░░░
대전교구  26/27  ▓▓▓▓▓▓▓▓▓░  ← "여사울성지 한 곳 남았습니다"
```

목표에 가까울수록 동기가 급증한다. 3/27 일 때 27곳을 들이대면 질리지만 26/27 이면 간다.

**③ 내가 그린 선** ← 우리만 할 수 있는 것

Camino 는 **정해진 길**을 걷는다. 우리는 각자 다르다.
방문한 성지를 **날짜순으로 이으면 세상에 하나뿐인 지도**가 나온다.

- 연말에 "2026년 나의 순례" 이미지로 뽑기 → 인스타 공유
- 흩어져 있다는 약점이 오히려 강점이 된다

**④ 지금 실행 가능한 넛지**

```
여기서 12km · 아직 안 가신 곳 3곳 · 지금 한적합니다
```

`haversineKm` 도 붐빔 지수도 이미 있다. 세 조건을 합치기만 하면 된다.

**⑤ WYD 2027 을 마감으로**

```
교구대회까지 D-356 · 내 교구 진행률 12%
```

외부 마감이 있으면 완성욕이 배가된다. 마침 날짜가 확정돼 있다
(`SNS-레퍼런스-조사.md` 3장).

## 6. 가져올 것 / 다르게 할 것

### 가져올 것

- 카드 = 사진 + 이름 + 한 줄 (우리 DB 의 `name` + `description` 첫 문장)
- 모바일 카드 **0.7 화면폭** — 다음 카드를 엿보이게
- 카드 전체를 링크로
- 제목 스케일 36→24, 굵기 600→700
- 이미지 없는 섹션을 사이사이에
- 핀 밀도로 선을 만들기 (폴리라인 계산 없이)
- 상세 화면 최상단에 **행동 버튼**(길찾기·저장·공유)
- 언어별 폰트 폴백

### 다르게 할 것

| 레퍼런스 | 우리 | 왜 |
| --- | --- | --- |
| Visit Seoul 본문 **13px** | **최소 16px, rem 기반** | `CLAUDE.md` 에 큰 글자 모드가 요구사항. 순례 인구는 고령층 비중이 크다. Gronze 도 16px 이다 |
| PC·모바일 **이미지 2벌** | `srcset` 으로 **한 장** | 사진이 208곳 중 14곳뿐. 두 벌 만들 인력이 없다 |
| 이벤트 섹션 이미지 **35장** | 훨씬 적게 | TourAPI 실시간 호출이 얹힌다. 첫 화면이 느려진다 |
| Buen Camino **저자 실명·매일 갱신** | AI 가이드 + **출처 표시** | 사람이 매일 갱신할 수 없다. 대신 근거를 화면에 드러낸다 |
| Buen Camino 숙소 예약 연동 | `nearbyLodging` 표시까지만 | 예약 연동은 범위 밖 |

## 8. 반드시 조심할 것

**종교 시설이다.** 게임 언어를 쓰면 순례가 점수 따기로 격하된다.

| 쓰지 말 것 | 쓸 것 |
| --- | --- |
| 정복, 클리어, 도전 | 잇다, 채우다, 함께 걷다 |
| 달성률 100% | 스물일곱 곳을 모두 다녀오셨습니다 |
| 미방문 = 실패한 느낌 | 흐리게 두되 부정적이지 않게 |
| 랭킹·경쟁 | (쓰지 않는다) |

스탬프와 배지는 **실제 순례 문화에 이미 있다** — Camino 의 크레덴시알,
한국 천주교의 순례 수첩. 그래서 정당하다. 반면 순위 경쟁은 위험하다.

## 9. 확인 못 한 것

- **색상 팔레트** — 어느 레퍼런스도 계측하지 않았다. 필요하면 다시 열어 뽑을 수 있다
- **상세 페이지 구조** — 홈 화면만 봤다
- **스크린샷** — 브라우저 창이 화면에 떠 있어야 캡처된다. 계측값으로 대신했다
- Buen Camino **리뷰 1.69만 개** — 순례자가 실제로 뭘 불평하는지가 들어 있다. 읽어 볼 값어치가 크다
