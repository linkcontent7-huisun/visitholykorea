# ADR 0003. 지도는 카카오맵으로 가되, 아직 붙이지 않았다

- 날짜: 2026-08-04
- 상태: 제안 (미구현)

## 맥락

이전 지도 화면은 실제 지도가 아니라 배경 아이콘 위에 좌표를 하드코딩한 가짜 핀 4개와
고정된 정보 카드 하나였다. 핀이 가리키는 id(`myeongdong` 등)는 DB에 존재하지도 않아
누르면 아무 일도 일어나지 않았다.

심사 기준상 "완성된 서비스"가 전제이므로, 목업을 그대로 두는 것은 위험 요소다.

## 결정

**임시 조치(이번에 반영):** 가짜 핀·가짜 카드를 걷어내고, 실제 DB 성지를 검색·교구 필터와 함께
목록으로 보여준다. 지도 영역에는 "지도 연동 준비 중"임과 좌표 확보 성지 수를 정직하게 표시한다.

**본 구현(예정):** 카카오맵 JavaScript SDK 를 쓴다.

- 한국 주소·지오코딩 정확도가 국내 서비스 중 가장 낫다.
- 길찾기 딥링크(`map.kakao.com/link/to/...`)를 이미 상세 페이지에서 쓰고 있어 일관된다.
- 공모전 규정상 TourAPI 외 공공/오픈 API 를 함께 쓰면 2차 심사 가점이 있다.

## 선행 조건

지도를 붙이기 전에 **성지 좌표부터 채워야 한다.** 좌표 없는 성지는 지도에 찍히지도 않고,
"쉼표 순례길"의 TourAPI 도보권 페어링도 동작하지 않는다. 즉 좌표 확보가 지도 작업보다 우선한다.
진행 상황은 `data/research/location_retry_summary.md` 참고.

## 구현 시 유의

- SDK 스크립트는 외부 CDN 이라 오프라인·저신호 환경에서 실패할 수 있다. 실패 시 목록 뷰로
  자연스럽게 떨어지게 만든다(지금의 목록 화면이 그대로 폴백이 된다).
- 카카오 JS 키는 도메인 화이트리스트로 보호되는 공개 키다. `VITE_KAKAO_MAP_KEY` 로 둬도 된다.
