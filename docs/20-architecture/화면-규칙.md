# 화면 규칙 — 2026-09-17 통일판

> 2026-09-17, Vercel Web Interface Guidelines(`vercel-labs/web-interface-guidelines`)로 화면을 점검한 뒤
> 정한 규칙이다. 기준 사용자는 **50대 이상**. 새 화면은 이 규칙을 따르고, 예외를 두려면 그 파일 주석에 이유를 남긴다.
> 코드는 `src/shared/components/ui/` 에 있다. 규칙의 근거는 각 컴포넌트 파일 머리 주석에 적혀 있다.

## 글자

- 본문 16px(`text-base`), 보조 14px(`text-sm`). **12px(`text-xs`) 아래는 쓰지 않는다** — 배지·출처 표기까지만 12px.
- 한국어 라벨에 `uppercase`·`tracking-widest` 를 쓰지 않는다(뜻이 없고 작아 보인다).
- 제목은 명조(`font-display`), 본문은 고딕. 굵기는 `font-bold` 까지 — `font-black`·`font-extrabold` 는 새로 쓰지 않는다.
- 낱말 중간 줄바꿈 금지·제목 마지막 줄 고르기는 `globals.css` 가 전역으로 한다(`word-break: keep-all`, `text-wrap: balance`).
- 말줄임은 `…` 한 글자. 사전(`dictionary.ts`)에서 `...` 를 전부 바꿨다.

## 색

- 누르는 것은 남색 `brand-blue` 하나. `brand-violet` 은 같은 값의 옛 이름이라 새 코드에 쓰지 않는다.
- 회색은 토큰(`app-border` · `app-text-muted` · `app-panel`)만. `gray-*`·`slate-*` 는 관리자 화면에만 남아 있다.

## 누름·포커스·움직임

- 누름 영역 최소 44px. 아이콘만 있는 버튼은 `aria-label` 필수, 장식 아이콘은 `aria-hidden`.
- `outline-none` 을 쓰지 않는다 — 키보드 포커스는 `globals.css` 의 `:focus-visible` 3px 남색 선이 전역으로 그린다.
- `transition-all` 금지. 바뀌는 속성만 적는다(`transition-colors` 등). 두 번 두드림 지연은 전역 `touch-action: manipulation` 이 없앤다.
- 날짜는 `SPEECH_LOCALE[language]` 로 `toLocaleDateString` — `'ko-KR'` 고정 금지.

## 같은 날 사장님 결정 (2026-09-17 오후)

- 같은 화면으로 가는 입구는 하나만: 상단바 검색창·돋보기·「성지 찾기」 메뉴를 빼고 홈 입구 카드만 남겼다(휴대폰 하단 탭은 유지).
- 홈의 「추천 성지」는 본문에서 빼고 푸터 링크 한 줄. 성지 카드에는 장소 이름만.
- 히어로 화살표는 사진 세로 가운데, 마지막 장 → 첫 장은 앞으로 넘어간다(복제 슬라이드).
- 성지 상세도 상단바·하단 탭 안에서 뜬다.

## 아직 안 한 것 (2026-09-17)

- 관리자 화면(`AdminPage` · `AdminSitePage`)은 운영자 전용이라 손대지 않았다(`slate-*` 남아 있음).
- `ExplorePage` 는 라우터에서 `/search` 로 보내는 죽은 화면이라 그대로 뒀다.
- 자주 묻는 질문·이용약관·404 문구는 한국어 하드코딩 그대로(다국어화는 별개 작업). 자주 묻는 질문의 「AI 순례 가이드」 항목은 제출 범위에서 뺀 기능을 설명하고 있어 문구 손질이 필요하다.
