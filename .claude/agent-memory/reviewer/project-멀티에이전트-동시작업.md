이 저장소는 여러 세션·에이전트가 **같은 로컬 작업 트리**를 동시에 고친다(2026-09-05 T-006 검토 중 실측:
검토 시작에는 없던 `data/docent/명동대성당.json` 수정이 검토 도중 나타났다).

**Why:** 검토 대상은 보통 커밋되지 않은 작업 트리다. 검토 중에도 남의 변경이 섞여 들어와,
"범위 밖 파일을 건드렸다"는 오판이나 남의 작업을 함께 커밋하는 사고가 날 수 있다.

**How to apply:** 검토를 시작할 때와 끝낼 때 `git status --porcelain` 을 각각 찍어 비교하고,
차이가 나면 그 파일이 누구 것인지 `git log`·커밋 내용으로 가려낸 뒤 검토.md 에
"이 커밋에 섞지 말 것"으로 명시한다. `git diff --numstat` 의 삭제 줄 수(0인지)는
남의 변경이 덮였는지 보는 가장 빠른 신호다.
