# 도슨트 현장조사 데이터

성지 한 곳 = 폴더 하나. 폴더명은 성지를 알아볼 수 있는 로마자 슬러그로 한다
(예: `galmaemot/`, `jeondong/`). 각 폴더에는:

- `points.json` — 도슨트 포인트 원고 (형식은 `_템플릿.json`)
- `photos/` — 현장 사진. `01-순교탑.jpg` 처럼 순번-이름으로

**사진 규칙** — 웹에 올리기 전 원본이므로 저장소에 커밋하되,
한 성지당 핵심 포인트 사진만 담는다 (참고컷은 노트북에 보관).
긴 변 1600px 이하로 줄여서 넣는 것을 권장 — 저장소가 무거워지면
나중에 clone 이 느려진다.

**원고 규칙** — `docs/30-content-ops/도슨트-현장조사-매뉴얼.md` 참조.
핵심: 비신앙인이 들어도 흥미로운 이야기여야 한다. 교리 설명이 아니라
"이 문양이 왜 여기 있는가"를 들려준다.

조사 상태는 `points.json` 의 `status` 로 관리한다:
`draft`(현장 초안) → `reviewed`(사용자 감수 완료) → `published`(웹 반영).
