│ 4. 핵심 기능 5개 — 무엇을 왜 만들었나                                          │
└─────────────────────────────────────────────────────────────────────────────┘

  ① 오디오 도슨트          ★ 수요조사 1위 (60%, 2위의 2.4배)
     208곳 기본 해설 + 대표 13곳 포인트 투어
     화면 문구 6개국어 / 원고는 한·영 (스페인어 확대가 다음 과제)
     • 성당 예절 가드 : 이어폰 없으면 재생 안 됨 (안드로이드는 실제 검증)
     • 모바일 TTS 방어 : 음성 목록 비동기 대기 · 언어 맞는 음성 선택
     • 초안 배지      : 현장 미확인 원고임을 정직하게 표시

  ② 붐빔 지수             ★ 차별점 — TourAPI 를 "역으로" 쓴다
     인기순이 아니라 한산한 곳을 계산해 추천
     ⚠ 수요조사에서 붐빔 페인은 약하게 나옴(자주 있다 0명)
        → 포지셔닝을 "관광지의 조용한 대안"으로 수정함

  ③ 순례 여권 · 스탬프
     건축 모티프 도장 13종 / 전례력 색 잉크 / 순례 별자리 / 교구 완주
     스탬프 0일 때 빈 여권 미리보기 (미리보기임을 반드시 명시)

  ④ 순례자 이야기          ★ 함께 만드는 앱
     스탬프 찍은 사람만 한 줄·사진 기여 → 실방문 인증이 저절로 됨
     좋은 사진은 운영자 승인으로 성지 대표 사진 승격 (사진 부족 해결 경로)

  ⑤ 마음 나침반
     7문항 → 지금 마음에 맞는 성지·코스 추천


┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. [불변 규칙] — 이것만은 절대 바꾸지 않는다                                   │
└─────────────────────────────────────────────────────────────────────────────┘

  ① TourAPI 응답을 저장하지 않는다
     한국관광공사 데이터는 매 요청 실시간 호출. DB·서비스워커 캐시 금지.
     → 어기면 공모전 실격 위험. (holy_sites 는 우리 자산이라 저장 자유)

  ② 비밀 키를 클라이언트에 두지 않는다
     VITE_ 접두사가 붙은 값은 브라우저에 그대로 노출된다.
     감출 키는 Supabase Edge Function 시크릿으로.

  ③ AI 답변은 성지 DB 안으로 제한한다
     종교 성지의 역사·전례는 틀리면 신뢰가 즉시 무너진다.
     "컨텍스트에 없으면 모른다고 답하라"를 시스템 프롬프트에 못 박아 둠.

  ④ 더미 데이터를 화면에 남기지 않는다
     심사 대상이 "완성된 서비스"다. 가짜 핀·가짜 카운트 금지.
     미구현 영역은 "준비 중"이라고 정직하게 표시.
     검수용 테스트 데이터는 쓰고 반드시 지운다.

  ⑤ 확인 못 한 것은 "확인 못 했다"고 쓴다
     추측을 사실처럼 적지 않는다. 숫자를 인용할 땐 언제 잰 값인지 함께.

│ 8. 실수했던 것 — 같은 실수를 반복하지 않기 위해                                │
└─────────────────────────────────────────────────────────────────────────────┘

  · 흰 화면 사고 (9/1)
    최신 정규식 문법(lookbehind) 한 줄이 구형 아이폰에서 앱 전체를 죽였다.
    → build.target=safari14 로 못 박음. 빌드가 실패해서 배포 전에 잡힌다.

  · 이어폰 영구 잠금 (9/1)
    마이크 없는 유선 이어폰을 "없음"으로 오판하고 출구 버튼도 없었다.
    → 장치 목록은 "있음"만 증명할 수 있다. 차단해도 출구는 항상 남긴다.

  · 사진 14MB 홈 화면 (8/28)
    원본 사진을 그대로 올려 링크가 멈췄다.
    → 사진은 1600px · 700KB 이하 규칙.

  · 문서가 코드보다 뒤처짐 (8/19)
    열흘 방치된 문서를 믿고 이미 끝난 일을 다시 할 뻔했다.
    → 작업이 끝나면 그 자리에서 docs/이어서-할-일.md 를 고친다.

  · "0km" 표시 (9/4)
    출발지가 시·도 대표 좌표라 같은 시 안이면 0이 나왔다.
    → 0은 정보가 아니라 고장으로 읽힌다. 숫자가 무의미하면 말로 바꾼다.
